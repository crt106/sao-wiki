# I0R8 · 狂风魔杖

> **品质**：稀有　**类型**：武器

**基础属性**

| 属性 | 数值 |
|---|---:|
| 筋力 / 敏捷 / 体力 | 各 +50 |
| 生命值上限 | +8,000 |

**主动技能：风卷**

- 向指定方向放出狂风，最大前进 3,000 码，速度约 400 码/秒，总持续约 7.5 秒。
- 每 0.01 秒对狂风周围 250 码的存活敌对非建筑单位造成 1 点固定混乱伤害。
- 伤害由独立附加效果造成，不会反复触发持有者自己的普攻与装备被动。
- 冷却 25 秒；高频命中专门用于击破 75 层骸骨猎杀者巡游态的中段骨架。

- **获取**：74 层风史莱姆（`nW74`）死亡时有 **5%** 概率掉落。
