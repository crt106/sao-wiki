# I0ON · 智慧之冠

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0ON`

!!! info "2.5 重审结论"
    旧页来源不明的问题已经定位：本物品由固定宝物箱（单位 ID：`ndrv`） 直接必掉。召唤物的查询文字写“攻击造成 1～3 万”，但 2.41 与 2.5 的真实附伤一直是 5,000～12,000。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 体力 | +220 |
| 生命值上限 | +10,000 |
| 防御力 | +40 |
| 魔法伤害减免 | 41% |
| 魔法／体力恢复数值 | +60 |

五项被动技能 ID 为 `A076`、`A191`、`A1BQ`、`A13H`、`A1BR`。表中的“恢复+60”是魔法恢复，不是生命回复。

## 主动：禁忌召唤

使用物品会施放 `A1BS`：

- 魔法消耗：100；
- 冷却：40 秒；
- 召唤数量：1；
- 持续时间：10 秒；
- 召唤单位：`n046`“暗黑元素”。

暗黑元素拥有50000生命、80防御、1.2秒攻击间隔和1200攻击距离；普通攻击基础值很低，主要伤害来自下方的追加伤害。

### 普通攻击附伤

=== "2.5 狂猎"

    暗黑元素造成一笔 普通伤害类型 普通攻击伤害时，只要伤害来源与目标有效且双方仍存活，就会额外造成 **5,000～12,000** 随机混乱攻击／火焰伤害。

    2.5修复了无效目标或死亡单位仍会继续受到追加伤害的问题。

=== "2.41 测试版"

    同样追加 **5,000～12,000** 随机混乱攻击／火焰伤害，但旧版缺少 2.5 的无效目标与存活保护。

    两个版本都不是查询文字所写的 10,000～30,000。

## 获取方式

指定宝物箱（单位 ID：`ndrv`）会直接掉落 `I0OM` 与 `I0ON`，没有随机判定。因此智慧之冠为 **必掉**。

当前没有正常商店、扭蛋、合成或其他直接获得方式。
