# I0QD · 熔火结晶

> **类型**：素材　**游戏数据价格**：2,000 金

- 描述：封存着流萤熔火形态残留能量的炽热结晶。
- **获取**：击杀[隐藏 Boss 流萤](../../info/楼层/隐藏与副本Boss/流萤.md)（`n0FF`）后，按当前在线玩家人数生成等量公共掉落。
- **用途**：与[动能腿甲](../装备道具/I0NY_动能腿甲.md)合成为[动能腿甲·熔火](../不归类/I0QC_动能腿甲·熔火.md)。

!!! note "掉落口径"
    掉落数量与当前在线玩家人数相同，但不会逐人绑定，请提前约定分配方式。
