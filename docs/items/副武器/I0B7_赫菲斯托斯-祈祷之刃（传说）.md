# I0B7 · 赫菲斯托斯-祈祷之刃（传说）

> **品质**：传说　**类型**：副武器（剑）　**物品 ID**：`I0B7`　**物品等级**：8

| 属性 | 实际值 |
|---|---:|
| 敏捷 | +210 |
| 攻击速度 | +100% |

旧页与新版 HUD 说明所写的“攻击力 +100”当前不生效。

## 恩惠之路

本物品可主动使用：

| 项目 | 实际值 |
|---|---:|
| 魔法消耗 | 100 |
| 冷却时间 | 30 秒 |
| 地面持续时间 | 5 秒 |
| 每个光环半径 | 300 |
| 每秒生命恢复 | 250 |

施放时会沿持有者面向，在0、300、600码处分别形成一个持续5秒、半径300的生命恢复区域。该区域只提供固定恢复，不含旧说明暗示的百分比增幅；游戏说明写35秒冷却，实际为30秒。

## 获取方式

击败单位 ID 为 `nmgd` 的对应敌人时，当前固定掉落 `manh`，不会掉落本物品；全面复核也未发现其他正常来源。

因此按 2.5 当前版本的正常流程，**祈祷之刃无法获取**。
