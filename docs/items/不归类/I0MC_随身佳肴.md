# I0MC · 随身佳肴

> **品质**：传闻　**类型**：不归类　**物品 ID**：`I0MC`

!!! info "2.5 重审结论"
    四种随机效果各占25%。回血回蓝实际执行9次，临时属性和防御约持续6秒，均比说明多一轮。2.5还新增了将本物品合成为“梦幻”的用途。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +200 |
| 敏捷 | +200 |
| 体力 | +200 |

## 主动：随身佳肴

主动能力 `A17H` 冷却 18 秒。施放后通过三层随机判断形成四个等概率结果，每项概率均为 **25%**：

| 结果 | 实际效果 |
|---|---|
| 鲜美佳肴 | 每1秒回复 `当前筋力×4` 生命与 `当前体力×4` 魔法，实际共9次 |
| 鲜美肉汤 | 添加全属性+100的 `A17D`，实际约持续6秒 |
| 鲜美零食 | 添加防御 +100 与魔法伤害减免 25%；同样约持续 6 秒 |
| 美味酒水 | 通过 `A17J` 增加 80% 移动速度，持续 5 秒；攻击速度加成为 0% |

前三个结果为持续效果；持有者死亡会提前结束并移除临时属性。说明中的“8秒／5秒”均比实际少一轮。

## 获取方式

美食任务以玩家状态值记录进度。购买任务物品 `I0MB` 时：

- 状态 0：接取任务；
- 状态 1：提示尚未完成；
- 状态 2：置为已完成状态 3，并直接把 1 件随身佳肴加入购买者背包；
- 状态 3：拒绝重复领取。

因此本物品是美食任务的一次性最终奖励，不是普通商店库存或随机掉落。
