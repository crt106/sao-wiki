# I00M · 狼征战斗服

> **品质**：劣质　**类型**：装甲

> **2.5 复核结论**：物品属性与旧页一致；本次补齐打造失败会照常消耗材料充能。2.5 版本差异记录未标出本物品改动，不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +20 |
| 敏捷 | +20 |
| 智力 | +20 |
| 防御值 | +5 |

## 获取方式

在 1 城防具打造中使用[夜狼狼皮](../素材/I00Z_夜狼狼皮.md)：

- 成功时直接获得狼征战斗服；
- 成功与失败都会消耗 1 次材料充能。

因此每次材料充能的实际获得概率为 **1/2（50%）**。
