# I0HQ · 战斗昆虫甲

> **品质**：普通　**打造物品等级**：29

> **2.5 复核结论**：旧页属性正确，但没有给出打造失败率与池内概率。2.5 与 2.41 游戏数据一致，本页不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +45 |
| 敏捷 | +45 |
| 智力 | +45 |
| 防御值 | +30 |
| 生命值上限 | +4500 |

生命值由 `A0H6` 的 2500 与 `A0H4` 的 2000 相加得到。

## 获取方式

在防具打造中使用[虫蛋壳](../素材/I004_虫蛋壳.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0HQ` 或 `I0HU`；
- 无论成功与否都会消耗 1 次材料充能。

每次材料充能获得本物品的名义概率为 **1/4（25%）**。游戏数据中的木材价格数值没有商店库存，不能作为购买来源。
