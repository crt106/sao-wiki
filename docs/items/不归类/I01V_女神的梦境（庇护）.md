# I01V · 女神的梦境（庇护）

> **品质**：祝福　**类型**：不归类　**物品 ID**：`I01V`

!!! warning "“免疫伤害”说明与实际效果不符"
    项目查询文字写“免疫伤害 5 秒”，但技能 `A11W` 实际只提供约 1% 减伤，并非 100% 免伤。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +120 |
| 敏捷 | +120 |
| 体力 | +120 |
| 生命值上限 | +20,000 |

## 主动：女神的指引

使用物品会施放 `A11W`：

- 持续时间：5 秒；
- 移动速度变化：0%；
- 攻击速度变化：0%；
- 所受伤害降低约 1%；
- 技能冷却：30 秒。

物品说明中的“CD 240”不正确，实际冷却为 30 秒。

## 被动：吞噬梦境

敌人开始攻击持有者时：

有 **25%** 概率回复：

`当前筋力（含加成）×5`

效果在持有者成为攻击目标时生效，不要求该次攻击已经命中。

## 获取方式

施放融合能力 `A0Y9` 时，若同时持有以下三件物品，会将三件材料全部移除并获得女神的梦境（庇护）：

- [Bug·幻梦之花](../装备道具/I0K4_Bug·幻梦之花.md) `I0K4`；
- [Bug·祈祷铃铛](../装备道具/I0KG_Bug·祈祷铃铛.md) `I0KG`；
- [水晶矿石](../素材/I0BB_水晶矿石.md) `I0BB`。

`I0K4 + I0KG + I0BB → I01V`

当前没有商店、扭蛋或固定掉落方式。
