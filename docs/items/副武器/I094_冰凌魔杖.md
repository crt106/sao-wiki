# I094 · 冰凌魔杖

> **品质**：稀有　**类型**：副武器（法杖）　**物品 ID**：`I094`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +70 |
| 敏捷 | +70 |
| 体力 | +190 |
| 生命值上限 | +7,500 |

体力由全属性 70 与额外体力 120 相加得到；生命值由 5,000 与 2,500 两项能力相加得到。

游戏说明虽然写有“魔法防御 41”，但本物品实际只有全属性、额外体力和两项生命加成，不提供 41% 减伤。

当前版本没有正常获取方式。游戏数据中的 5 木材价格不代表本物品可以购买。
