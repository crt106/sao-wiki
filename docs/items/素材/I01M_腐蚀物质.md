# I01M · 腐蚀物质

> **类型**：素材　**物品等级**：45　**使用次数**：1

> **版本结论**：2.5 与 2.41 的游戏数据和怪物掉落一致；本页以 2.5 重新核验后的结论为准，不另设版本 Tab。

## 获取方式

- 来源单位：36 层雪地小昆虫（单位 ID：`nspd`）。
- 击败该单位时，掉落率为 `1/20`（5%）。

因此，腐蚀物质的实际单次掉落率为 5%。

游戏名称仍写作“36.37 层／腐蚀物质”，但当前只会由 36 层的 `nspd` 掉落，不能扩写为 37 层通用掉落。
