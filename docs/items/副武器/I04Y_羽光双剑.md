# I04Y · 羽光双剑

> **品质**：普通　**类型**：副武器　**物品 ID**：`I04Y`　**物品等级**：28

## 实际属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +150 |
| 筋力 | +10 |
| 敏捷 | +80 |
| 生命值上限 | +1,500 |

旧页遗漏了实际存在的 **筋力 +10**。

## 生命吸收 Lv2

攻击造成伤害后，将 **20% 伤害**转为生命值。

## 获取方式

在 2 城武具打造中使用 [16层／鸟之羽（稀有材料）](../素材/I01I_鸟之羽（稀有材料）.md)：

1. 每次消耗 1 充能材料；
2. 打造成功率 50%；
3. 成功后随机获得 `I04X`、`I04Y`、`I0GW`、`I0JM` 中的 1 件。

若四种成功结果等概率，则每次打造获得本物品的概率约为 1/8（12.5%）；最终分布仍建议以长期游戏统计为准。
