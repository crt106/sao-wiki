# I0GG · 楼兰之剑·沉梦

> **品质**：传说　**类型**：副武器（剑类）　**物品 ID**：`I0GG`　**物品等级**：2

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +500 |
| 筋力 | +90 |
| 敏捷 | +90 |
| 体力 | +90 |

## 被动效果

- **高级致命**：`A08D` 的实际参数为 50% 概率、3 倍伤害；旧页漏写了这一项。
- **吸血鬼病原体**：攻击造成伤害时，将其中30%转化为自身生命值。

## 获取方式

`n00T`（梦岚离）的三项掉落掉落表面写成：

`manh 33% / I01W 34% / I0GG 33%`

当前实际掉落为：`I0GG` 必定获得，另有 33% 概率同时获得 `manh`。

因此楼兰之剑·沉梦在当前版本中是梦岚离的**固定掉落**，不是旧页所写的 33% 权重掉落。
