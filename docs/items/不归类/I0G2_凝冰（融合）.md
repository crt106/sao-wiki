# I0G2 · 凝冰（融合）

> **品质**：融合 · **类型**：不归类 · **物品等级**：154

## 基础属性

| 属性 | 数值 | 物品自带能力 |
|------|-----:|----------|
| 攻击力 | +1200 | `A0WN` |
| 敏捷 | +350 | `A11Z` |
| 体力／智力 | +350 | `A11Z` |

持有时还会获得移动速度 +100% 和攻击速度 +100%；原物品描述没有列出这两项，最终移动速度仍受游戏速度上限影响。

## 物品能力

### 弓术

[真白](../../heroes/穿越时空的少女_椎名真白.md)（单位 ID：`H009`）持有 `I0G2` 时，“弓之伤害等级”增加 5。它会进入以下公式：

- Q 普通弹体远距分支：作为最终固定加数；
- E 魔法箭雨：作为 `10 + 弓之伤害等级` 的一部分；
- R 风，消散吧：作为 `2 + 弓之伤害等级` 的倍率部分，并以施法时的等级为准。

W不受该等级影响。Q与诗乃标记联动，W、E另有专属属性切换，详见下方版本Tab。

### 冰魄箭（S级）

被动技能 `A120` 的效果为：

- 作用半径：300；
- 目标间隔：0.1 秒；
- 初始伤害：2000；
- 持续伤害：每秒 800；
- 持续时间：3 秒。

这是物品自带的被动能力，不是需要点击施放的主动技能。游戏数据能确认上述参数，但多目标选择、重复上弹和持续伤害刷新方式仍应以实际游戏为最终准绳。

## 真白技能联动

物品属性、融合配方与专属持有条件在 2.41→2.5 间没有明确变化；2.5 调整的是配套英雄 Q 的伤害系数。

=== "2.5（狂猎）当前版"

    | 技能路径 | 无凝冰 | 持有凝冰 |
    |----------|--------|----------|
    | Q 普通弹体近距 | 敏捷×98 | 仍为敏捷×98，仅享受物品属性 |
    | Q 普通弹体远距 | 敏捷×随机系数（98～289）＋等级 | 公式属性不切换，并加入凝冰提供的等级 +5 |
    | Q 诗乃标记联动 | 敏捷×98 | **（敏捷＋智力）×98** |
    | W 空中阻击 | 每支敏捷×4 | **每支（敏捷＋智力）×2.5** |
    | E 魔法箭雨 | 敏捷×随机系数（5～8）＋（10＋等级） | **（敏捷＋智力）×随机系数（5～8）＋（10＋等级）** |
    | R 风，消散吧 | （敏捷＋智力）×（2＋等级） | 属性公式不变；物品属性和等级 +5 均会提升伤害 |

    !!! warning "Q 不是统一切换"
        `I0G2` 只改变 Q 与诗乃标记联动时的伤害；普通弹体的近距与远距伤害仍按原公式结算。旧 Wiki 把整个 Q 都写成“敏捷改为敏捷＋智力”，范围过大。

## 专属限制

只有[真白](../../heroes/穿越时空的少女_椎名真白.md)（英雄 ID：`H009`）可以持有；其他英雄拾取后会收到“专属道具”提示，并被移出背包。

## 获取方式

在打铁妹处使用 `A0Y9`「打造（T）」并提交以下三件材料，即可合成 `I0G2`：

| 材料 ID | 材料 |
|---------|------|
| `I09D` | [轻羽光弓](../武器/I09D_轻羽光弓（传说）.md) |
| `I0JN` | [急流·提升◆◆◆](../副武器/I0JN_急流·提升◆◆◆.md) |
| `I09G` | [圣物-蓝炎宝石](../特殊/I09G_圣物-蓝炎宝石（稀有）.md) |

当前 2.5 中没有凝冰的普通商店、Boss 掉落、扭蛋或地图固定放置来源；只能通过上述打造融合获得。该配方不消耗金币，材料齐全时必定成功。
