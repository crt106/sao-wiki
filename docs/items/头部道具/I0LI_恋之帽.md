# I0LI · 恋之帽

> **品质**：礼物　**类型**：头部道具　**物品 ID**：`I0LI`

!!! warning "当前没有有效的持有者限制"
    恋之帽可以转交给其他英雄使用，不会被自动移出背包。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +30 |
| 敏捷 | +30 |
| 体力 | +30 |
| 生命值上限 | +1,000 |
| 防御力 | +15 |

本物品只有物品属性，没有额外技能或攻击／施法触发效果。

## 获取方式

唯一来源是一次性订制支持包：

1. 配置的支持身份使用领取物品 `I0KV`；
2. 本局尚未领取过该奖励；
3. 同时发放 `I0LG`、`I0LH`、`I0LJ` 与 `I0LI`；
4. 每局只能领取一次。

本物品只能通过上方订制奖励获得，普通首领、商店、打造、合成和扭蛋均不提供。

订制领取资格只限制获取方式；物品获得后可以转交给其他英雄使用。
