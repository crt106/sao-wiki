# 界面与 HUD

2.52 提供新版 SAO 风格 HUD 与经典 Warcraft III 界面。开局由 1 号位的房间种族决定：选择兽族时使用经典界面；选择人族或其他种族时启用新版 HUD。

!!! warning "`-hud` 不是经典界面切换"
    新版 HUD 初始化后，输入 `-hud` 只会隐藏或重新显示自定义装饰层；原生按钮、小地图、头像位置与界面布局仍保持新版安排。若要完整经典界面，需要在开局前选择兽族模式。

## 新版 HUD 显示内容

- 底部命令台整合英雄 3D 肖像、生命／魔法、属性、技能、背包与功能菜单。
- 左上显示自己与队友卡片；顶部显示游戏时间、当前楼层与进度。
- 右上资源区显示金币、荣誉、人口，并额外显示复活次数与积分。
- 英雄状态与部分物品被动会显示自定义状态槽，悬停可查看说明或剩余时间。
- 选中商店时，货架会显示在右侧侧挂面板，底部仍保留自己英雄的背包，方便购买时核对空位。
- 多选两个以上单位时，命令台上方会出现最多 12 格的多选面板；点击格子可切换为单选该单位。

## 物品与属性提示

- 悬停背包或商店物品时，会显示新版名称、类型、属性、技能与描述。
- 取消当前单位选择后，把鼠标移到地面物品附近，也能显示地面物品详情；若没有出现，先按 <kbd>Esc</kbd> 或点击空地清除选中单位。
- 悬停英雄属性区可查看白字、绿字、护甲类型与特殊状态等补充信息。

## 右侧功能菜单

| 按钮 | 当前效果 |
|---|---|
| 选中佣兵 | 选中自己当前存活的佣兵或契约猫；没有时给出提示 |
| 选中宠物 | 选中自己当前存活的宠物；没有时给出提示 |
| 快速回城 | 只把主英雄传送到起初之镇并消耗 1 次回城次数；特殊战斗状态下不可用 |
| 指令帮助 | 打开游戏内帮助页 |
| 装备图鉴 | 当前为占位按钮，后续版本开放 |
| 隐藏首领 | 当前为占位按钮，后续版本开放 |

快速回城按钮与聊天指令 `HC1` 的目的地和限制相同，但按钮只传送主英雄；`HC1` 还可能连同佣兵英雄一起处理，并分别消耗次数。

## 常用操作

- `-hud`：隐藏／显示新版 HUD 的装饰层。
- <kbd>F9</kbd>：打开原生任务面板。
- <kbd>F10</kbd>：打开原生菜单。
- <kbd>F11</kbd>：打开原生盟友面板。
- <kbd>F12</kbd>：打开原生消息记录。

新版布局会接管顶部部分按钮的位置；即使某个顶栏图标被移出可见区，相应功能键仍可使用。
