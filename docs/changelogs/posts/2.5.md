# 2.5 版本更新

刀剑物语改图 2.5(狂猎)版本更新内容，重头戏是全新自绘的 **SAO 风格战斗界面**与**内置存档系统**，同时包含新英雄莉奈娅、新增 73~75 层与多场隐藏 BOSS 战、**AI 电脑队友**、大规模英雄数值调整，以及一大批崩溃 / 逻辑 bug 修复。

!!! tip "这个版本能存档了"
    聊天框输入 `-save` / `-load` 即可保存和读取进度，终于不用每次都从 1 层刷起。

<!-- more -->

## 全新战斗界面

- 全屏自绘 HUD 替换原版魔兽界面：英雄栏、命令卡、物品栏、小地图、头像与血蓝条全部按类 SAO 风格设计稿重新摆放，原版顶部信息栏同步隐藏，你问为什么不是完全还原 SAO
- 新增最多 5 人的队友状态卡，血条低血量时变红提示
- 物品 / 技能 tooltip 全面重制为结构化面板，全图约 949 件物品预渲染说明文本
- 新增自定义 buff 条：护甲、无敌等特殊状态直接在血条区外显数值；首批 16 项英雄关键机制也已接入——桐人残影数量与持续时间、缇娜武器形态、夏娜"炎发灼眼"、斑"须佐能乎"、草壁操双剑等级、喵可莉流血层数、莉奈娅召唤物剩余时间等状态现在都会直接显示层数 / 倒计时
- 更换专用字体（数值字体 Rajdhani + 中英混合字体），修复旧字体中文字形空白问题
- 顶部新增时间 / FPS / 网络同步校准值(分车检查)显示
- 商店界面同步适配新 HUD 的选中、地面拾取与卡片切换交互
- 新老 HUD 切换方式：**玩家 1 选择兽族以外的种族为全新 HUD，选兽族则为旧版 UI**

## 存档系统（新）

- 聊天输入 `-save` 保存进度、`-load` 读取进度，重开游戏后自动恢复英雄等级、三维属性、装备、金币木材、坐标与团队主线进度
- 雇佣兵、宠物、地面掉落物、已开启的宝箱、限购商店记录、回城次数一并保存
- 部分英雄的专属状态也已支持存读档
- 部分特殊游戏进度内会不允许存档读档

## 新英雄：莉奈娅

- from神神的原，输出 + 辅助定位，技能强度随"命座"层数成长

## AI 队友 (测试功能)

- 大厅中创建房间时加入电脑玩家后，电脑会自动选择英雄成为队友参战：命运模式下随机指派，自选模式可用 `-ai` 指令为电脑指定英雄，超时未选则自动随机
- 目前电脑会自动选择的英雄范围有限,共10人
- 电脑队友会跟随队伍作战、自动释放技能连招，会自动拾取队友丢弃的装备并走合成链合成；缺少关键装备时会开口向队友索要
- 面对高危 BOSS 技能时会主动走位躲避危险区域，配合集火与停手节奏，还会根据战况进行喊话互动
大概吧 以上功能相关命令可以使用 `-ai help`游戏内查看
