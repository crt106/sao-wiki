# I0LD · 精致混动盔甲

> **品质**：普通　**类型**：装甲　**物品等级**：19　**物品 ID**：`I0LD`

!!! info "本次重审结论"
    2.5 与 2.41 的属性和通用效果相同。旧 Wiki 漏掉了每秒生命回复、医疗波的三目标衰减和“施法回复 2000”的空目标问题，也把它误写为[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)专属；实际任何英雄都能持有，[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)的 Q、E 与隐藏普攻被动会获得额外强化。2.5 仍没有正常获取来源。

## 基础属性

| 属性 | 实际数值 | 来源能力 |
|------|---------:|----------|
| 力量 | +30 | `A0C7` |
| 敏捷 | +30 | `A0C7` |
| 体力 | +30 | `A0C7` |
| 最大生命值 | +2000 | `A0H4` |
| 魔法伤害减免 | 22% | `A07B` |
| 每秒生命回复 | +120 | `A07O` |

对应技能 ID 为 `A1DL`、`A0H4`、`A0C7`、`A07B`、`A07O`。其中 `A07O` 虽显示“生命恢复 60”，实际为每秒恢复 120 点生命。

## 主动 · 医疗波

主动使用技能 `A1DL` 时：

| 参数 | 实际值 |
|------|--------|
| 首个目标恢复 | 5000生命 |
| 最大目标数 | 3 |
| 每次跳跃衰减 | 25% |
| 施法距离 | 900 |
| 魔法消耗 | 0 |
| 冷却 | 9秒 |

按游戏数据原始数据计算，三个目标的名义治疗量依次为5000、3750、2812.5；最终取整、目标选择顺序、无第二或第三名有效友军时的跳跃表现由 Warcraft 医疗波结算。

`-cxitem` 的“生命的流动：恢复5000生命值，冷却9秒”只描述了首个目标，不能据此写成固定单体治疗。

## 施法回复2000的空目标错误

游戏内还保留了“施放技能后额外回复 2000 生命”的旧说明，但该效果当前不会对持有者生效，不能计入物品收益。实际可用的恢复效果只有上文所列的医疗波。

## 斯托蕾亚联动

任何英雄都能持有本物品；[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)持有时，Q、E 与 `A0JO` 会获得以下变化：

| 技能 | 无 `I0LD` | 持有 `I0LD` |
|------|------------|--------------|
| Q · X跳斩 | 力量×72 | (力量＋敏捷)×72 |
| E · 幻魔神剑 | 属性基数取力量 | 属性基数取力量＋敏捷 |
| 20级 `A0JO` 普攻附伤 | 固定6000 | `6000＋(受击者力量＋受击者敏捷)×3` |

2.41 的 Q 倍率为25，E 的四档倍率为16／20／38／58；取属性方式和 `A0JO` 的受击者游戏数据错误与2.5相同。

!!! danger "R 分支不是自身属性强化"
    持甲时，`A0JO` 错误地按受击者属性计算，而不是按[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)自身属性。因此目标属性越高，附加伤害越高；2.5仍未修复。

## 获取方式

**当前2.5没有正常获取渠道。** 物品等级与标价不能作为掉落或商店来源的依据。

## 使用限制

物品没有英雄类型限制，也不绑定固定[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)单位。任意持有者都能获得基础属性与医疗波；只有[斯托蕾亚](../../heroes/斯托蕾亚_魔方.md)技能本身会进入上面的联动分支。
