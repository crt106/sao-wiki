# I0PX · 罪欲

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0PX`

!!! warning "“濒临死亡”只是说明文字"
    冷却就绪时，任意一笔正伤害都会触发圣洁之光，不要求伤害足以致命。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +150 |
| 敏捷 | +150 |
| 体力 | +200 |
| 生命值上限 | +15,000 |
| 防御力 | +50 |

## 被动：圣洁之光

冷却就绪且受到正伤害时：

1. 将本次伤害归零并把持有者生命设为 1；
2. 无敌、暂停 3 秒；
3. 结束后增加一份最大生命值，通常回满；
4. 3 秒结束后才启动 60 秒冷却，因此触发到再次可用约为 **63 秒**。

该保护只覆盖普通有效伤害，特殊击杀效果不保证触发。本物品的冷却独立于[罪恶王冠](I0C3_罪恶王冠（传说）.md)；同时持有多件保护装备时，它们可能在不同伤害中依次生效。

## 获取方式

使用 1 件[圣物·蓝炎宝石](../特殊/I09G_圣物-蓝炎宝石（稀有）.md)进行宠物打造：

`I09G → I0PX`

这条单材料配方在 2.41 与 2.5 均存在。当前版本没有正常商店、首领直接掉落或扭蛋入口。

## 合成用途

=== "2.5 狂猎"

    可与[苍穹之冠](I0NZ_苍穹之冠.md)合成[王女之冠](I0Q9_王女之冠.md)：

    `I0PX + I0NZ → I0Q9`

=== "2.41 测试版"

    旧版没有 `I0Q9`，也没有这条两材料配方。
