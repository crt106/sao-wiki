|---|---:|

## 获取方式

本物品来自地图中的一只**指定金色宝箱**，不是所有金色宝箱的通用掉落：

- 宝箱单位 ID 为 `nrvs`；
- 击破后有 60% 概率掉落 `I063`、20% 概率掉落 `I03T`、20% 概率掉落动能石光杖。

因此本物品的实际概率为 **20%**。
