# I0GW · 精致羽光双剑

> **品质**：优越　**类型**：副武器（双剑）　**物品 ID**：`I0GW`　**有效物品等级**：28

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +300 |
| 筋力 | +10 |
| 敏捷 | +80 |
| 生命值上限 | +1,500 |

## 被动效果

攻击造成伤害时，会将其中30%转化为自身生命值。

## 获取方式

2 城武具打造检测背包中的 [I01I · 鸟之羽（稀有材料）](../素材/I01I_鸟之羽（稀有材料）.md)：

1. 成功率 50%；
2. 无论成功还是失败，都消耗[鸟之羽](../素材/I01I_鸟之羽（稀有材料）.md)的一次使用次数；
3. 成功后随机获得 `I04X`、`I04Y`、`I0GW`、`I0JM` 中的 1 件。

若四种成功结果等概率，则每次打造获得本物品的概率约为 1/8（12.5%）；最终分布仍建议以长期游戏统计为准。
