# I017 · 混动盔甲

> **品质**：普通　**物品等级**：物品等级 19

> **2.5 复核结论**：旧页漏掉每秒 80 点生命恢复，也写错了 Boss 掉率；本物品在 Soul Reaper 掉落中实际为必掉。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +30 |
| 敏捷 | +30 |
| 智力 | +30 |
| 生命值上限 | +1500 |
| 所受魔法伤害 | -22% |
| 生命恢复 | +80/秒 |

`A07P` 的能力名仍写“生命恢复40”，但实际数值为 80。

## 主动效果

**生命的流动**使用 `A1DL` 医疗波：

- 施法距离 900，魔法消耗 0，冷却 9 秒；
- 首个目标恢复 5000 点生命；
- 最多治疗 3 个目标，后续目标的治疗量会逐次降低。

游戏内还保留了“施放技能后额外恢复 2000”的旧效果，但当前不会对持有者生效，不能计入有效治疗。

## 获取方式

有两个正常来源：

1. **防具打造**：使用[8层富人的布料（稀有材料）](../素材/I044_8层富人的布料（稀有材料）.md)，每次材料充能 **50%** 直接获得。
2. **Soul Reaper**：击败该 Boss（单位 ID：`npfm`）后，必定掉落 1 件。

医疗波的跳跃取整表现仍待实际确认。
