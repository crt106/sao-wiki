# 其他好玩的

> 本页集中整理复活次数、复活类道具和容易被旧资料误判的特殊机制。下列结论以 2.5 的当前游戏表现为准。

## 复活次数如何计算

- 每名正常开局的玩家都有 **1 次**复活次数。
- 完成英雄选择时，英雄还会获得 1 个 [`I09F` 复活水晶](../items/特殊/I09F_复活水晶.md)；这个物品不会在拾取时加次数，必须**主动使用**，使用后复活次数 +1。
- 使用游戏内查询指令可以查看当前玩家剩余的复活次数。
- 普通英雄死亡时，若当前次数至少为 1，则消耗 1 次并在约 3 秒后原地复活，随后获得约 1.5 秒无敌。

!!! note "不计入本页的免次数复活"
    [莉伊](../heroes/莉伊.md)大招和 [`I0OV` 七皇统治](../items/不归类/I0OV_七皇の统治.md) 的复活优先级高于普通复活，触发时不消耗复活次数，因此不计入下方水晶统计。

## 直接增加复活次数的道具

| 道具 | 实际行为 | 当前获取方式 |
|---|---|---|
| [`I09F` 复活水晶](../items/特殊/I09F_复活水晶.md) | 每主动使用 1 个，所属玩家复活次数 +1 | 英雄选择赠送；限量商店兑换；Boss、宝箱与地图掉落池 |
| [`I0BY` ★Zero剑](../items/武器/I0BY_★Zero剑（★）.md) | 共有 3 次使用次数；每次使用令复活次数 +1，最多合计 +3 | 扭蛋机 A 的 1★奖励 |
| [`I0OH` 商店复活水晶购买项](../items/特殊/I0OH_复活水晶.md) | 购买后获得真正的[复活水晶（`I09F`）](../items/特殊/I09F_复活水晶.md) | `h071` 限量商店，200 金，单局总库存 5，当前不刷新 |

!!! warning "旧页的“捡起就 +1”不成立"
    只有实际使用 `I09F` 或 `I0BY` 才会增加复活次数；单纯拾取不会生效。

## 蝶恋花的死亡被动

[`I0O0` 蝶恋花](../items/装备道具/I0O0_蝶恋花.md)由 [`I04J` 恶魔的右手](../items/装备道具/I04J_恶魔的右手.md) + [`I04K` 灰姑娘的水晶鞋](../items/装备道具/I04K_灰姑娘的水晶鞋.md) + [`I0D2` 红吻胸针](../items/装备道具/I0D2_红吻胸针（礼物）.md) 合成。

携带者死亡时分成两部分结算：

- **每次死亡都执行**：搜索死亡点 3000 范围内的非敌对单位，补满生命与魔法；这里不是“全图队友”。
- **600 秒冷却部分**：若该持有者所属玩家的化蝶冷却未占用，就从当前仍在游戏中的玩家里随机选 1 人，使其复活次数 +1，然后开始 600 秒冷却。
- 随机目标可能是持有者自己，也可能是其他正在游戏的玩家；当前效果没有排除本人。

!!! warning "冷却按玩家记录"
    化蝶的 600 秒复活奖励冷却由同一玩家的所有单位共享，额外携带同名物品不会重置冷却；范围补满生命与魔法的效果仍会在每次死亡时执行。
