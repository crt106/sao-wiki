# I05E · 鬼人面具

> **品质**：稀有　**类型**：头部道具　**物品 ID**：`I05E`

!!! info "2.5 重审结论"
    击败单位 ID 为 `njga` 的首领时必定掉落本物品。生命吸收为 10%；同时持有多件吸血物品时只取最高比例。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +10 |
| 防御力 | +1 |
| 生命值上限 | +300 |

## 生命吸收 Lv1

普通攻击造成伤害时，按 **10%** 比例恢复生命：

1. 汇总攻击者持有的全部吸血物品；
2. 只保留其中最高比例，不进行相加；
3. 按当时结算伤害的 **10%** 计算本物品的治疗量；
4. 只有治疗量大于 1 时才回复，并且不会超过攻击者的已损失生命。

该触发发生在英雄／保命物品对伤害的前置改写之后、Boss 减伤与护盾结算之前。因此最终实际吸血量不一定等于目标最后扣除生命的 10%，需要结合完整伤害结算顺序理解。

## 获取方式

击败鬼人（单位 ID：`njga`）后，会掉落：

- 通用材料 `I0BE` 1 件；
- 鬼人面具 `I05E` 1 件。

击败 20 级凶灵贞子（单位 ID：`njga`）后必掉。当前没有正常商店、扭蛋或合成方式。
