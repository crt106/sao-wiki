# I04X · 飞羽之弓

> **品质**：优越　**类型**：副武器　**物品 ID**：`I04X`　**物品等级**：28

## 实际属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +88 |
| 筋力 | +80 |
| 敏捷 | +80 |
| 体力 | +80 |

!!! warning "“精准射击 Lv1”只有说明文字"
    当前实际生效的只有攻击力 +88（技能 ID：`A014`）与全属性 +80（技能 ID：`A0TQ`）。“精准射击 Lv1”不会提供精准、命中或远程攻击加成。

## 获取方式

在 2 城武具打造中使用 [16层／鸟之羽（稀有材料）](../素材/I01I_鸟之羽（稀有材料）.md)：

1. 每次消耗 1 充能材料；
2. 成功率 50%；
3. 成功后随机获得 `I04X`、`I04Y`、`I0GW`、`I0JM` 中的 1 件。

若四种成功结果等概率，则每次打造获得本物品的概率约为 1/8（12.5%）；最终分布仍建议以长期游戏统计为准。
