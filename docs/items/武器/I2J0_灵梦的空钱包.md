# I2J0 · 灵梦的空钱包

> **品质**：特殊　**类型**：武器　**版本**：2.51 新增

## 基础属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +100 |
| 敏捷 | +100 |
| 体力 | +155 |
| 生命值上限 | +10,000 |

## 被动技能：乱扔垃圾

- 只要物品位于英雄物品栏中，就会每 **0.2 秒**尝试发射一枚追踪御符。
- 只锁定持有者周围 1,000 码内的[纯狐](../../info/楼层/隐藏与副本Boss/纯狐.md)，优先选择生命百分比最高的目标。
- 御符命中造成 **（当前体力 + 当前敏捷）×1** 的混乱／通用伤害。
- 持有者死亡或卸下钱包时，在途御符会立即消失；复活后若仍持有，发射会自动恢复。
- 与[灵梦的钱包（有钱了！）](I2J1_灵梦的钱包（有钱了！）.md)同时携带时，强化版优先，每个 0.2 秒周期最多发射一枚御符。

## 获取与打造

- 击败[博丽灵梦](../../info/楼层/隐藏与副本Boss/index.md#reimu)时固定掉落。
- 与[大块的金币](../素材/I2J2_大块的金币.md)通过宠物打造，可合成为[灵梦的钱包（有钱了！）](I2J1_灵梦的钱包（有钱了！）.md)。

!!! note "专用目标"
    空钱包的常规用途只针对纯狐，不会自动攻击其他敌人。若被 75 层团长夺取并装备，目标规则才会反转为玩家阵营单位。
