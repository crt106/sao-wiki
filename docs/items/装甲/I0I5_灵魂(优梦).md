# I0I5 · 灵魂（优梦）

> **品质**：灵魂（Earl's 物品等级）　**类型**：装甲

> **2.5 复核结论**：旧页把“遗忘的记忆”写成持续 5 秒，实际只持续 3 秒；所有持有者共用 3 秒触发间隔，多人同时使用时会互相阻塞。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +80 |
| 敏捷 | +80 |
| 智力 | +80 |
| 闪避率 | +45% |
| 生命值上限 | +10000 |

## 被动效果

### 恒温

持有者同时位于寒冷生命扣减与炎热魔法扣减的豁免范围中，不受两类区域环境惩罚。

### 负面免疫

持有者受到伤害后会：

- 移除全部负面魔法效果；
- 清理 Boss 连续控制类状态。

这是受伤后的持续清理，不是对所有负面状态的前置拦截。

### 遗忘的记忆

持有者施放任意技能时：

1. 筋力增加 80；
2. 等待 3 秒；
3. 移除这 80 点筋力。

同队多名玩家持有本物品时无法同时触发，前一次强化结束后才能再次生效；旧说明中的 5 秒并非实际持续时间。

### 抵抗

物品带有 `A1E6`，持有者免疫51～60层的藤蔓影响。

## 获取方式

击败 Lv30 天空龙（单位 ID：`njgb`）时，**必定掉落 1 件** `I0I5`。
