# I0I0 · 巨牙大棒

> **品质**：普通　**类型**：副武器（棒类）　**物品 ID**：`I0I0`　**打造等级**：33

## 实际属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +2,500 |
| 筋力 | +145 |
| 生命值上限 | +8,000 |

## 获取方式

拾取 [3 城商店武器打造](../特殊/I0DC_3城商店武器打造.md)时，背包需要持有 [33 层巨蜥的大牙](../素材/I07O_33层巨蜥的大牙.md)：

1. 每次打造无论成功或失败都消耗大牙 1 充能；
2. 成功率为 **50%**；
3. 成功后随机获得 `I0I0`、`I0IB`、`I0IN` 中的 1 件。

若三种成功结果等概率，则每次打造获得本物品的概率约为 1/6（16.67%）；最终分布仍建议以长期游戏统计为准。
