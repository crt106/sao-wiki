# I0N6 · 火花之冠·提升◆

> **品质**：优越　**类型**：头部道具　**物品 ID**：`I0N6`

!!! info "属性按成品属性计算"
    旧页把“基础值”和“追加值”并排写出，容易误读为只提供基础部分。引擎实际加载的是本阶成品自己的能力，以下为最终总值。

## 基础属性

| 属性 | 实际总值 |
|---|---:|
| 筋力 | +65 |
| 敏捷 | +90 |
| 体力 | +65 |
| 生命值上限 | +2,600 |

## 获取方式

在打铁妹处使用“打造”能力 `A0Y9`，背包持有[火花之冠·提升](I0N5_火花之冠_提升.md)时：

`I0N5 → I0N6`

升级时会移除前一阶并获得本阶，没有额外材料、金币成本或失败概率。物品标注的金币价格不代表可以在商店购买。

## 继续提升

再次使用同一打造能力可将本物品必定替换为[火花之冠·提升◆◆](I0N8_火花之冠_提升◆◆.md)：

`I0N6 → I0N8`
