# 公会：命运之夜（CD）

**主属性**：智力 · **英雄 ID**：`O001`

> 单位名（物编）：`|cffff0000公会:命运之夜(four*king)|r`，自定义名「CD」。
> 招式取自《刀剑神域》风格的连斩演出，是一名以高频普攻、爆发连击为核心的近战智力英雄。

## 基础属性

| 属性 | 初始值 | 每级成长 |
|------|--------|---------|
| 力量 | 20 | +1.0 |
| 敏捷 | 20 | +1.0 |
| 智力（主） | 20 | +1.0 |

## 技能

???+ abstract "Q · 切割（炎斩）　冷却：5秒　魔耗：10　3级解锁"

    *技能ID：A0ED*

    对**单体目标**造成一次斩击伤害。施放时内部会掷骰决定斩击属性，但**当前版本掷骰固定为 1**（源码 `GetRandomInt(1, 1)`），因此实战中**只会触发「炎斩 / 爆炎斩」分支**，其余属性分支为不可达的残留代码：

    - **炎斩**（默认）：造成 **力量 × 8** 的混乱伤害（伤害类型为神圣 `DAMAGE_TYPE_DIVINE`，攻击类型为 `ATTACK_TYPE_CHAOS` 混乱、无视护甲）。
    - **爆炎斩**（持有专属物品「灵魂（鸢）」`I0LK` 时）：伤害升级为 **(力量 + 敏捷 + 智力) × 8**，即**全属性和 × 8** 的混乱/神圣伤害，并附加 `A-Bomb` 爆炸特效。

    !!! warning "描述与实测差异"
        - 技能 Ubertip 写「对敌人造成 x8 的力量伤害」，与无专属时一致；但**持有 `I0LK` 时实际为全属性和 ×8**，提示文字未体现这一升级。
        - 源码中还写有「雷斩（敏捷×8/×4）、水斩（智力×4）、黑暗斩（固定 300）、暴风（全属性×2 + 击退）」等分支，分别对应专属物品 `I0HA`、`I0M5` 等；但由于掷骰被锁定为 1，**这些分支当前完全无法触发**，请勿当作现状理解。

???+ abstract "W · 影子　冷却：35秒　魔耗：100　10级解锁"

    *技能ID：A0EE*

    在自身位置生成一个**镜像分身**（基于魔法免疫镜像 `AOmi`）。分身**没有任何技能**，**输出为本体的 50%**（能力 `DataB = 0.5`），持续 **180 秒（3 分钟）**，魔耗 **100**。

    !!! warning "描述与实测差异"
        Ubertip 写「攻击力和防御力也只有自己的一半」，但能力数值中只有「施加伤害 = 50%」（`DataB = 0.5`）成立；「所受伤害」`DataC = 1.0`，即分身**承受 100% 伤害、并非半血/半防御**。提示文字的「防御力一半」未在数值中体现。

!!! note "E（15 级槽位）为空"
    在 `hero_ability_registry.j` 的登记行中，CD 的技能槽顺序为 Q(3级)=切割、W(10级)=影子、**E(15级)=空**、R(20级)=疯狂幻想、F(35级)=狮子之弹。第 15 级技能槽未绑定任何技能，因此 CD **没有 E 技能**。

???+ abstract "R · 疯狂幻想　冷却：42秒　魔耗：0　20级解锁"

    *技能ID：A0EF*

    指定单体目标，进入**持续性连击演出**（释放期间本体被锁定，*请小心被打断*）。施放时本体短暂定身、播放攻击前摇，随后分两段持续输出：

    - **第一阶段（约 28 段）**：以约每 0.01 秒递进的节奏对目标连续普攻，每段造成 **敏捷 × 5** 的混乱/全能伤害（`DAMAGE_TYPE_UNIVERSAL`）。随着段数累积攻击节奏不断加快，并叠加镜头噪声/梦境滤镜的演出效果，本体在出手瞬间短暂无敌。
    - **第二阶段（约 24 段）**：完成第一阶段后，本体动画加速并衔接终结连段，每段造成 **(力量 + 敏捷 + 智力) × 7**，即**全属性和 × 7** 的混乱/全能伤害，伴随大量斩击与火山特效。

    若目标中途死亡、本体死亡或施法被打断，连击会提前中止。

    !!! warning "描述与实测差异"
        Ubertip 写「CD 时间 50」，而物编 `Cool = 42.0`，**实际冷却为 42 秒**。段数（约 28 + 24）来自源码计数阈值，与提示文字未明确给出的数值一致以源码为准。

???+ abstract "F · 狮子之弹　冷却：被动　35级解锁"

    *技能ID：A0EI*

    被动强化普攻，效果由能力数值直接提供：

    - **30% 概率暴击**，暴击伤害为 **×3.5**（源码 `DataA = 30`、`DataB = 3.5`）。
    - **20% 概率闪避**敌方攻击（`DataD = 0.2`）。

    !!! warning "描述与实测差异"
        旧 Wiki 与部分提示写「每次普攻额外造成 力量 × 5 毁灭伤害」。源码中确有这段逻辑（`Trig_CD6`：`力量 × 5` 毁灭伤害），但该触发器**初始化时即被 `DisableTrigger` 禁用**，且其判定单位绑定的是 `gg_unit_Nsjs_0707`（时崎狂三的实例，并非 CD）。**因此该额外毁灭伤害在当前版本对 CD 完全不生效**，狮子之弹实际只提供暴击与闪避。

???+ abstract "D · 精神分裂　冷却：25秒　初始自带"

    *技能ID：A0EC*

    自我强化状态，持续 **7 秒**。激活后**攻击速度 +100%**（`DataB = 1.0`），同时**受到的伤害提高、并无视物理攻击**（按 Ubertip 描述为受伤 +50%）。适合配合 E「疯狂幻想」的连击节奏打出爆发，但开启期间承伤变高，需注意自身生存。

    !!! warning "描述与实测差异"
        D 技能未出现在 `hero_ability_registry.j` 的技能槽登记行中，而是直接写在单位 `abilList`（`A0EE,A0ED,A0EC,A0EF,...` 中的 `A0EC`），属初始自带技能位；其承伤增幅数值取自 Ubertip（物编 `DataC = -0.1` 含义不明），建议以游戏内实测为准。

## 专属装备

CD 的 Q「切割」对专属物品做了运行时背包检测：

- 持有**灵魂（鸢）** `I0LK`（物编名 `|cff3399ff灵魂|r|cff6495ed(鸢)|r`）时，Q 由「炎斩（力量×8）」升级为「爆炎斩（全属性和×8）」。

> 源码中 Q 还检测了 `I0HA`、`I0M5` 等其它专属物品以切换雷斩/水斩等属性，但由于属性掷骰被锁定为 1，这些检测在当前版本不会被命中，实际只有 `I0LK` 对 Q 产生可见影响。
