# I09C · 绝迹（传说）

> **品质**：传说　**类型**：副武器　**物品 ID**：`I09C`　**实际物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +700 |
| 筋力 | +110 |
| 攻击速度 | +100% |

## 歼灭绝杀

持有本物品的单位每次使用技能或道具时，会对自身周围 350 范围内存活的敌方非建筑单位造成：

`当前筋力（含加成） × 3`

伤害使用混乱攻击类型与通用伤害类型，没有独立冷却；使用技能或道具都会触发。

## 获取方式

击败固定 Boss“Lv24: Soul Reaper”（单位 ID：`npfm`）时，必定掉落 1 件 `I09C`。
