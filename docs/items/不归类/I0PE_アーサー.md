# I0PE · アーサー

> **品质**：不归类 · **物品等级**：82 · **定位**：相羽六专属武器

## 基础属性

| 属性 | 数值 | 技能 ID |
|------|-----:|----------|
| 力量 | +300 | `A1FN` |
| 敏捷 | +300 | `A1FN` |
| 智力／体力 | +300 | `A1FN` |
| 攻击速度 | +200% | `A0SR` |
| 最大生命值 | +30000 | `A1FL` |

物品描述中的“魔法粒子”“魔法阵形态”没有独立主动效果；专属加成体现在相羽六的技能公式中。

## 专属限制

只有相羽六（英雄 ID：`Ofar`）可以正常持有；其他英雄拾取后，物品会被移出背包。

## 相羽六技能联动

=== "2.5（狂猎）当前版"

    | 技能 | 无专属 | 持有アーサー |
    |------|--------|--------------|
    | Q 魔法回避 | 单段敏捷×10；战意≥1时×27 | 单段×27；战意≥1时×44 |
    | W 闪雷连射 | 每发固定值＋敏捷×82 | 每发固定值＋敏捷×99 |
    | E 魔法刻印 | 敏捷×战意×3.4 | 不变 |
    | R 雷神惩戒 | 每跳敏捷×随机系数（10～24） | 每跳敏捷×随机系数（27～41） |
    | T 神枪天际 | 两个基础段各×204；追加（战意+20）×3.4 | 三个组成段分别增加17 |

    Q 的战意增量与专属增量各为 +17。T 的“分别增加17”是指外圈基础、内圈第二基础和内圈追加三个组成段各加17，内圈总增量为敏捷×51。

    !!! note "W 首次施法缺陷"
        每局首次施放 W 时，敏捷与本物品加成通常不会正常计入；后续施放才大多恢复。物品页的系数表是正常分支数值，不代表首次施法一定达到该值。

## 获取方式

击败“★★★★Lv70：（王珏）★★★★”（单位 ID：`n02B`）时，必定掉落一件 `I0PE`，掉率为 **100%**。

王珏还会同时掉落 `I0Q3`、`I0PD`、`I0PF`、`I0FE`。当前 2.5 没有アーサー的商店、扭蛋或普通合成来源。

## 文本与实装差异

拾取提示中同时残留“技能系数+3”和“所有技能倍率在基础上增加5”两套旧文字：

- 2.41 实际增量是 +5；
- 2.5 实际增量已经调整为 +17；
- E 在两个版本都不受本物品强化；
- T 的内圈由三个组成段分别增加，而不是总伤害只加一次。
