# I03N · 鳄鱼王皮战衣

> **品质**：稀有　**类型**：装甲

> **2.5 复核结论**：旧页没有给出生命恢复实际值，也写错了 Boss 掉率。`A07J` 实际每秒恢复 40；击败 7 层 Boss 后，本物品实际必掉。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 防御值 | +5 |
| 生命值上限 | +1500 |
| 所受魔法伤害 | -22% |
| 生命恢复 | +40/秒 |

`A07J` 的能力名仍写“生命恢复20”，但实际数值为 40。

## 获取方式

有两个正常来源：

1. **7 层 Boss**：击败对应首领（单位 ID：`ncea`）后，必定掉落 1 件。
2. **指定宝物箱**：在 `I034 / I03S / I00O / I03N` 四件物品中等概率开出一件，本物品概率为 **25%**。

生命恢复的面板显示与背包满时的掉落位置仍待实际确认。
