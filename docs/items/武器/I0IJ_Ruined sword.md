# I0IJ · Ruined sword

**分类**：武器 · **品质**：传说 · **固定来源**：冰晶之地的领主

2.5把说明中的攻击力800改为700，但仍漏写攻击速度。实际属性能力与固定掉落在2.41、2.5中相同。

## 基础属性

| 属性 | 实际值 | 对应能力 |
|------|-------:|----------|
| 攻击力 | +700 | `A0QF` |
| 力量 | +200 | `A0SF` |
| 敏捷 | +200 | `A0SF` |
| 智力（物品文字称“体力”） | +200 | `A0SF` |
| 攻击速度 | +100% | `A0F2` |
| 最大生命 | +30000 | `A0VS` |

## 版本差异

=== "2.5（狂猎）当前版"

    说明已把攻击力改为 700，与 `A0QF` 一致；但仍漏写攻击速度 +100%。

=== "2.41 测试版"

    说明写攻击力800，但 `A0QF` 实际已经是+700；其他四个对应技能与2.5逐项相同。2.5是说明纠错，不是削弱。

## 获取途径

击败指定 Boss“冰晶之地的领主”（单位 ID：`n024`）时，必定掉落：

- `I0IJ` Ruined sword；
- `I0DK` [堕落天使剑](../副武器/I0DK_堕落天使剑（传说）.md)；
- `I0GV` [雷暴战甲](../装甲/I0GV_雷暴战甲.md)。

因此 `I0IJ` 是冰晶之地领主的必掉物，不是游戏说明所称的不明确“水晶深处随机爆出”。
