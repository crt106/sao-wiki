# I05V · 觉醒·灵魂（魅惑）

> **品质**：觉醒　**类型**：装甲

> **2.5 复核结论**：旧页写成“体力”，实际加成是智力；所谓“受到伤害反射”也不准确，效果会在敌人开始攻击时立即对周围全部敌人造成一次筋力伤害。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 智力 | +380 |
| 生命值上限 | +15000 |
| 防御力 | +57 |
| 所受魔法伤害 | -30% |

对应技能 ID 为 `A0LK`、`A060`、`A079`、`A0VQ`。

## 被动效果

### 恒温

持有者同时位于寒冷生命扣减和炎热魔法扣减的豁免范围中，不受两类区域环境惩罚。

### 筋力反射

当敌人对持有者发起攻击时，会立即影响持有者周围250范围：

- 命中全部存活的敌方非建筑单位；
- 每个目标受到 `持有者当前筋力 × 3` 的毁灭伤害；
- 伤害来源记为持有者。

这项范围反击在敌人开始攻击时立即生效，即使该次攻击没有命中也会触发。攻击频率越高，触发次数越多。

### 负面清理

持有者受到伤害后会移除全部普通负面魔法效果，并清理部分 Boss 连续控制状态；它是受伤后的清理，不是所有负面效果的前置免疫。

### 抵抗

持有者通过 `A1E6` 免疫51～60层藤蔓。

## 获取方式

施放打造能力 `A0Y9` 时，背包同时拥有以下三件材料会立即合成：

- [灵魂（启示者）](I09K_灵魂（启示者）.md)；
- [神秘：灵魂钻石](../素材/I0F0_神秘_灵魂钻石.md)；
- [神秘的幻彩水晶](../特殊/I09L_神秘的幻彩水晶.md)。

实际效果会移除三件材料并给予 1 件 `I05V`，没有随机失败判定。
