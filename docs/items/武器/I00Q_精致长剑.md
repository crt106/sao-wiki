# I00Q · 精致长剑

**分类**：武器 · **品质**：普通 · **物品等级**：16

旧页虽然读对了能力值，却因没有追踪按等级随机打造，把这件仍可获得的武器标成了“无法获取”。2.5只修正物品说明，真实属性在两版中相同。

## 基础属性

| 属性 | 实际值 | 对应能力 |
|------|-------:|----------|
| 攻击力 | +74 | `A012` |
| 力量（物品文字称“筋力”） | +30 | `A01V` |

## 版本差异

=== "2.5（狂猎）当前版"

    游戏说明已把攻击力从70改为74，与 `A012` 的 实际数值为 74 一致。

=== "2.41 测试版"

    2.41的说明写攻击力70，但携带的同一能力 `A012` 已经是+74；`A01V` 也同样为力量+30。2.5没有增强武器，只是把说明改成实际值。

## 获取途径

本物品可通过武器打造获得：

1. 持有1份 `I02L`（4层／狂傲的剑片）；
2. 使用任一武器打造物品 `I00H`、`I048`、`I0DC` 或 `I0MM`；
3. 打造有 `1/2` 概率成功，无论成功或失败都会消耗1份材料；
4. 成功后随机获得 `I00P`、`I00Q`、`I00S`、`I0JH` 中的 1 件。

2.5 与 2.41 的四种成功结果一致。若四种结果等概率，单次尝试获得精致长剑的概率约为 `1/2×1/4＝1/8`。物品标示价格不能单独证明存在商店来源。
