# I0J1 · 国王之冠

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0J1`

!!! warning "名义 16% 实际为必掉"
    两个现行来源都会固定掉落 `I0J1`，不是旧页所写的普通权重掉落。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +400 |
| 敏捷 | +250 |
| 体力 | +400 |

本物品没有生命、防御、主动技能或额外实际效果。

## 获取方式

击败以下任一 Boss 时，都会必定掉落 1 件 `I0J1`：

- 49 层“炙炎花园”首领（单位 ID：`nlkl`）；
- 寂静之箱（单位 ID：`nrvl`）。

旧资料中的 16% 概率并不适用于 2.5；另有一条历史掉落记录当前也不生效，不能算作第三个来源。
