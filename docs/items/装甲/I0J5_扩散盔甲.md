# I0J5 · 扩散盔甲

> **品质**：优越　**打造物品等级**：41

> **2.5 复核结论**：旧页没有还原池内概率，并把“体力恢复”误写成未量化被动；该效果实际恢复魔法值。本物品当前没有可用的主动技能。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +90 |
| 敏捷 | +90 |
| 智力 | +90 |
| 生命值上限 | +8000 |
| 每秒魔法恢复 | +20 |

## 隐藏效果：散热

持有 `I0J5` 的单位位于炎热区域豁免范围中，不受每轮 1000 点魔法扣减。

## 获取方式

使用[32 层急冻猪的皮毛](../素材/I08A_32层急冻猪的皮毛.md)打造防具：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0J5` 或 `I0J7`。

因此每次材料充能获得扩散盔甲的概率为 **1/2 × 1/2 = 1/4（25%）**。成功和失败都会消耗材料充能；游戏数据的 标注木材价格 没有对应的正常商店出售。
