# I04B · 冒险者的皮衣

> **品质**：优越　**物品等级**：物品等级 13

> **2.5 复核结论**：旧页面板值正确；本次补齐打造失败照常消耗材料充能。2.5 版本差异记录未标出本物品改动，不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 敏捷 | +50 |
| 闪避 | 15% |
| 防御值 | +8 |
| 移动速度 | +40 |

## 获取方式

在 1 城防具打造中使用[火爆野猪皮](../素材/I003_火爆野猪皮.md)：

- 成功时直接获得冒险者的皮衣；
- 成功与失败都会消耗 1 次材料充能。

因此每次材料充能的实际获得概率为 **1/2（50%）**。
