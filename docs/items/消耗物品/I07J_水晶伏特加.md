# I07J · 水晶伏特加

> **分类**：消耗物品　**售价**：3,500 金　**使用次数**：1 次

> **版本结论**：2.5 与 2.41 的游戏数据、商店和宝箱来源一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际效果

| 项目 | 实际值 |
|---|---|
| 作用目标 | 使用者自身 |
| 移动速度 | 能力 `AIsa` 提供 +50 |
| 持续时间 | 300 秒 |
| 冷却数值 | 3 秒 |

`AIsa` 的 实际数值 是移动速度**比例**数值，不是平面“移动速度 +50”。当前数值远高于标准加速卷轴的 2.0，正常情况下会被引擎最高移动速度限制，表现应接近直接达到移速上限。
