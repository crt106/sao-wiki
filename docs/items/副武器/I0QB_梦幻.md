# I0QB · 梦幻

> **品质**：传说　**类型**：副武器

**基础属性**

| 属性 | 数值 |
|---|---:|
| 生命值上限 | +20,000 |
| 筋力 / 敏捷 / 体力 | 各 +300 |
| 移动速度 | +200 |
| 魔法恢复 | +50 |

**技能效果**

| 技能 | 实际效果 |
|---|---|
| 梦幻 | 拾取时将英雄攻击间隔直接减少 0.5；丢弃时恢复 0.5。 |
| 噬魂 | 每次普通攻击额外造成“攻击者最大生命值 × 5%”的混乱伤害，并恢复该追加伤害 50% 的生命；追加伤害不会再次触发自身。 |

- **获取**：宠物打造合成——[随身佳肴](../不归类/I0MC_随身佳肴.md) + [BUG化·结晶](../特殊/I0K2_BUG化·结晶.md) + [九天凤凰琴](I0O5_九天凤凰琴.md)。
- **配方**：`I0MC` + `I0K2` + `I0O5` → `I0QB`。
