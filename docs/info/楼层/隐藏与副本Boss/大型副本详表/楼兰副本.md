# 楼兰副本

> 楼兰副本分为前院与后院两个大型连战区域。击败当前一组 Boss 后，下一组敌人才会出现。

!!! info "2.5 复核口径"
    王珏、琳与梦岚离的旧页都漏掉了实际掉落；下列清单按 2.5 当前有效奖励重建。

## 副本流程

- **楼兰前院第一波**：梦岚离 / 琳 / 王珏同时存在。三者全部击杀后，等待约 60 秒刷新第二波。
- **楼兰前院第二波**：沁 / 栖 / 婳同时刷新，分别掉落三把仙剑。
- **楼兰后院第一波**：月神 / 朱雀同时存在。二者全部击杀后，等待约 60 秒刷新白 Saber。
- **楼兰后院终战**：白 Saber 首次被打到致死会进入变身流程，约 5 秒后满血转入黑化形态；真正的最终掉落来自黑化形态。
