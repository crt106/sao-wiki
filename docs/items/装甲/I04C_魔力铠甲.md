# I04C · 魔力铠甲

> **品质**：稀有　**类型**：装甲

> **2.5 复核结论**：旧页把 标注金币价格 展示成售价，但地图没有对应商店库存；唯一正常来源是一层 Boss 的独立 14% 掉落。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 智力 | +35 |
| 生命值上限 | +1500 |
| 防御值 | +23 |
| 移动速度 | +30 |

游戏旧文案把智力属性称为“体力”，这里统一使用 Warcraft 实际属性名。

## 获取方式

击败一层 Boss（单位 ID：`nanw`）时，魔力铠甲有 **14%** 概率掉落；其他物品的掉落不会降低这一概率。当前没有商店购买来源。
