# I0FF · 花骑的战衣

> **品质**：传说　**类型**：装甲

> **2.5 复核结论**：旧页只写“Boss/宝箱权重 34%”，没有指出唯一有效入口是固定金色宝箱。当前三项权重总和为 100，本物品概率可精确写成 34%。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +90 |
| 敏捷 | +90 |
| 智力 | +90 |
| 生命值上限 | +10000 |

## 隐藏效果

**御寒**：寒冷区域每 3 秒会对未获豁免的单位造成 1000 点自伤；持有 `I0FF` 的单位可获得对应豁免，不受这笔环境伤害。

## 获取方式

指定一只 `nrvs` 金色宝箱绑定一次性掉落表：

| 物品 | 权重 |
|---|---:|
| `I0FF` | 34 |
| `I09F` | 33 |
| `I03S` | 33 |

权重总和为 100，因此箱子首次死亡时获得花骑的战衣的概率为 **34%**；实际效果随后移除。当前没有第二个 Boss、商店、打造或合成来源。
