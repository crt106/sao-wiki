# I0GX · 变异剑

> **品质**：劣质　**类型**：副武器（剑类）　**物品 ID**：`I0GX`　**有效物品等级**：18

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +100 |
| 敏捷 | +58 |
| 生命值上限 | +500 |

## 获取方式

### 地图宝箱

地图中的一只宝物箱（单位 ID：`ndrv`）固定提供 1 件变异剑。

### 1 城武器打造

使用 [I03J · 7层鳄鱼牙齿](../素材/I03J_7层鳄鱼牙齿.md)打造，成功率为 50%；无论成功或失败，都会消耗 1 次材料使用次数。成功后会随机获得 `I06M` 或 `I0GX`。

若两种成功结果等概率，则每次打造获得变异剑的概率约为 25%；最终分布仍建议以长期游戏统计为准。
