# I06M · 鳄鱼牙剑

> **品质**：劣质　**类型**：副武器　**物品 ID**：`I06M`　**物品等级**：18

## 实际属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +100 |
| 筋力 | +40 |
| 生命值上限 | +800 |

## 获取方式

!!! warning "旧页写错了打造材料"
    正确材料是 [7层／鳄鱼牙齿](../素材/I03J_7层鳄鱼牙齿.md)，不是旧页所写的鳄鱼尖爪 `I03L`；使用尖爪无法获得本物品。

在 1 城武器打造中：

1. 每次消耗鳄鱼牙齿 1 充能；
2. 成功率 50%；
3. 成功后随机获得 `I06M` 或 `I0GX`。

若两种成功结果等概率，则每次打造获得本物品的概率约为 25%；最终分布仍建议以长期游戏统计为准。
