# I0EL · 超电磁炮

> **类别**：头部道具　**品质**：礼物　**专属英雄**：[御坂美琴](../../heroes/御坂美琴.md)

## 基础属性

| 属性 | 数值 | 实际能力 |
|------|------|----------|
| 筋力 | +50 | `A0FW` |
| 敏捷 | +50 | `A0FW` |
| 体力 | +50 | `A0FW` |
| 生命值上限 | +1500 | `A0H2` |

`A0FW` 提供力量、敏捷、智力各 +50，`A0H2` 提供生命值上限 +1500。物品没有额外主动技能。

## 英雄联动

游戏内文字把它标记给[御坂美琴](../../heroes/御坂美琴.md)，但2.5与2.41中都不会强化[御坂美琴](../../heroes/御坂美琴.md)的技能；“专属”当前只是物品标签，实际只有上述通用属性。

旧资料把御坂技能与 `I093` 关联，但 `I093` 实际是[琴里的发饰](../不归类/I093_琴里的发饰（专属道具，不归类）.md)；`I0EL` 当前没有对应的御坂技能强化。

## 获取方式

本物品不是商店商品、合成产物或 Boss 掉落。

[I0KV · 外物补给品1](../特殊/I0KV_外物补给品1.md) 被指定玩家的英雄拾取时，会给予 `I0EL`。它属于**每局一次的指定玩家礼物**。

## 版本状态

2.41 与当前 2.5 的物品属性、技能效果和获取方式没有明确差异，因此本页不拆分版本 Tab。
