# I09M · 死树之矛（稀有）

> **品质**：稀有　**类型**：副武器（长矛）　**物品 ID**：`I09M`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +300 |
| 筋力 | +102 |
| 生命值上限 | +2,500 |
| 每秒生命恢复 | +60 |

旧页只写了“生命恢复 Lv3”，当前能力 `A07M` 的实际恢复值为每秒 60。

## 获取方式

旧资料曾把 15 层 Boss（单位 ID：`nenc`）列为 20% 掉落来源，但该 Boss 在 2.5 中实际不会掉落本物品。当前版本没有正常获取方式。

因此按 2.5 当前版本的正常流程，**死树之矛无法获取**。
