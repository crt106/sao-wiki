# I0F4 · 偷悦者

> **品质**：传说　**类型**：副武器（剑）　**物品 ID**：`I0F4`　**实际物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +1,200 |
| 筋力 | +150 |
| 敏捷 | +150 |
| 生命值上限 | +5,000 |

## 被动效果

### 隔绝斩击 Lv3

普通攻击对主目标周围 250 范围内的地面敌方或中立单位造成 20% 分裂伤害。游戏数据旧说明仍写 25%，实际应以 实际数值为 0.20 为准。

### 歼灭绝杀

持有者每次使用技能或道具时，对自身350范围内存活的敌方非建筑单位造成：

`当前筋力（含加成） × 3`

伤害使用混乱攻击类型与通用伤害类型，没有独立冷却。

## 获取方式

击败固定 Boss“Lv58: 前奏曲·狼神”（单位 ID：`nmam`）时，必定掉落 1 件 `I0F4`。
