# I0KY · 命运之枪·刚格尔尼

> **品质**：礼物　**类型**：武器　**物品 ID**：`I0KY`

## 属性与物品自带能力

### 物品直接持有效果

| 效果 | 可实际值 | 能力 ID |
|------|---------:|---------|
| 力量 | +50 | `A0FW` |
| 敏捷 | +50 | `A0FW` |
| 智力 | +50 | `A0FW` |
| 致命一击 | 50%概率造成3倍攻击伤害 | `A10C` |
| 闪避 | 1% | `A10C` |
| 主动无敌 | 3秒，冷却15秒 | `A0O8` |

旧页把 `A0O8` 只写成“驱散恐惧”，但实际使用后会无敌 3 秒。

### 订制身份拾取附加

授权英雄拾取时，实际效果还会添加：

| 效果 | 可实际值 | 能力 ID |
|------|---------:|---------|
| 攻击力 | +500 | `A10A` |
| 攻击速度 | +50% | `A07Y` |
| 魔法伤害减免 | 50% | `A0BT` |

当前确认效果为 **全属性各+50**；是否可能显示为+100仍需在游戏内查看面板确认。

!!! warning "“魔法防御 +50”不是固定点数"
    说明文字写“魔法防御 50”，实际能力数值 实际数值为 0.5，含义是 **50% 魔法伤害减免**。

## 通用被动

### 普通伤害吸血

普通伤害吸血比例为 **30%**，恢复量按本次伤害的 30% 计算，不是旧页写的“力量×0.3”。

若同时携带多件吸血物品，只取其中最高比例，不会把各件比例相加；治疗还受最大生命上限限制。

### 攻击发起回复

持有 `I0KY` 或 `I0L6` 的英雄发起攻击时，立即恢复：

- 生命：当前力量×1
- 魔法：当前力量×1

该回复在攻击开始时生效，不要求本次普通攻击已经命中。效果约有 0.1 秒的多人共享间隔，因此多个持有者同时攻击时可能漏掉一次回复。

## 蕾米莉亚联动

[蕾米莉亚·斯卡雷特](../../heroes/蕾米莉亚_斯卡雷特.md)持有本物品时，W 的生命与魔法恢复获得强化：

- 无本物品：生命与魔法各回复力量×2；
- 持有本物品：生命与魔法各回复力量×4。

该联动适用于英雄 ID 为 `Ewar` 且持有本物品的蕾米莉亚。它与上面的攻击发起回复是两条独立效果。

## 获取方式

唯一确认来源是订制补给流程：

1. 英雄自动使用“外物补给品3”`I0KW`；
2. 英雄所有者必须匹配两名指定订制玩家之一；
3. 本局尚未领取过该奖励；
4. 成功后计数减为 0，并向该英雄发放 1 件 `I0KY`。

未授权英雄无法持有 `I0KY` 或升级品 `I0L6`。

当前版本没有发现本物品的 Boss 掉落、商店上架、扭蛋或普通合成产出。

## 合成用途

`I0KY ×1 + I0L7 ×1 → I0L6`

- 材料：[解放-神枪（I0L7）](../特殊/I0L7_解放-神枪.md)
- 产物：[命运魔枪·刚格尔尼（I0L6）](I0L6_命运魔枪·刚格尔尼.md)

## 使用限制

物品按**玩家订制身份**授权，不按英雄 ID 授权。只有指定玩家的英雄属于正常可用范围。

2.5 与 2.41 的物品本身、30%吸血、订制发放、攻击发起回复、W 联动和合成公式一致。
