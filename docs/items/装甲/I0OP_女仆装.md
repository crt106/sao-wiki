# I0OP · 女仆装

> **品质**：传闻　**类型**：装甲

> **2.5 复核结论**：旧页写成“减少 15% 伤害”，但结算机制对同一物品先乘 `0.85`、随后又乘 `0.7`，实际承伤比例为 `0.595`，即总减伤 **40.5%**。来源也不是八重樱，而是六号 Boss 触手怪。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +220 |
| 敏捷 | +220 |
| 智力 | +220 |
| 生命值上限 | +15000 |
| 防御力 | +150 |
| 每秒生命恢复 | +200 |

能力名仍写“生命恢复 100”，但实际数值为 200。

## 被动效果

### 精美女仆装

**伤害 × 0.85 × 0.7 = 伤害 × 0.595**

因此单独持有女仆装时，实际受到的伤害为原值的 **59.5%**，即总减伤 **40.5%**，不是文本所写的 15%。该效果还会与其他减伤继续相乘。

### 负面清理

持有者受到伤害后会移除全部普通负面魔法效果，并清理部分 Boss 连续控制状态。它是受伤后的清理，不是所有负面效果的前置免疫。

物品可以点击使用，但当前没有可确认的主动效果。

## 获取方式

击败六号 Boss 触手怪（单位 ID：`n04M`）时，必定掉落 1 件 `I0OP`。旧页所写的 `n04T` 八重樱不是本物品来源。
