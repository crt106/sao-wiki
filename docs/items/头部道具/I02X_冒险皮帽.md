# I02X · 冒险皮帽

> **品质**：普通　**类型**：头部道具　**物品 ID**：`I02X`

!!! info "2.5 重审结论"
    旧页把本物品写成商店货，但当前没有对应商店库存。实际来源是以“13、14层／黑与白的树皮”进行防具打造；单次尝试获得本物品的总概率为 25%。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +55 |
| 敏捷 | +85 |
| 生命值上限 | +1,800 |

本物品只提供上表属性，没有主动技能或额外效果。

## 获取方式

使用[13、14层／黑与白的树皮](../素材/I056_13.14层黑与白的树皮.md)打造防具：

1. 打造成功率为 `1/2`；
2. 成功后再以 `1/2` 概率产出冒险皮帽，另 `1/2` 产出[巫师之衣](../装甲/I04W_巫师之衣.md)；
3. 失败时不产出物品；
4. 无论成功还是失败，都会消耗 1 次材料。

因此每次尝试的实际结果为：

- 冒险皮帽：`1/2 × 1/2 = 1/4`，即 **25%**；
- 巫师之衣：**25%**；
- 无产物：**50%**。

物品标示价格不是购买价格；当前版本没有正常商店、扭蛋或固定掉落方式。
