# I00O · 精致战斗服

> **品质**：普通　**物品等级**：物品等级 14

> **2.5 复核结论**：物品说明写闪避 15%，但 `A06V` 的实际数值是 13%；旧页采用 13% 是正确的。本次补齐两个独立获取方式及其概率，不拆版本 Tab。

| 属性 | 数值 |
|---|---:|

## 获取方式

有两个正常入口：

1. **防具打造**：使用[夜狼的细毛皮](../素材/I00W_夜狼的细毛皮.md)，每次材料充能有 **1/2（50%）** 概率直接获得，失败也消耗充能。
2. **固定宝箱**：地图中的一只指定 `ndrv` 宝物箱在首次死亡时，从 `I034 / I03S / I00O / I03N` 四件物品中按相同权重选一件，本物品概率为 **1/4（25%）**；该掉落触发随后移除，只执行一次。
