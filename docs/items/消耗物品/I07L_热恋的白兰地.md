# I07L · 热恋的白兰地

> **分类**：消耗物品　**购买价**：5,000 金　**充能**：1 次

> **版本结论**：2.5 与 2.41 的游戏数据一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际效果

使用 `A0VW` 后立即恢复自身 5,000 点生命值。游戏内说明中的“无限制时间”不是持续恢复机制；实际能力是一次性即时治疗。

技能冷却为 20 秒，但物品本身只有 1 次使用次数，正常单件使用时不会再次施放。

## 获取方式

共有三处商店出售：

- `orai`：工会“命运之夜”玩家商店；
- `h03X`：玩家（酒保）：雄；
- `h06Q`：玩家（酒保）：雄。

三处价格均为 5,000 金。
