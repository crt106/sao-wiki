# I0Q9 · 王女之冠

> **品质**：传说　**类型**：头部道具

## 基础属性

| 属性 | 数值 |
|---|---:|
| 生命值上限 | +30,000 |
| 攻击力 | +8,000 |
| 攻击速度 | +120% |
| 护甲 | +100 |
| 筋力 / 敏捷 / 体力 | 各 +150 |

## 技能效果

| 技能 | 实际效果 |
|---|---|
| 不屈意志 | 冷却就绪时，受到任意一笔正伤害都会将该伤害清零并把生命设为1；随后无敌并暂停3秒，结束后回满。60秒冷却从保护结束后开始，触发间隔约63秒。 |
| 越战越勇 | 每次普通攻击增加 1 层，每层 +1,000 攻击力，最多 10 层（+10,000）；连续 5 秒没有普通攻击则清空。 |
| 沐浴鲜血 | 普通伤害吸血 30%；多件吸血物品同时存在时，通用吸血系统取最高比例而非相加。 |

!!! warning "不屈意志没有致死判断"
    该效果不比较本次伤害与当前生命，只要冷却结束后受到一笔正伤害就会触发。“致死保护”只是说明中的名称，并不要求伤害足以致死；极端旁路伤害也不保证触发。

!!! info "与[行于流逝的岸](../不归类/I0Q3_行于流逝的岸.md)同时持有"
    2.52 起，两件物品共享一次保护竞争窗口。两项保护都可用时优先触发王女之冠；[行于流逝的岸](../不归类/I0Q3_行于流逝的岸.md)不会被一并消耗，仍可在后续伤害中触发。王女之冠的 3 秒暂停演出期间，嵌套伤害也不能抢先触发另一件物品。若王女之冠仍在冷却而[行于流逝的岸](../不归类/I0Q3_行于流逝的岸.md)已经就绪，则由后者触发。
