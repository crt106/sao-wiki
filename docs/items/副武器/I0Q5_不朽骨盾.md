# I0Q5 · 不朽骨盾

> **品质**：传说　**类型**：副武器　**物品 ID**：`I0Q5`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +4,000 |
| 防御力 | +150 |
| 魔法伤害减免 | 30% |
| 生命值上限 | +15,000 |

## 被动效果：荆刺的实际目标错误

持有者承受低于 999,999 的正伤害时，会再受到一笔等于原伤害 10% 的混乱／毁灭伤害。目标仍然是**持盾者本人**，并不是原攻击者，因此当前版本不是 10% 反伤。“最高 500,000”的限制实际也不会生效。

这笔附加自伤是否会再次触发同类效果仍待确认；当前版本不能把旧说明当作已生效反伤。

## 主动技能：暴君敕令

主动能力 `A1MF` 冷却 60 秒：

1. 持续 3 秒把进入伤害系统的原始伤害累加到持有者自己的吸收槽，并把对应伤害清零；
2. 结束时取累计值的 10%，上限 500,000；
3. 对持有者周围 450 范围每个存活敌人分别造成该数值的混乱／毁灭伤害。

达到 500,000 释放上限需要累计吸收至少 5,000,000。被动自伤当前效果位于吸收清零之前，两者的嵌套交互尤其需要实际游戏验证。

## 获取方式

72 层 `nwzr` 死亡时与 [I0Q4 · 骷髅帝王剑](I0Q4_骷髅帝王剑.md) 二选一，各 50%，每次只创建一件。
