# I042 · 竞技的邀请函

> **分类**：消耗物品　**标示价格**：500 金　**库存上限**：3

> **版本结论**：2.5 与 2.41 的游戏数据和竞技实际效果一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际功能

`A0VB` 对另一名英雄发出竞技邀请：

1. 目标必须是正在游戏的真人玩家英雄；
2. 目标等级必须达到 60；
3. 目标不能已经处于竞技区域中心 2,500 范围内；
4. 对方同意后，双方分别传送到两个竞技出生点，互相改为敌对并获得竞技保护能力；
5. 一方死亡后判定胜负、复活败方、传回主城并恢复联盟。

竞技期间，所有玩家的 `A0VB` 都会暂时关闭；同一时间只会进行一场竞技。

## 获取方式

当前没有商店、掉落、合成、扭蛋或其他正常获取来源。旧页“商店购买”的结论错误；`I042` 在正常流程中无法获取。
