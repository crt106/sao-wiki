> **品质**：传说　**类型**：装备道具

**基础属性**

| 属性 | 数值 |
|---|---:|
| 生命值上限 | +20,000 |
| 攻击力 | +10,000 |
| 筋力 / 敏捷 / 体力 | 各 +150 |
| 魔法恢复 | +50 |

**技能效果**

| 技能 | 实际效果 |
|---|---|
| 禁忌 | 系统每 0.5 秒按英雄当前筋力、敏捷、体力之和重新计算绿字攻击力，数值为 `全属性总和 × 10`；丢弃戒指后移除该动态加成。 |
| 瞬间加速 | 沿当前面向快速移动 700 码；该位移不附带无敌，冷却 12 秒。 |
