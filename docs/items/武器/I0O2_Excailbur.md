# I0O2 · Excailbur

> **品质**：传闻　**类型**：武器　**物品 ID**：`I0O2`

!!! info "本次重审结论"
    2.5 将物品说明中的生命值 35000 修正为 30000，并把 Saber 专属宝具从全属性×100调整为×6。旧 Wiki 还漏掉了 10% 攻击增幅、持续双回复和免死冷却异常，并误把“攻速120”与“3秒免伤主动”写成有效效果；本页已经统一修正。

## 版本差异

=== "2.5（狂猎）当前版"

    - 实际基础属性：全属性各 +333、最大生命值 +30000。
    - Saber 宝具：`当前全属性之和 × 6`。
    - 物品说明已把生命值 35000 改成 30000，但“攻速120”当前并不生效。
    - 拾取提示仍写宝具“全属性×100、前方550”，已经过时。

    !!! warning "旧说明中的×7也不是实际值"
        宝具旧调整说明写从×100改为×7，实际效果紧接着赋值为 **×6**。

=== "2.41 测试版"

    - 实际基础属性同样是全属性各 +333、最大生命值 +30000。
    - Saber 宝具为 `当前全属性之和 × 100`。
    - 物品说明写最大生命值 +35000，但 `A19E` 两版都只提供 +30000；这是说明错误，不是 2.5 对生命能力的削弱。

    物品主动、周期回复和致命保护与 2.5 相同，包括下文“免死通常只能触发一次”的问题。

| ------ | ---------: |
| 力量 | +333 |

对应技能 ID 为 `A19F`、`A0TS`、`A19E`。显示文字中的“攻速 120”实际不生效，不能计入属性。

## 技能效果

### 主动 · A19F

`I0O2` 可主动使用，对应技能 ID 为 `A19F`。当前效果是攻击增幅，而不是伤害免疫：

| 参数 | 实际值 |
|------|--------|
| 攻击伤害增幅 | 10% |
| 持续时间 | 3 秒 |
| 冷却 | 60 秒 |
| 作用范围 | 500 |
| 可影响目标 | 地面、空中、自身 |

因此游戏内查询所写“阿瓦隆：免疫受到伤害 3 秒”与当前实际效果不符。实际受益单位范围和冷却显示仍待游戏内确认。

### 周期恢复

任意持有者都会约每 **1.1 秒**获得一次恢复：

- 回复最大生命值的 1%；
- 回复最大魔法值的 1%；
- 结算后计数归零。

这不是说明文字中的每秒固定恢复，也不限定 Saber。丢弃再重新拾取后，恢复间隔可能沿用丢弃前的进度。

### 致命保护

任意持有者承受致命伤害时，实际效果会：

1. 将本次伤害改成 0，并把生命锁到 1；
2. 设为无敌和暂停；
3. 通过 `A1A2` 在3秒内恢复共500000生命；
4. 约 3 秒后解除无敌与暂停。

这不是直接把生命设置为最大值。最大生命不超过500000且恢复正常生效时通常会回满；更高生命、恢复被覆盖或辅助施法失败时不保证满血。

!!! danger "显示120秒，实际整场只能触发一次"
    每个英雄单位通常只能触发一次免死。即使等待超过 120 秒、丢弃再拾取或正常复活，也无法再次触发；因此它不是可循环使用的 120 秒冷却效果。

    同一笔致命伤害若已被更高优先级机制改成0，当前效果仍可能继续走到圣剑分支并消耗这次唯一机会；多免死物品的优先级仍待实际确认。

### Saber 专属宝具

只有 Saber（单位 ID：`Ogld`）持有本物品时，发起攻击才有机会发动宝具：

- 触发概率：**16/101，约 15.84%**；
- 内置冷却：成功触发后 20 秒；
- 方向：从 Saber 指向本次被攻击单位的当时坐标；
- 路径：前方 100～1300，每隔 100 建立一个判定中心，共 13 个；
- 每个中心半径：250；
- 同一敌人跨多个中心只受伤一次；
- 攻击／伤害类型：混乱／通用。

| 版本 | 每个敌人的宝具伤害 |
|------|--------------------|
| 2.5 | `当前力量＋当前敏捷＋当前智力` 的总和再乘 6 |
| 2.41 | `当前力量＋当前敏捷＋当前智力` 的总和再乘 100 |

宝具在攻击发起时判断，不要求普通攻击已经命中。实际13个圆的中心延伸到1300，圆半径还会继续覆盖前后区域，拾取提示中的“前方550”并非真实判定长度。

## 使用限制

本物品不限制持有英雄。非 Saber 也能获得基础属性、主动、周期恢复和致命保护；只有直线宝具要求英雄 ID 为 `Ogld`。
