# I04P · 微战盔甲

> **品质**：劣质　**打造物品等级**：22

> **2.5 复核结论**：旧页没有给出战斗指挥的实际值；技能说明写的“防御 +1”已经过时，`A0AL` 实际为护甲 +10。2.5 与 2.41 游戏数据一致，本页不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +40 |
| 防御值 | +18 |
| 生命值上限 | +500 |

## 被动效果

**战斗指挥 Lv1**：通过 `A0AL` 为光环有效目标增加 **10 点护甲**。

## 获取方式

在 11/12 层防具打造中使用[毫无光泽的盔甲](../素材/I04S_11.12层毫无光泽的盔甲.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I04P`、`I04V`、`I04W` 中的 1 件；
- 无论成功与否都会消耗 1 次材料充能。

若三种成功结果等概率，每次材料充能获得本物品的概率约为 **1/6（16.67%）**。
