# 结衣

**主属性**：力量 · *头衔：AI* · **英雄 ID**：`Odrt`

!!! note "2.41 版本说明"
    结衣在 2.41 已不是旧版“黑色狂魂/暗黑星辰”升级里程碑体系。当前版本本体单位 `Odrt` 自带 `A1AW,A0U0,A0TY,A1B5,AInv,A0DY`，核心机制围绕**神焰魔剑**形态与**数据支援**成长展开。

## 技能

???+ abstract "W　· 惩戒-摧毁　冷却：18秒　初始自带"

    锁定敌人后快速突进，约 1 秒后在自身位置生成爆炸，对周围约 **500码**敌人造成**力量×75**混乱/毁灭伤害。

    !!! warning "描述与实测差异"
        技能描述写伤害为**筋力×78**，但 2.41 触发器实际为**力量×75**。

???+ abstract "E　· 究极爆破　冷却：26秒　初始自带"

    需要处于**神焰魔剑形态**。在目标点召唤爆破核心并进行位移演出，爆炸时对周围约 **600码**敌人造成一次**力量×110**混乱/毁灭伤害。

    爆炸后还有约 **1秒**持续伤害判定，每 **0.1秒** 对范围内敌人造成**(力量+敏捷)×2**混乱/毁灭伤害。

???+ abstract "R　· 终焉审判　冷却：37秒　初始自带"

    锁定目标并令目标静止，释放期间结衣每 **0.1秒**恢复**敏捷×0.6**生命，最多约 **30次**。

    约 2.3 秒后对目标造成一次**结衣当前生命值×3**混乱/毁灭伤害，并恢复目标行动。

???+ abstract "被动　· 神焰魔剑　被动"

    结衣自带的魔剑机制。进入神焰形态后，结衣的普攻会记录目标；当本次攻击造成伤害时，额外追加**英雄等级×随机2~5**魔法伤害。

    该额外伤害只在神焰形态开启时生效。触发器中有“魔法值≥50”的判断，但未实际扣除魔法值。

???+ abstract "被动　· 数据支援　自动成长"

    选中结衣时会自动触发一次数据支援：随机分配总计 **6点**属性到力量、敏捷、智力，并启动每 **30秒**一次的循环成长，后续每次同样随机分配总计 **6点**属性。

    同一初始化流程还会让结衣进入神焰形态：播放变身动作，约 3 秒后启用 alternate 站姿，并将神焰形态标记设为开启。

## 机制总结

- 当前版本结衣的主要输出来自**神焰形态下的 W/E/R**，不是旧版召唤物技能链。
- `A1B5` 是页面上可见的“神焰魔剑”被动说明；`A0DY` 是“数据支援”机制入口，实际在英雄初始化时自动调用。
- W/E 都要求神焰形态标记开启；初始化会默认开启，因此正常游玩时可直接使用。
