# I0L7 · 解放-神枪

> **类型**：特殊合成素材　**物品 ID**：`I0L7`

## 实际效果

本物品没有属性、主动技能或被动技能，唯一用途是参与命运枪升级公式；说明文字“遇到某件武器时会解放力量”不是独立装备效果。

## 获取方式

唯一确认来源是订制补给流程：

1. 英雄自动使用“外物补给品 4”`I0KZ`；
2. 英雄所有者必须匹配两名指定订制玩家之一；
3. 本局尚未领取过该奖励；
4. 成功后同时获得 `I055` 与 1 件 `I0L7`。

当前版本没有正常获取方式。

## 合成用途

`I0KY ×1 + I0L7 ×1 → I0L6`

- 主材料：[命运之枪·刚格尔尼（I0KY）](../武器/I0KY_命运之枪·刚格尔尼.md)
- 产物：[命运魔枪·刚格尔尼（I0L6）](../武器/I0L6_命运魔枪·刚格尔尼.md)

2.5 与 2.41 的实际效果、订制来源和合成用途一致。
