# I05N · 黑暗·解放者

**分类**：不归类 · **物品等级**：82 · **物品 ID**：`I05N` · **物品战力**：29,700

物品等级 82 不代表掉落楼层。旧页把它写成“迷宫 25 层随机物品”，实际应为指定 25 层 Boss 的必掉物品。

## 基础属性

| 属性 | 实际数值 | 物品自带能力 |
|------|---------:|----------|
| 攻击力 | +700 | `A0QF` |
| 力量 | +100 | `A0EH` |
| 敏捷 | +150 | `A0EH` |
| 最大生命 | +8,000 | `A0TD` |

物品图标可以被点击使用，但当前版本没有对应的主动效果；实际只有三项被动属性。

## 英雄联动

说明文字只写“细剑系提升 Lv1、双剑系提升 Lv1、影流”，真实效果分散在多个英雄实际效果中：

| 英雄／入口 | 持有本物品时的实际变化 |
|------------|------------------------|
| 指定[草壁操](../../heroes/暗杀者.md) | 拾取时专属加成 +1，丢弃时 -1；该值会加入 Q／W／E 键倍率 |
| 指定[桐人](../../heroes/封弊者_桐谷和人_桐人.md) | 拾取时双剑加成 +1，丢弃时 -1 |
| [亚丝娜](../../heroes/闪光_亚丝娜.md) `A0AD` | 每次范围伤害由敏捷×3提高为敏捷×6 |
| 亚丝娜 `A0E7` | 每次伤害基数由敏捷×23提高为敏捷×26；目标为镜像时仍在此基础上再乘10 |
| 亚丝娜 `A0BU` | 直线滑行伤害由敏捷×30提高为敏捷×45 |
| [红叶](../../heroes/红叶.md)被动 | 拾取／丢弃通常在 +2／0 之间切换额外弹体数；总弹体数为 `向下取整（3＋物品加成＋敏捷/500）` |
| 桐人新式连斩 `A1LG` | 挥砍数 27→35，每次敏捷倍率 7→10，收尾路径伤害倍率 100→103 |
| 桐人遗留 `A0A8` | 若通过特殊方式获得，收尾阈值 27→36，范围终结倍率由 `敏捷×（108＋双剑等级）` 提高为 `敏捷×（158＋双剑等级）`；正常玩法无法获得该技能 |

!!! warning "多英雄联动注意"
    草壁操与桐人的“+1”只对英雄生效；红叶在 +2／0 之间切换。亚丝娜联动可能算到错误角色；敏捷×45的效果仍待实际确认。

## 获取方式

击败 25 层的 35 级食人魔 Boss（单位 ID：`nfre`）后，必定掉落 1 件 `I05N`。

因此正常击杀该 Boss 会固定掉落 **1 件**黑暗·解放者，不是随机掉落。楼层上下文见[21—30层](../../info/楼层/21-30层.md)。

**其他来源**：当前没有商店、扭蛋或合成来源。

## 合成用途

黑暗·解放者会作为材料被消耗：

`黑剑·阐释者（I0HP） ＋ 黑暗·解放者（I05N） → 黑剑·阐释者-真（I0PS）`

- 材料：[黑剑·阐释者](../武器/I0HP_黑剑·阐释者.md)
- 产物：[黑剑·阐释者-真](I0PS_黑剑·阐释者-真.md)

配方：`I0HP` + `I05N` → `I0PS`。
