# I0O4 · 蝴蝶结

> **品质**：传闻　**类型**：道具

**基础属性**

| 属性 | 数值 |
|---|---|
| 筋力 | +200 |
| 敏捷 | +260 |
| 生命值 | +15000 |
| 移动速度 | +100 |

**技能效果**

| 技能名 | 效果 |
|---|---|
| 恒温 | 不受寒冷(30-40层HP减少)和炎热(40-50层MP减少)影响 |
| 爱意传递 | 生命值未满时自动触发医疗链回复生命（回复量基准为智力×10，逐个衰减10%），约每12秒自动检测一次 |

- ⚠️ **实测勘误**：游戏内文本写"使用技能/道具时有百分50触发、内置cd2秒"，但实际实现为**每 0.1 秒轮询、计数 120 归零后触发**（即约 12 秒一次），只要生命未满就必定触发，与施法无关、也不存在 2 秒 CD；回复量基准为**智力×10**而非固定 1 万。
- 描述：类似蝴蝶的装饰，意寓福在眼前、富运迭至。
- **获取**：随机掉落池（RandomDistAddItem 350025行）
