# I069 · 会唱歌的枪

> **品质**：稀有　**类型**：副武器（枪械）　**物品 ID**：`I069`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +300 |
| 筋力 | +45 |
| 敏捷 | +45 |
| 体力 | +45 |
| 生命值上限 | +2,000 |

## 主动技能

本物品可主动释放一道直线冲击波：

| 项目 | 实际值 |
|---|---:|
| 伤害 | 15,000 |
| 施法距离 | 500 |
| 冲击距离 | 600 |
| 最终区域范围 | 150 |
| 魔法消耗 | 250 |
| 冷却时间 | 10 秒 |

目标列表为地面敌人和建筑；旧页只写了 600 距离与 15,000 伤害，遗漏了施法距离、范围、耗魔和冷却。

## 获取方式

在 2 城武具打造中消耗 1 份 [会唱歌的河豚（I08E）](../素材/I08E_会唱歌的河豚.md)，成功率为 50%。无论成功或失败都会消耗 1 充能。
