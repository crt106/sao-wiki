# 2.52 Wiki 翻新审计

## 引用扫描结果

- 扫描范围：`docs/` 下 1069 个 Markdown 文件。
- 实体索引：964 个物品页、59 个英雄页，共 1023 个实体、2438 个名称／rawcode 别名。
- 最终安全补丁检查：`linked: 0`、`files: 0`，即没有仍可由规则直接补上的唯一引用。
- 最终明细：[`reference_audit_final.json`](reference_audit_final.json)。

最终报告仍保留 434 个候选，它们不是 434 个漏链，而是用于人工复核的上下文：

| 分类 | 数量 | 处理原则 |
|---|---:|---|
| 同行已有同目标链接 | 61 | 避免一句话反复链接同一页面 |
| 与传送物品同名的地点 | 52 | “通天塔”“楼兰后院”等地点不自动指向传送道具 |
| 已登记上下文排除 | 3 | 当前英雄显示名、技能同名等明确非交叉引用 |
| 2～3 字高风险短词 | 316 | “任务”“能量”、Boss 同名、技能名内子串等不自动链接 |
| 多目标歧义 | 2 | “强盗利刃”已在同句列出并链接 3 个变体；“草莓奶昔”标题中的“草莓”不是材料引用 |

## 工具

- `scripts/audit_wiki_references.py`：只读扫描英雄、物品名称与 rawcode，输出 JSON 明细。
- `scripts/generate_wiki_reference_patch.py`：只生成 `apply_patch` 文本，不直接修改 Wiki；短名称只处理人工登记的安全别名。

自动链接前必须保留人工语义复核。尤其不能把“红叶时雨”中的“红叶”、Boss 技能“月镰”、69 层 Boss“独裁者”或 53 层 Boss“暗杀者”链接到同名英雄／物品页。
