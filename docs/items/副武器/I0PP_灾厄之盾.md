# I0PP · 灾厄之盾

> **品质**：传说　**类型**：副武器（盾类）　**物品 ID**：`I0PP`

## 实际属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +400 |
| 敏捷 | -200 |
| 体力（智力） | -200 |
| 生命值上限 | +80,000 |
| 防御 | +150 |

游戏说明把生命拆成“基础 30,000”和“能抗最毒的打增加 50,000”，实际则由技能 `A1J3` 一次性提供生命值上限 +80,000，并非两个独立效果。

## 灾厄

物品查询文字声称会让持有者多承受伤害并反弹部分伤害，但 2.5 实际游玩中只能确认上表五项属性；伤害放大、反伤和“秒杀类无效”均未生效。

## 获取方式

本物品的实际等级为 **8**，分类为常驻装备。当前版本没有正常获取方式。
