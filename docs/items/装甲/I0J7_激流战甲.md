# I0J7 · 激流战甲

> **品质**：优越　**打造物品等级**：41

> **2.5 复核结论**：补齐 33 点防御、主动治疗的 7 秒冷却和精确打造概率。每次急冻猪皮毛充能获得本物品的最终概率为 25%，不是“打造成功后必得”。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +80 |
| 敏捷 | +80 |
| 智力 | +80 |
| 生命值上限 | +5000 |
| 防御力 | +33 |

## 主动效果：战斗回复 Lv3

使用能力 `A06E` 后恢复 **2500 点生命值**，冷却时间 **7 秒**。

## 隐藏效果：散热

持有 `I0J7` 的单位位于炎热区域豁免范围中，不受每轮 1000 点魔法扣减。

## 获取方式

使用[32 层急冻猪的皮毛](../素材/I08A_32层急冻猪的皮毛.md)打造防具：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0J5` 或 `I0J7`。

因此每次材料充能获得激流战甲的概率为 **1/2 × 1/2 = 1/4（25%）**。成功和失败都会消耗材料充能；没有找到独立商店或 Boss 来源。
