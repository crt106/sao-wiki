# I0QC · 动能腿甲·熔火

> **品质**：传说　**类型**：不归类

**基础属性**

| 属性 | 数值 |
|---|---:|
| 筋力 / 敏捷 / 体力 | 各 +210 |
| 生命值上限 | +30,000 |
| 移动速度 | +180 |

**主动技能：动能急行·熔火**

- 使用时先扣除最大生命值的 10%，最低保留 1 点生命，不会直接致死。
- 随后获得 1.5 秒无敌并沿面向快速移动 600 码。
- 冷却 15 秒。

- **获取**：宠物打造合成——[动能腿甲](../装备道具/I0NY_动能腿甲.md) + [熔火结晶](../素材/I0QD_熔火结晶.md)。
- **配方**：`I0NY` + `I0QD` → `I0QC`。
