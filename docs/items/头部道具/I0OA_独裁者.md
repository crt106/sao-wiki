# I0OA · 独裁者

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0OA`

!!! warning "说明文字与实际游戏数据不一致"
    物品说明写有 33 点魔抗，但当前实际不会获得魔法减伤。旧页还把来源误写为 300 金商店，并把威严范围写成 3000；实际来源为固定宝物箱，掉率 80%，光环作用范围为 999999。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +120 |
| 敏捷 | +240 |
| 生命值上限 | +15,000 |
| 魔法／体力恢复数值 | +50 |

技能 `A15O` 提供魔法／体力恢复数值 +50，不是生命回复。说明中的“魔抗 33”没有实际效果，因此不列入属性表。

## 威严

技能 `A1AD` 提供防御光环：

- 作用范围：999999；
- 防御力奖励：+120；
- 目标：可接受友军光环的友方单位与自身。

在当前地图尺度下，这相当于近乎全图的友军 120 防御光环，不是旧查询文字中的 3000 范围。

## 获取方式

指定宝物箱（单位 ID：`ndrv`）开启后，有 **80%** 概率获得 1 件独裁者。该箱子还会给出其他固定奖励，但不会改变本物品的独立概率。

物品标示价格不是购买价格；当前没有正常商店、扭蛋或合成来源。
