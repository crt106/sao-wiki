# I01K · 天翼战斗剑

> **品质**：稀有　**类型**：副武器　**物品 ID**：`I01K`

!!! warning "“生命力 100”不是实际属性"
    该数字只出现在物品背景文字中，实际不会增加生命值上限。

## 实际属性

| 属性 | 实际值 |
| --- | ---: |
| 攻击力 | +50 |
| 筋力 | +30 |

## 治疗

本物品可主动使用，对应技能 ID 为 `A06F`。一次使用的实际恢复为：

$$
\text{生命恢复}=500+\text{当前筋力}
$$

技能冷却为 7 秒，物品可以重复使用；按钮实际显示的冷却仍待游戏内确认。

## 获取方式

本物品的实际等级为 **8**，分类为常驻装备。当前版本没有正常获取方式。
