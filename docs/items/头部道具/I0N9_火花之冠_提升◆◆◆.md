# I0N9 · 火花之冠·提升◆◆◆

> **品质**：优越　**类型**：头部道具　**物品 ID**：`I0N9`

## 基础属性

物品自带能力已经把前三阶的基础值与“Max 提升”合并，持有本阶时的实际总值为：

| 属性 | 实际总值 |
|---|---:|
| 筋力 | +100 |
| 敏捷 | +120 |
| 体力 | +95 |
| 生命值上限 | +6,800 |
| 防御力 | +35 |

## 被动：战雄

技能 `A16W` 提供：

- 移动速度 +10%；
- 攻击速度 +10%。

游戏内旧说明仍写“攻击速度 +5%”，与当前“双 10%”效果冲突；实际光环范围、目标和与同类光环的叠加规则仍待游戏内确认。

物品虽然可以点击使用，但 `A16U`、`A16T`、`A16V`、`A16W` 均为被动，当前没有可确认的主动效果。

## 获取方式

在打铁妹处使用“打造”能力 `A0Y9`，将[火花之冠·提升◆◆](I0N8_火花之冠_提升◆◆.md)直接替换为本物品：

`I0N8 → I0N9`

本次提升必定成功，不消耗金币，也不需要额外材料。当前版本没有其他正常获取方式；页面标注的金币价格不代表本物品可以购买。
