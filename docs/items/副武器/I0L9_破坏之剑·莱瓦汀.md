# I0L9 · 破坏之剑·莱瓦汀

> **品质**：礼物　**类型**：副武器　**物品 ID**：`I0L9`　**实际关联英雄**：芙兰朵露·斯卡雷特（`Osam`）

游戏提示仍把本物品标成蕾米莉亚专属，但所有英雄联动都指向 `Osam` 与芙兰朵露技能，旧页的专属英雄判断错误。

## 物品本体属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +100 |
| 攻击速度 | +50% |
| 筋力 | +30 |
| 敏捷 | +30 |
| 体力 | +30 |

攻击造成伤害时，会将其中30%转化为自身生命值。

## 通用持有效果

持有 `I0L9` 的单位开始普通攻击时，会立即对目标额外造成：

`（当前筋力 + 当前敏捷 + 当前体力）× 2`

伤害类型为混乱攻击、通用伤害，即使普通攻击没有命中也会触发。

## 授权拾取附加效果

只有两名指定玩家的英雄可以保留本物品，拾取后会：

- 给持有者加入 `A0CL`：半径 310、30% 分裂；
- 创建两只 `e053` 守卫，并每2秒跟随持有者；
- 守卫攻击与回击治疗的旧版联动仍然生效。

这些守卫效果只对芙兰（单位 ID：`Osam`）稳定生效；多名持有者同时使用时，伤害、回击目标或治疗可能异常。

本物品仅面向指定支持身份发放。非授权角色不属于正常获取与使用范围；多人同时使用时，守卫伤害、回击目标或治疗可能互相影响。

## 芙兰朵露技能联动

=== "2.5（狂猎）当前版"

    持有 `I0L9` 的角色使用 `A0YL` 时，会移动到目标位置，并对400范围内存活的非建筑敌人造成：

    `当前筋力 × 20`

    伤害类型为混乱攻击、通用伤害，并将目标在 0.3 秒内击退 300。

=== "2.41（测试版）历史效果"

    2.41 只采用芙兰朵露（英雄 ID：`Osam`）的装备状态，持有时伤害倍率为当前筋力 ×30。

`A0YH` 在 2.5 中仍只采用芙兰朵露的装备状态。条件满足后，实际施法者获得 `A0RV`，持续 6 秒，攻击速度与移动速度均 +300%。

## 击杀成长异常

持有本物品完成击杀，理论上最多可累计 1,000 层，并通过 `R001` 为 `Osam` 每层增加 3 点攻击力。

但当前版本无法把这项成长稳定授予持有者，因此不能把它视为可靠生效的物品属性。

## 获取方式

两名指定支持身份使用 `I0KV` 时，会一次性获得 `I0EO` 与 `I0L9`。正常掉落、商店、合成与打造均没有其他来源。
