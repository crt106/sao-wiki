# I0OC · 生机之书

> **分类**：消耗物品（拾取即用）　**使用次数**：1 次

> **版本结论**：2.5 与 2.41 的游戏数据和三条获取方式一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际效果

英雄拾取后会自动消耗，并通过技能 `A1AU` 永久增加 2,000 点最大生命值。

## 获取方式

| 来源 | 概率 | 说明 |
|---|---:|---|
| 地图地面物品 | 100% | 开局后可直接拾取 |
| `nrvs` 金色宝箱 | 100% | 与 `I03T` 一同掉落 |
| `n040` 兰蛤蟆 | 100% | 击败后必掉；部分宝物箱（`ndrv`）还会出现兰蛤蟆 |

本件没有商店或合成来源，旧页的“获取方式待验证”现已补全。
