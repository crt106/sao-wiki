# I0DX · 黑纱·魅惑之幽

> **品质**：稀有　**类型**：装甲

> **2.5 复核结论**：旧页把 `A0XP` 写成含糊的“体力回复 Lv4”，实际是每秒恢复 40 点魔法。本次同时把固定 Boss 与固定金色宝箱两个来源拆开说明。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +120 |
| 敏捷 | +120 |
| 智力 | +120 |
| 生命值上限 | +10000 |
| 魔法恢复 | +40/秒 |

## 获取方式

有两个正常来源：

1. 击败 Lv67 干旱中暴食者（单位 ID：`nfrg`）时，**必掉 1 件**。
2. 首次击破指定金色宝箱（单位 ID：`nrvs`）时，在 `I07Z` 与 `I0DX` 中等概率掉落一件，本物品概率为 **50%**；该宝箱奖励只能获得一次。

魔法恢复、Boss 与箱子掉落落点仍待实际确认。
