# I079 · 奇怪的武器

> **类型**：素材　**物品等级**：33　**使用次数**：1

> **版本结论**：2.5 与 2.41 的游戏数据、怪物掉落和可能结果一致；本页以 2.5 重新核验后的结论为准，不另设版本 Tab。

## 获取方式

击败 23 层暴躁的野兽（单位 ID：`ngnb`）时，有 5% 概率获得 `I073`、`I074`、`I079`、`I07A` 中的 1 件。

若四种结果等概率，则本物品的单次掉落率约为：

`5% × 1/4 = 1.25%`

旧页面把物品等级 33 误当成楼层，并写成“33层掉落”；实际来源是 23 层。

## 用途

游戏说明称它可以做武器，但当前版本没有确认到合成、打造或任务用途，因此没有可用配方。

## 原始说明

能做点武器，可是这样的武器看上去一般商人不会要。
