# I0PV · 罪恶王冠（觉醒）

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0PV`

!!! warning "失落的圣诞并非低血量判定"
    物品提示沿用了“生命低于 30%”文字，但 2.5 与 2.41 中，冷却结束后受到的第一笔正伤害就会触发，不要求生命低于 30%。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +350 |
| 敏捷 | +350 |
| 体力 | +350 |
| 生命值上限 | +12,000 |

## 被动：失落的圣诞

冷却就绪时，持有者受到任意一笔正伤害都会：

1. 本次伤害归零，持有者生命直接设为 1；
2. 无敌并暂停 3 秒；
3. 结束后增加一份最大生命值，通常回满；
4. 此时才启动 60 秒冷却，触发到再次可用约为 **63 秒**。

该效果没有生命比例或致死条件，只覆盖普通有效伤害，特殊击杀效果不保证触发。

本物品与[基础罪恶王冠](I0C3_罪恶王冠（传说）.md)共享约63秒的保护冷却，因此两件同时持有不会提供两套独立保护。`I0PV` 本身没有基础王冠的旧式低血量保护。

## 主动：结晶化

对 1,000 距离内的敌方地面或空中单位使用，冷却 45 秒：

- 造成 `当前筋力＋敏捷＋体力` 的总和 ×60；
- 攻击类型为混乱，伤害类型为毁灭；
- 同时由附加效果施放眩晕能力 `A1B9`。

`A1B9` 只有 1 个物品等级，普通与英雄持续时间均为 **2.6 秒**。触发当前效果虽然尝试设置等级 2，但游戏数据中没有第二级，因此旧页写“眩晕 2 秒”不是当前数据的精确值，最终控制表现仍待实际确认。

## 获取方式

由[罪恶王冠](I0C3_罪恶王冠（传说）.md)与[王的力量结晶](../素材/I0PW_void.md)合成：

`I0C3 + I0PW → I0PV`

2.5与2.41均可按该配方合成。
