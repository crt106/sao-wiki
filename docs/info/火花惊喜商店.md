# 火花惊喜商店

火花（单位 ID：`n2H0`）是 2.5 新增的特殊商店 NPC，位于地图东侧的迷宫传送区附近，与[流萤隐藏入口](楼层/隐藏与副本Boss/流萤.md)处在同一片区域。

## 商品一览

| 商品 | 价格 | 用途 |
|---|---:|---|
| [四次元口袋（`I2H0`）](../items/不归类/I2H0_四次元口袋.md) | 50,000 金 | 提供生命与魔法恢复；主动使用后暂时离开背包，15 秒后返回。 |
| [死亡凋零的教材（`I2H1`）](../items/副武器/I2H1_死亡凋零的教材.md) | 50,000 金 | 提供三围与生存属性；主动技能形成持续 50 秒的百分比伤害区域。 |
| [闲聊/火花：交谈对话（`I2H2`）](../items/特殊/I2H2_火花交谈对话.md) | 免费 | 与火花聊天；每名玩家各自循环四句对话。 |
| [你能表演一下那个吗..?（`I2H3`）](../items/特殊/I2H3_你能表演一下那个吗.md) | 10,000 金 | 请火花进行约 16.56 秒的舞蹈与音乐演出。 |

四种商品售出后都会在约 1 秒后补货，不是单局限购。

## 交互说明

- `I2H0` 与 `I2H1` 是正常进入背包的装备，完整属性与主动效果见各自页面。
- `I2H2` 与 `I2H3` 是商店交互按钮，购买后会自动使用并消失，不会留在背包中。
- 闲聊进度按玩家分别循环，其他玩家购买不会改变你下一次看到的台词。
- 点舞会向全队显示火花的回应并开始演出；舞蹈尚未结束时再次点舞，会重新开始动作，音乐可能与上一段重叠。
