# I2H1 · 死亡凋零的教材

> **品质**：特殊　**类型**：副武器　**购买价**：50,000 金

**基础属性**

| 属性 | 数值 |
|---|---:|
| 筋力 / 敏捷 / 体力 | 各 +100 |
| 生命值上限 | +8,000 |
| 法力值上限 | +12,000 |
| 魔法恢复 | +30 |

**主动技能：死亡凋零青春版**

- 在目标点形成持续 50 秒的区域，每秒结算一次。
- 每次结算对 500 码内敌人造成其最大生命值 **0.1%** 的混乱伤害。
- 施法者当秒必须仍在区域中心 1,000 码内；超出范围只跳过该秒伤害，法术不会提前结束。
- 冷却 120 秒。

- **获取**：在[火花惊喜商店](../../info/火花惊喜商店.md)向 NPC 火花（`n2H0`）购买，50,000 金；售出后约 1 秒补货。
