# I00L · 野猪皮服

> **品质**：劣质　**打造物品等级**：11

> **2.5 复核结论**：旧页把 50 金游戏数据数值写成售价，并遗漏了生命恢复的实际值。2.5 与 2.41 游戏数据一致，本页不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +15 |
| 生命值上限 | +150 |
| 所受魔法伤害 | -13% |
| 生命恢复 | +20/秒 |

`A07Q` 的能力名仍写“生命恢复10”，但实际数值为 20，因此以每秒 20 点为准。

## 获取方式

在 1 城防具打造中使用[野猪的皮](../素材/I000_野猪的皮.md)：

- 每次消耗 1 次材料充能；
- 打造成功率为 `1/2`；
- 成功后固定获得野猪皮服。

因此每次材料充能获得本物品的概率为 **1/2（50%）**。页面标注的金币价格没有对应商店，不能当作实际购买价格。
