# I0DW · 天使教徒（传说）

> **分类**：头部道具　**品质**：传说　**初始充能**：50 次

> **版本结论**：2.5 与 2.41 的游戏数据、唯一有效来源和孤立旧机制状态一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 力量 | +180 |
| 最大生命 | +5,000 |

## 主动能力：限制的爱

主动技能 `A0XR` 的效果为：

| 项目 | 实际值 |
|---|---:|
| 生命恢复 | 3,000 |
| 魔法恢复 | 3,000 |
| 作用范围 | 600 |
| 冷却 | 3 秒 |

使用后会恢复自己及 600 范围内的友军；每件物品初始带 50 次充能。

## 获取方式

击破寂静之箱（单位 ID：`nrvl`）后，必定掉落 1 件 `I0DW`、2 件 `I0BE` 和 1 件 `I09F`。

旧资料还记录过另一条掉落，但当前版本不会生效，不计为获取来源。
