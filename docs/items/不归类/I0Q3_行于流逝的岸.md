# I0Q3 · 行于流逝的岸

**分类**：不归类 · **物品等级**：82 · **专属英雄**：[雷电·忘川守·芽衣](../../heroes/雷电_忘川守_芽衣_刺客.md)（`O01Y`／`O01Z`）

2.52 与 2.41 的物编属性相同，但 2.41 尚未接入“司渡”的 24% 增伤，2.52 还修复了与[王女之冠](../头部道具/I0Q9_王女之冠.md)同时持有时的免死竞争。旧页照抄物品查询说明，把未生效的 24% 增伤、错误的 100 点恢复和错误的 100 秒主动冷却都写成了实际效果，本页已按实际执行纠正。

## 基础属性

| 属性 | 实际值 | 对应能力 |
|------|-------:|----------|
| 攻击力 | +16000 | `A1LR` |
| 防御力 | +80 | `A1LS` |
| 魔法伤害减免 | 50% | `A0BT` |
| 最大生命 | +20000 | `A1IN` |

主动技能 ID 为 `A1MD`，属性技能 ID 为 `A1ME`。

## 版本效果

=== "2.52（狂猎）当前版"

    ### 司渡 · E／R 伤害提升24%

    司命持有本物品时，“红叶时雨·万倾一空”和“残梦尽染·一刀缭断”的每笔伤害均乘1.24：

    - 单独持有 `I0Q3` 时，E 与 R 的最终倍率为1.24；
    - 装甲 `I0FE` 原有的18%强化继续独立生效；两件同时持有时，伤害提升相加，最终倍率为1.42；
    - Q 与 W 也不会受到 `I0Q3` 强化。

    ### 司命 · 致命保护

    当持有者受到足以致命的伤害，且该效果可用时：

    1. 本次结算伤害被改为0，持有者生命被设为1；
    2. 获得 3 秒免死状态；
    3. 前1秒额外设为无敌，随后解除无敌，但余下2秒仍会阻止致命伤害；
    4. 3秒结束时增加一份最大生命值，正常情况下回到满血；
    5. 此时才启动120秒独立冷却，因此从触发时点到再次可用约为123秒。

    这3秒不是全程无敌：第一秒后，若单位通过其他方式恢复到1点以上，低于当前生命的非致命伤害仍可正常扣除；实际效果保证的是不会死亡。物品查询所写“时间过后回复100生命值”与执行不符。

    若同时持有[王女之冠](../头部道具/I0Q9_王女之冠.md)，两项保护都可用时优先触发王女之冠，本物品不会被一并消耗；王女之冠冷却而司命就绪时，才由司命触发。两件物品共享触发演出中的竞争锁，不能被嵌套伤害在同一轮内连续触发。

    ### 忘川 · 主动形态切换与范围伤害

    **主动能力**：`A1MD` · **实际冷却**：120秒 · **作用范围**：自身周围450

    使用时先在 `O01Y` 与 `O01Z` 两种形态之间切换，再读取当时的平均攻击力：

    `伤害＝（当前最小攻击力＋当前最大攻击力）÷2×20`

    对 450 范围内存活敌人各造成一笔混乱攻击／毁灭伤害，建筑也会受到伤害。伤害在使用时一次计算；物品查询写“CD 100 秒”，但实际冷却为 120 秒。

=== "2.41 测试版"

    `I0Q3`、`A1MB`、`A1MC`、`A1MD`、`A1ME` 的物编数值与 2.52 一致，但2.41成图没有把“司渡”的24%说明接入 E／R 伤害函数。

    | 项目 | 2.41 | 2.52 |
    |------|------|-----|
    | 基础属性 | 攻击16000、防御80、减魔伤50%、生命20000 | 相同 |
    | 司渡 | `I0Q3` 未生效；`I0FE` 提供1.18倍率 | `I0Q3` 提供1.24倍率；与 `I0FE` 同时持有为1.42 |
    | 司命 | 3秒免死、首秒无敌、结束回满 | 相同 |
    | 忘川 | 切换形态，450范围平均攻击力×20，冷却120秒 | 相同 |

    因此2.41的“司渡”仍属于只有说明、没有倍率的旧问题；2.52当前版已经补上24%倍率。回复100和冷却100仍只是旧说明文字，并非实际执行值。

## 专属限制

- `O01Y` 或 `O01Z` 英雄拾取时可以保留，并显示专属提升提示。
- 只有司命（英雄 ID：`O01Y`／`O01Z`）可以正常持有；其他英雄拾取后，物品会被移出背包。
- 该物品不能通过[物品镜像](../特殊/I0PZ_物品镜像.md) `I0PZ` 复制。

## 获取途径

击败王珏（单位 ID：`n02B`）时，必定掉落 1 件 `I0Q3`，并同时掉落 `I0PD`、`I0PE`、`I0PF` 和 `I0FE`。

当前 2.52 中没有 `I0Q3` 的合成、商店、扭蛋或其他获得方式；物品等级 82 也不属于扭蛋机使用的 201～205 或 211～215 档位。
