# I0PD · 闪烁之光

> **品质**：不归类　**物品等级**：82　**物品 ID**：`I0PD`　**专属英雄**：闪光·亚丝娜（`Hmkg`）

!!! info "本次重审结论"
    物品属性和获取方式在2.5与2.41相同，变化发生在亚丝娜的技能实际效果。旧页把两条互相矛盾的拾取提示概括成统一“系数+3”，又把物品说明中的“隐藏任务获得”当成来源；真实来源是王珏 `n02B` 无随机必掉，74层隐藏任务只是该物品的后续用途。

## 专属持有条件

只有亚丝娜（英雄 ID：`Hmkg`）可以正常持有；其他英雄拾取后，物品会被移出背包。

重复拾取时可能显示不同的强化数字，但属性和技能效果不会重复计算。

## 获取方式

**击败王珏（单位 ID：`n02B`）时，必定掉落 1 件。**

同一名王珏还会同时掉落：

- `I0Q3`
- `I0PD`
- `I0PE`
- `I0PF`
- `I0FE`

该物品为必定掉落。当前版本没有其他正常获取方式；物品说明中的“通过隐藏任务获得”不准确，物品等级 82 也不代表来自 82 层。

## 2.5 新增的 74 层用途

在74层任务商店购买[前进的资格（I0R6）](../特殊/I0R6_74层前进的资格.md)时：

- 购买者必须是亚丝娜 `Hmkg`；
- 背包必须持有 `I0PD`；
- 满足条件后，青眼恶魔会永久进入任务易伤状态；
- 对话道具 `I0R6` 会被移除，闪烁之光本身不会被消耗。

这是一条**物品用途**，不是闪烁之光的获取任务。2.41没有74层及该入口。

## 尚未证实的说明文字

物品说明还写有“透明剑刃有 25 层强化空间”，但当前没有对应的强化、升级或属性成长效果，因此只能视为说明文字。物品镜像能力也无法复制 `I0PD`，与所谓 25 层强化无关。
