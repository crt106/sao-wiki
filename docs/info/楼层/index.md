## 阅读说明

- **数值口径**：以 **2.41 测试版** 为准；标★ Boss 为该段路的硬墙，建议优先看完。
- **粒度分级**：
    - **★ 重点 Boss**：写满数据 / 持续被动 / 主动技能 / 半血狂暴 / 喊话速查。
    - **普通 Boss**：写基础数据、主要技能、关键掉落、玩家提示。
- **写作角度**：玩家攻略视角——「看到什么 / 怎么躲 / 怎么打」，不解读代码实现。
