# I0H5 · 绽放之花

> **品质**：稀有　**类型**：装甲

> **2.5 复核结论**：旧页把两项技能 ID 对调，也没有给出真实数值。森林的缠绕实际为每秒 10000 点；15 层 Boss 掉落绽放之花的实际概率不是 20%，而是 100%。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 智力 | +105 |
| 生命值上限 | +5000 |
| 每秒魔法恢复 | +30 |

游戏内说明把智力称作“体力”，实际增加的是智力。

**属性技能 ID**：`A04Q`

## 主动效果：森林的缠绕

**主动技能 ID**：`A0WP`

| 参数 | 实际值 |
|---|---:|
| 每秒伤害 | 10000 |
| 普通目标持续时间 | 3 秒 |
| 施法距离 | 400 |
| 魔法消耗 | 100 |
| 冷却时间 | 20 秒 |

游戏内技能文字仍显示“15 点/秒、9 秒”，与实际数值不符。英雄和 Boss 可能因抗性而缩短控制持续时间，具体表现仍待实际确认。

## 获取方式

### 15 层 Boss

击败 15 层访魂者（单位 ID：`nenc`）后，`I0H5` 实际为**必掉 1 件**，不是旧资料所写的 20%。

### 固定宝物箱

另有一只宝物箱（单位 ID：`ndrv`）可以开出本物品：

- `I0H5`：权重 34；
- `I03T`：权重 33；
- `I03S`：权重 33。

该宝箱开出绽放之花的概率为 **34%**，且每局仅结算一次。
