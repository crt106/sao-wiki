# I0DO · 小魔女

> **品质**：优越　**类型**：副武器　**物品 ID**：`I0DO`

## 实际属性

| 属性 | 实际值 | 能力 |
|---|---:|---|
| 体力 | +120 | `A04O` |
| 生命值上限 | +5,000 | `A0JY` |
| 移动速度 | +90 | `A08M` |

游戏说明与旧页写的是“生命值 800”，实际挂载的 `A0JY` 明确为生命值上限 +5,000。移动速度 90 是 `AIms` 系能力的平值，不是 90%。

## 获取方式

背景文字声称由 23 层材料打造，但当前没有对应打造方式。本物品等级为 **8**，当前版本没有正常获取方式。
