# I0L3 · 邪恶拳刃·提升

**分类**：武器 · **品质**：普通 · **物品等级**：44

旧页把获取途径留为待验证。本物品可通过随机打造获得，也是邪恶拳刃提升链的起点。

## 基础属性

| 属性 | 实际值 | 对应能力 |
|------|-------:|----------|
| 攻击力 | +260 | `A01L` |
| 敏捷 | +188 | `A03H` |
| 防御力 | +25 | `A05M` |
| 最大生命 | +2500 | `A0H6` |

## 版本差异

=== "2.5（狂猎）当前版"

    说明已把攻击力从245改为260，与 `A01L` 一致。

=== "2.41 测试版"

    说明写攻击力245，但四项对应技能与2.5相同，实际攻击力已经是260。此次只修正说明。

## 获取与升级

使用 `I0A9`（34 层／滑行者的爪）打造武器时，成功率为 `1/2`；成功后随机获得 8 种当前武器结果中的 1 件。若八种结果等概率，直接获得 `I0L3` 的概率约为 `1/16`。

施放打造能力 `A0Y9` 可把它升级为 [I0J9 · 邪恶拳刃·◆](I0J9_邪恶拳刃·◆.md)。该能力冷却10秒、消耗250魔法。
