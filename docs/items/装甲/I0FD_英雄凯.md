# I0FD · 英雄凯

> **品质**：稀有　**类型**：装甲

> **2.5 复核结论**：`A11L` 的当前影响范围为0，“周围敌人减速”是否能命中目标仍待实战确认。英雄凯还提供藤蔓免疫，并会在受伤后清除负面状态。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +100 |
| 敏捷 | +100 |
| 智力 | +100 |
| 防御值 | +50 |
| 生命值上限 | +20000 |

## 主动与隐藏效果

### 英雄潜能

主动技能 `A11L` 冷却 12 秒、魔法消耗 0。游戏说明写有 60 点伤害和 50% 移动／攻击速度减缓，但当前影响范围为 **0**。

因此“周围敌人减速”在当前版本不会正常生效。

### 负面清除与藤蔓免疫

- 持有者每次受到伤害后会移除普通负面状态，并解除部分 Boss 持续状态；
- `A1E6` 使持有者免受 51～60 层藤蔓机制影响。

这属于“受伤后清除”，并非阻止所有负面状态先行施加。

## 获取方式

击败 Lv48 鱼龙兽（单位 ID：`nmgw`）时，**固定掉落 2 件** `I0FD`。
