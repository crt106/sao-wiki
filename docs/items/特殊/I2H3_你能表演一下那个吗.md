# I2H3 · 你能表演一下那个吗..?

> **类型**：NPC 点舞交互道具　**购买价**：10000 金　**版本**：2.5 新增

## 获取方式

- 在[火花惊喜商店](../../info/火花惊喜商店.md)向 NPC 火花（`n2H0`）直接购买。
- 商品售出后约 1 秒补货，不是一次性限购商品。
- 本物品没有装备属性或物品技能；购买后会自动使用并消失，只承担点舞按钮功能。

## 实际效果

1. 向所有玩家广播“火花”收到点舞请求。
2. 火花切换到循环舞蹈动作，同时播放专属音乐。
3. 约 16.56 秒后，火花恢复待机动作。
4. 舞蹈尚未结束时可以再次购买并重新触发；快速连续点舞时，音乐可能与上一段重叠。
