# I0FG · 灵魂（死逝）

> **品质**：灵魂（King's 物品等级）　**类型**：装甲

> **2.5 复核结论**：旧页误写为“Boss 低于 50%”。实际可对任意生命值不高于 50% 的有效目标使用；所谓“永久消失”只在当前对局内生效。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +70 |
| 敏捷 | +70 |
| 智力 | +70 |
| 生命值上限 | +10000 |

## 主动效果：你将死，我即逝

施放 `A0Z2` 时，目标生命值不高于 50% 且施法者单位 ID 不是 `H03L / H03O / H03N`，会直接击杀目标、消耗 `I0FG`，并在约0.1秒后将施法者移出当前对局。

该效果不要求目标是 Boss。条件不满足时，`A0Z2` 自带的投射物、伤害与1秒眩晕是否仍会生效，仍待实战确认；施法者移除也不会跨存档永久保存。

## 获取方式

击败单位 ID 为 `nsrv` 的罪渊之箱时，首次必定掉落 **1 件** `I0FG`。
