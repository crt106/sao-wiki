# I06D · 神落之面

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I06D`

!!! info "2.5 重审结论"
    当前有两个有效来源：一只 40 级雪地小野兽必掉，以及一只指定金色宝箱的 25% 奖池。旧资料中的第三个来源当前不生效。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 敏捷 | +180 |
| 生命值上限 | +7,000 |
| 魔法伤害减免 | 30% |

## 体力恢复 Lv5

物品自带技能 `A0XO` 的实际效果为“魔法恢复 50”。

这里的“体力恢复”指地图的魔法／体力资源恢复，不是每秒生命回复。由于 `AIrm` 的叠加与面板呈现由游戏引擎执行，本页保留数值 50，实际恢复速率需游戏内读取资源变化确认。

## 获取方式

### 固定雪地小野兽

地图中的 40 级雪地小野兽（单位 ID：`nowb`）死亡后，其奖池只有：

`I06D`：100%

因此满足掉落条件时为 **必掉**。

### 固定金色宝箱

地图中的金色宝箱（单位 ID：`nrvs`）使用四项等概率奖池：

`I06D`：25% / `I03S`：25% / `I03T`：25% / `I0LA`：25%

因此该宝箱取得神落之面的实际概率为 **25%**。

旧资料中的另一条掉落当前不生效，不能当成额外来源。当前也没有正常商店、扭蛋或合成来源。
