# I0LJ · 恋之衣

> **品质**：礼物　**类型**：装甲

> **2.5 复核结论**：游戏说明和旧页写生命值 1000，但技能 `A0H4` 实际增加 2000。物品只通过订制支援品发放；当前版本没有生效的英雄专属持有限制。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +30 |
| 敏捷 | +30 |
| 智力 | +30 |
| 生命值上限 | +2000 |
| 防御力 | +15 |

## 获取方式

限定玩家拾取[外物补给品 1](../特殊/I0KV_外物补给品1.md)时，只有同时满足以下条件才会发放：

- 该支持身份仍有 1 次领取资格；
- 拾取者属于指定支持名单。

成功后一次给予 `I0LG`、`I0LH`、`I0LJ`、`I0LI` 各 1 件。该奖励每局只能领取一次，不属于普通 Boss、商店、合成或扭蛋流程。

当前版本只限制**获得方式**，没有有效的持有者限制；恋之衣可以转交给其他单位使用。
