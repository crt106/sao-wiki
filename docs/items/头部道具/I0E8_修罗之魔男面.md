## 实际技能

### 遗忘的记忆

持有本件的单位完成任意技能效果时：

- 力量临时 +80；
- 持续 3 秒，不是旧页所写的 5 秒；
- 与 `I0E7` 等同类物品共享 3 秒触发间隔，无法多人同时触发。

### 死亡掌握

本次伤害足以致死且 60 秒冷却可用时：

1. 将本次结算伤害清零并把生命设为 1；
2. 无敌并暂停 3 秒；
3. 结束时恢复到满生命；
4. 启动 60 秒冷却。

## 获取方式

击败雷米利亚（三皇，单位 ID：`nenp`）后，固定掉落 `I0E8`、`I0E7`、`I0C3`、`I0BB` 各 1 件。

当前版本没有正常获取方式。
