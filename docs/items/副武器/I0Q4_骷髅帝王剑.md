# I0Q4 · 骷髅帝王剑

> **品质**：传说　**类型**：副武器　**物品 ID**：`I0Q4`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +8,000 |
| 筋力 | +300 |
| 生命值上限 | +15,000 |

## 被动效果

### 血偿轮回

持有者造成正伤害后，按结算伤害的 8% 恢复生命。同一持有者在 0.3 秒内多次造成伤害时，只有第一笔会触发恢复。

### 帝王气息

持有者受到 普通攻击伤害 的普通攻击伤害时，有 50% 概率把该笔伤害清零。效果只保护持有者本人，不是“让周围单位攻击落空”，也不覆盖技能与其他伤害类型。

## 主动技能：掠魂刻印

主动能力 `A1MG` 冷却35秒。施放后对持有者周围450范围内的存活敌人造成：

- 禁锢 2 秒；
- 造成 `当前筋力 ×60`；
- 伤害类型为混乱攻击、毁灭伤害。

## 获取方式

击败 72 层 Boss（单位 ID：`nwzr`）后，会在以下两件物品中等概率掉落一件：

- `I0Q4` 骷髅帝王剑；
- [I0Q5 · 不朽骨盾](I0Q5_不朽骨盾.md)。

两件物品各占 **50%**，每次只掉落其中一件。
