# I0GV · 雷暴战甲

> **品质**：传说　**类型**：装甲　**物品 ID**：`I0GV`

!!! info "本次重审结论"
    2.5 与 2.41 的属性和实际效果相同。旧 Wiki 把镜面反射简化成“反弹给攻击者”，并把掉落 Boss 错写成雷罚龙 `n023`；实际会伤害持有者周围 250 范围内的敌人，来源是冰晶之地领主（单位 ID：`n024`）。

## 基础属性

| 属性 | 实际数值 | 来源 |
|------|---------:|------|
| 力量 | +300 | `A0P9` |
| 敏捷 | +300 | `A0P9` |
| 最大生命值 | +12000 | `A0VP` |
| 防御 | +50 | `A05X` |
| 闪避 | 45% | `A0LM` |

物品提供 `A0LM`、`A05X`、`A0P9`、`A0VP` 四项被动，并通过 `A1E6` 免疫51～60层藤蔓。

## 技能效果

### 镜面反射

英雄持有者成为普通攻击目标时，会立即对自身周围250范围内全部存活敌方非建筑单位造成：

**持有者当前敏捷 × 3**

- 攻击类型：攻城
- 伤害类型：毁灭
- 无概率判定、无个人冷却
- 不要求本次普通攻击已经命中或造成正数伤害

因此它不是只把伤害“反弹给攻击者”。攻击者站在250范围内会被命中；同范围内其他敌人也会一起受伤，而远程攻击者若在范围外反而不会受到这次伤害。

### 雷神之体

当前版本通过三条独立路径效果环境抵抗：

- 生命环境伤害：寒冷／高温区域每3秒自伤1000时，`I0GV` 位于免疫范围；
- 魔法环境损失：高温区域每3秒扣除1000魔法时，`I0GV` 位于免疫范围；
- 藤蔓：拥有 `A1E6` 的英雄免疫51～60层藤蔓控制。

这三项都有实际效果或能力检查，不只是说明文字。原说明把高温楼层写成“30～40层”属于文本错误；楼层范围应结合[楼层资料](../../info/楼层/index.md)阅读。

### 负面免疫

持有者作为伤害目标进入通用伤害处理时，实际效果会执行：

- 移除普通负面魔法效果；
- 清理 Boss 施加的持续控制与负面状态。

这是**受伤处理时清除负面状态**，不是永久阻止所有负面状态被施加。两次伤害之间刚获得的状态、非伤害触发的特殊控制，以及清理机制未覆盖的自定义状态仍待实际确认。

## 与斯托蕾亚的旧技能联动

本物品只与已经无法正常获得的旧主动技能 `A0JN` 有历史联动。当前斯托蕾亚使用 `A1LX／A0JO`，因此雷暴战甲不会提高她现行的 Q、W、E、破坏之雷或普攻附伤。

## 获取方式

击败指定[44 层冰晶之地的领主](../../info/楼层/41-50层.md)（单位 ID：`n024`）时，必定掉落 1 件 `I0GV`。

同一 Boss 还会固定掉落 `I0IJ` 与 `I0DK`。当前没有商店、合成或扭蛋来源。

!!! warning "旧页 Boss 写错"
    Lv85 雷罚龙（`n023`）不会掉落雷暴战甲；真实来源是单位 ID 为 `n024` 的冰晶之地领主。

## 使用限制

物品没有英雄类型持有条件。任意英雄都可获得基础属性、范围反击、环境抵抗与受伤清负面效果。
