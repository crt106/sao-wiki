# I0HA · 堕天使之羽饰

> **分类**：头部道具　**品质**：礼物　**使用限制**：支持者专属

> **版本结论**：2.5 与 2.41 的属性、专属获取方式和战斗效果一致，因此不另设版本 Tab。

## 有效持有时的完整属性

授权玩家持有时会获得以下完整属性：

| 属性 | 数值 | 对应技能 |
|---|---:|---|
| 力量 | +50 | `A0FW` |
| 敏捷 | +50 | `A0FW` |
| 智力 | +50 | `A0FW` |
| 移动速度 | +100 | `A08T` |
| 最大生命 | +2,500 | `A0H6` |
| 魔法伤害减免 | 41% | `A076` |
| 敌方防御 | -15，范围 900 | `A0CG` |

## 实际战斗效果

| 效果 | 执行规则 |
|---|---|
| 生命吸收 | 普通伤害的 35% 转化为生命 |
| 镜面反射 | 敌人开始攻击持有者时，对250范围内所有敌方非建筑造成 `当前敏捷×3` 伤害；即使该击没有命中也会触发 |
| 周期恢复 | 每秒恢复 `当前全属性之和 × 0.3` 生命；飘字却显示全属性之和，显示值是实际治疗的约 3.33 倍 |
| 主动召唤 `A11N` | 召唤自定义 `hmil` 单位，持续 30 秒，冷却 60 秒 |

旧页列出的五个设计名没有逐项对应到独立能力；本页按实际游戏数据与实际效果拆解。

## 获取与装备限制

唯一获取方式为指定支持礼包：

1. 玩家拾取特殊物品 `I0KX`；
2. 拾取者属于指定支持名单，且礼包仍有领取次数；
3. 满足条件后获得 1 件 `I0HA`，并消耗一次领取次数。

只有授权玩家持有时才能获得对应属性与持续恢复；其他玩家无法保留本物品。

标示的金币与木材价格不代表可以购买；旧页“商店购买、3600 秒补货”错误。
