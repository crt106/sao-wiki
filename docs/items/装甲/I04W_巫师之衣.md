# I04W · 巫师之衣

> **品质**：普通　**打造物品等级**：22

> **2.5 复核结论**：旧页把魔抗写成正值，并没有还原两条打造分支的最终概率。实际为魔法伤害减免 27%，且外部豁免范围明确提供御寒效果。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 智力 | +75 |
| 生命值上限 | +2000 |
| 所受魔法伤害 | -27% |

## 隐藏效果

**御寒**：寒冷区域每 3 秒会对未获豁免的单位造成 1000 点自伤；持有 `I04W` 的单位可获得对应豁免，不受这笔环境伤害。

## 获取方式

有两条防具打造分支：

1. 使用[毫无光泽的盔甲](../素材/I04S_11.12层毫无光泽的盔甲.md)：成功率为 `1/2`；成功后随机获得 `I04P`、`I04V`、`I04W` 中的 1 件。若三种结果等概率，本物品的单次概率约为 **1/6（16.67%）**。
2. 使用 `I056` 材料：先以 `1/2` 成功，再在 `I02X` 与 `I04W` 中各取 `1/2`，本物品概率为 **1/4（25%）**。

两种方式失败时同样消耗 1 次材料充能；具体随机分布与环境伤害豁免仍待实际游戏确认。
