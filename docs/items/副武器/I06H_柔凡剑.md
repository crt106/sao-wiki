# I06H · 柔凡剑

> **品质**：传说　**类型**：副武器（剑）　**物品 ID**：`I06H`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +45 |
| 敏捷 | +45 |
| 体力 | +45 |
| 攻击速度 | +35% |
| 生命值上限 | +2,500 |

## 凝聚仙气

本物品可主动使用，立即恢复 500 点魔法值，魔法消耗为 0，冷却时间为 9 秒。

## 获取方式

完成桩哔支线并击败目标（单位 ID：`nsc3`）后，每局结算一次奖励：

- 50% 概率给予柔凡剑和 [真红白之圣灵剑（I06O）](../武器/I06O_真红白之圣灵剑.md)；
- 另 50% 概率给予 `I0LC` 和 `I06O`。

两种结果都会获得 `I06O`，柔凡剑只在第一种结果中出现。奖励发给完成支线的玩家，并且每局只能领取一次。
