# I0N8 · 火花之冠·提升◆◆

> **品质**：优越　**类型**：头部道具　**物品 ID**：`I0N8`

!!! info "属性按成品属性计算"
    本阶不是“仍然只加基础属性、另把追加值展示出来”。物品自带能力已经把基础与提升合并，以下为持有本阶时的最终总值。

| 属性 | 实际总值 |
|---|---:|
| 筋力 | +80 |
| 敏捷 | +100 |

## 获取方式

在打铁妹处使用“打造”能力 `A0Y9`，将[火花之冠·提升◆](I0N6_火花之冠_提升◆.md)直接替换为本物品：

`I0N6 → I0N8`

本次提升必定成功，不消耗金币，也不需要额外材料。页面标注的金币价格不代表本物品可以购买。

## 继续提升

再次使用同一打造能力，可必定替换为[火花之冠·提升◆◆◆](I0N9_火花之冠_提升◆◆◆.md)：

`I0N8 → I0N9`
