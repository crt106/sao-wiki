# I0DQ · ★★贵族的果实

> **物品名称星级**：★★　**扭蛋池当前效果**：物品等级 202

> **2.5 复核结论**：名称和 物品等级 202 都指向二星档，但物品说明仍写三星，旧文件名也因此误标为三星；本页以执行池为准。2.5 与 2.41 游戏数据一致，不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 智力 | +150 |
| 防御值 | +45 |
| 生命值上限 | +2000 |
| 所受魔法伤害 | -35% |

游戏旧文案把智力属性称为“体力”，这里统一使用 Warcraft 实际属性名。

## 获取方式

使用[礼物混乱之圣诞扭蛋](../特殊/I0AX_礼物混乱之圣诞扭蛋.md)并消耗[圣诞礼物·扭蛋卷](../特殊/I0BE_圣诞礼物·扭蛋卷.md)：

- 二星档被选中的概率为 `4/15`；
- 当前 物品等级 202 池共有 5 件物品；
- 按池内均匀抽取计算，本物品单次扭蛋的名义概率为 `4/75`。

即 **约 5.33%**。
