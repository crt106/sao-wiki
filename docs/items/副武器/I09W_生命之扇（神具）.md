# I09W · 生命之扇（神具）

> **品质**：神具　**类型**：副武器　**物品 ID**：`I09W`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +5,000 |
| 筋力 | +90 |
| 敏捷 | +90 |
| 体力 | +90 |
| 生命值上限 | +15,000 |

## 不坏之命

=== "2.5（狂猎）当前版"

    每个持有生命之扇的存活单位每秒分别恢复：

    `（当前筋力 + 当前敏捷 + 当前体力）× 1.5`

    治疗与飘字均使用这个数值，飘字向下取整；丢弃后停止恢复。

=== "2.41（测试版）历史效果"

    同一时间只有最后拾取生命之扇的单位会持续回血；后拾取者会覆盖前一名持有者。任意一名持有者丢弃物品，还可能停止其他持有者的回血。

    实际治疗公式同样是全属性之和 ×1.5，但飘字只显示全属性之和 ×1，造成显示值比实际治疗少三分之一。

## 获取方式

击败 70 级间奏·龙神（单位 ID：`ntrh`）后，必定掉落 1 件生命之扇。
