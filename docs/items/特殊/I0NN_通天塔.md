# I0NN · 通天塔

> **分类**：特殊　**物品等级**：8　**价格**：100 金

## 2.52 当前数据

### 基础属性

当前没有可直接展示的基础属性。

### 物品能力

本物品没有背包能力。它是「副本传送」商店的购买交互项：购买时把购买单位传送到通天塔入口，并用 3 秒平滑镜头移动到落点。

- 当前没有额外的楼层击杀或英雄等级门槛；
- 本项只负责进入场景，不会直接召唤塔内 Boss；
- 进入后需向「NPC:虚无」购买[通天塔阶梯](I0OI_通天塔阶梯.md)，才能按进度开启下一场挑战。

完整流程和七层 Boss 资料见[通天塔攻略](../../info/楼层/隐藏与副本Boss/大型副本详表/通天塔.md)。
