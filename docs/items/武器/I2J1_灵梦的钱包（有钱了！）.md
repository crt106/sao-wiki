# I2J1 · 灵梦的钱包（有钱了！）

> **品质**：特殊　**类型**：武器　**版本**：2.51 新增

## 基础属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +150 |
| 敏捷 | +150 |
| 体力 | +200 |
| 生命值上限 | +15,000 |

## 被动技能：乱扔垃圾（高尚版）

- 只要物品位于英雄物品栏中，就会每 **0.2 秒**尝试发射一枚追踪御符。
- 在持有者周围 1,000 码内选择生命百分比最高的存活敌人；同百分比时优先更近的目标。
- 御符通常造成 **（当前体力 + 当前敏捷）×3** 的混乱／通用伤害。
- [喵露朵露薇](../../heroes/喵露朵露薇.md)装备时，伤害倍率降低为 **×1**。
- 持有者死亡或卸下钱包时，在途御符会立即消失；复活后若仍持有，发射会自动恢复。
- 与[灵梦的空钱包](I2J0_灵梦的空钱包.md)同时携带时，本物品优先，每个 0.2 秒周期最多发射一枚御符。

## 获取方式

通过宠物打造合成：

- [灵梦的空钱包](I2J0_灵梦的空钱包.md)
- [大块的金币](../素材/I2J2_大块的金币.md)

!!! warning "[喵露朵露薇](../../heroes/喵露朵露薇.md)的反向专属"
    [喵露朵露薇](../../heroes/喵露朵露薇.md)可以正常获得本物品的属性与追踪效果，但御符倍率不是通常的 ×3，而是 ×1。
