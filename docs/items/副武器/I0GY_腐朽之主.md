# I0GY · 腐朽之主

> **品质**：礼物　**类型**：副武器　**物品 ID**：`I0GY`　**有效物品等级**：8

## 物品本体属性

| 属性 | 实际值 |
|---|---:|
| 体力 | +380 |
| 攻击速度 | +100% |
| 移动速度 | +120 |
| 生命值上限 | +8,000 |

游戏说明写的是体力 +330，但真正挂载的 `A0LK` 为 实际数值为 380。旧页还把 `A0LK`、`A08K`、`A0F2` 错写成高级致命、分裂与吸血；这三个能力实际分别是体力、移动速度与攻击速度，没有任何暴击、分裂或吸血参数。

## 授权拾取附加属性

指定玩家拾取时，实际效果额外加入：

| 附加能力 | 数值 |
|---|---:|
| 攻击力 | +1,200 |
| 筋力 | +233 |
| 敏捷 | +233 |
| 体力 | +233 |
| 生命值上限 | +10,000 |

实际效果还再次尝试加入与物品本体相同的 `A0F2`。同一单位通常不能叠加同一 ID，因此授权持有者的当前可确认合计应为：

- 攻击力 +1,200；
- 筋力 +233、敏捷 +233、体力 +613；
- 攻击速度 +100%、移动速度 +120；
- 生命值上限 +18,000。

只有符合支持身份的玩家可以持有；不符合条件时物品会离开背包。丢弃后，额外属性与外观效果会消失。

## 获取方式

指定支持身份使用 `I0KV` 时，会一次性获得 `I0GY` 与 `I081`。正常掉落、商店、合成与打造均没有其他来源。
