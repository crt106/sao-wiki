# I2J2 · 大块的金币

> **类型**：素材　**版本**：2.51 新增

- **获取**：完整击破[纯狐](../../info/楼层/隐藏与副本Boss/纯狐.md)全部八段生命后，在正式结算时固定掉落一块。
- **用途**：与[灵梦的空钱包](../武器/I2J0_灵梦的空钱包.md)通过宠物打造，合成为[灵梦的钱包（有钱了！）](../武器/I2J1_灵梦的钱包（有钱了！）.md)。
- **战斗属性**：无。

!!! note "掉落时点"
    分段锁血或中途重建不会提前掉落；只有八段生命全部击破、挑战正式完成时才会生成。
