# I0LZ · 堕天使之羽饰

> **分类**：头部道具　**品质**：礼物　**使用限制**：指定玩家名专属

> **版本结论**：2.5 与 2.41 的游戏数据、玩家名限制和无来源状态一致；本页采用全中文标题，并以 2.5 重审结论为准，不另设版本 Tab。

## 实际属性与被动

本件与 `I0HA` 不是同一套效果，旧页复制 `I0HA` 数据是错误的。

| 效果 | 实际值 |
|---|---|
| 力量、敏捷、智力 | 各 +75 |
| 最大生命 | +2,500 |
| 每秒生命恢复 | +650 |
| 魔法恢复比例 | 能力 `A0XO` 的实际倍率为 50，不是智力或体力属性 |
| 暴击 | 30% 概率造成 5 倍普通攻击伤害 |
| 生命吸收 | 普通伤害的 35% 转化为生命 |
| 腐蚀攻击 | 攻击不加额外伤害，但使目标防御 -50，持续 5 秒 |
| 岁月献祭 | 330 范围内对地面敌人与中立单位造成献祭周期伤害，伤害数值 5,000 |
| 主动召唤 `A11N` | 召唤自定义 `hmil` 单位，持续 30 秒，冷却 60 秒 |

本件没有 `I0HA` 的移动速度 +100、魔伤减免 41%、敌方防御光环、被攻击反射或每秒全属性治疗。

## 获取与装备限制

当前持有规则如下：

- 玩家名精确等于“旧事如梦”时允许持有；
- 其他玩家拾取后，物品会被立即移出背包。

当前版本没有正常获取方式。
