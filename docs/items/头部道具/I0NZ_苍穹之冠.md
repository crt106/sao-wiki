# I0NZ · 苍穹之冠

> **品质**：传闻　**类型**：头部道具　**物品 ID**：`I0NZ`

!!! info "2.5 重审结论"
    旧页误把300金标价写成商店来源，并漏记每秒200点生命恢复。物品属性和主动效果与2.41相同；2.5新增了合成[王女之冠](I0Q9_王女之冠.md)的材料用途。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +150 |
| 敏捷 | +150 |
| 体力 | +150 |
| 生命值上限 | +20,000 |
| 防御力 | +50 |
| 每秒生命恢复 | +200 |

生命恢复和防御对应技能 ID 为 `A192`、`A193`；物品说明没有单列生命恢复，但实际仍会生效。

## 主动：世界之巅

使用 `A194` 后：

1. 持有者受到的伤害减少50%；
2. 持续2秒；
3. 物品冷却为 80 秒。

这项减伤与部分同类效果按加法叠加，而不是彼此相乘；总减伤达到100%时，伤害会归零。

## 获取方式

由[金沙之杯](../装备道具/I0BF_金沙之杯（稀有）.md)与[世界之花](../装备道具/I0GA_世界之花.md)合成：

`I0BF + I0GA → I0NZ`

这条配方在 2.41 与 2.5 均存在。当前版本没有商店或直接掉落来源；页面标注的金币价格不代表本物品可以购买。

## 合成用途

=== "2.5 狂猎"

    可与[罪欲](I0PX_罪欲.md)合成[王女之冠](I0Q9_王女之冠.md)：

    `I0PX + I0NZ → I0Q9`

=== "2.41 测试版"

    旧版没有 `I0Q9`，也没有这条两材料配方。
