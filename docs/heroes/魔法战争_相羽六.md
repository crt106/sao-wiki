# 魔法战争 · 相羽六

**主属性**：敏捷 · **英雄 ID**：`Ofar`

> 历史勘误：本英雄（`Ofar`，单位名「魔法战争」、称谓「相羽六」）一度被误标为「炮姐」。经核源码确认，**炮姐对应的单位是 `Ewrd`**，与本页无关。本页 E 技能（`S001`）在物编里残留了一段描述「电磁路径」的炮姐文案，属错挂提示，实际机制以触发器为准（见下）。

## 基础属性

| 属性 | 初始值 | 每级成长 | 备注 |
|------|--------|---------|------|
| 力量 | 20 | +1.0 | |
| 敏捷 | 20 | +0（无成长字段） | **主属性** |
| 智力 | 20 | +1.0 | |

- 攻击类型：**混乱（chaos）**，攻击间隔 1.8 秒，攻击距离 800（远程，蓝色弹道）。
- 主属性为敏捷，但物编 `[Ofar]` 段**未配置 `AGIplus` 字段**，故敏捷每级自然成长为 0；敏捷主要靠装备/技能堆叠。所有核心技能伤害均以**当前敏捷**结算。

!!! info "战意系统（核心资源）"
    全局变量 `udg_AXXZ` 即「战意」，是本英雄所有技能的伤害放大器：

    - **E（魔法刻印）** 普攻被刻印目标时，战意按 **1→2→…→10** 逐次累加，第 10 层时一次性大爆发后清零，再从 1 重新开始。
    - **Q（魔法回避）** 只要战意 ≥1，伤害系数额外 +5，但**不消耗战意**。
    - **R（雷神惩戒）** 施放瞬间把战意**直接设为 20**，随后每次幻影攻击消耗 1 点，直到耗尽。
    - **第5技（神枪天际）** 内圈追加伤害按 **敏捷×(战意+20)** 结算。

## 技能

???+ abstract "Q · 魔法回避　冷却：7秒　消耗：50魔法　3级解锁"

    自身快速向后方退去 **350 码**（朝向反向 180° 位移）并留下一具幻影（`e02A`，存活 3 秒）。幻影对原地 **350 码**范围内的敌方非建筑单位**分 3 段**造成混乱伤害（每段间隔约 0.2 秒）：

    - 基础每段伤害 = **当前敏捷 × 3**；
    - 若**战意 ≥1**，系数 +5 → **敏捷 × 8**（战意不消耗）；
    - 若装备专属武器アーサー，系数再 +5。

    | 条件 | 每段系数 |
    |------|---------|
    | 战意<1，无专属 | 敏捷 × **3** |
    | 战意≥1，无专属 | 敏捷 × **8** |
    | 战意<1，有アーサー | 敏捷 × **8** |
    | 战意≥1，有アーサー | 敏捷 × **13** |

    *技能ID：A0PO*　*伤害类型：混乱（ATTACK_TYPE_CHAOS / DAMAGE_TYPE_DEMOLITION）*

    !!! warning "描述与实测差异"
        Ubertip 写「幻影会击晕敌人 2 秒」，但触发器 `Trig...002` 中**只有伤害与血液特效，没有任何眩晕调用**。游戏内 Q 实际**不附带击晕**，物编里 2 秒/4 级的眩晕来自父技 `AOw2` 的残留学习提示，并未在触发逻辑里生效。

???+ abstract "W · 闪雷连射　冷却：22秒　消耗：50魔法　10级解锁"

    自身播放施法动作后，向前方**分轮射出穿透子弹**（弹幕单位 `e029`/`e02G`，混乱攻击），子弹具备穿透力，射击全程相羽六处于无敌（驱役推进）。每发子弹的伤害值由「固定底伤 + 敏捷系数项」构成，其中**敏捷系数项 `sh` = 当前敏捷 × 24**（装备アーサー后系数 +5 → **× 29**）。

    - **战意 < 5**：常规连射（3+4+5 三轮弹幕，每发约 `300 + sh`）。
    - **战意 ≥ 5**：追加更强一轮，弹幕分 **3 / 4 / 5 / 6 发**四轮放出，固定底伤逐轮递增（`100+sh`、`200+sh`、`300+sh`、`400+sh`），范围与威力均上升。

    *技能ID：A0PM*　*伤害类型：混乱*

    !!! warning "描述与实测差异"
        Ubertip 把伤害写成「100/200/300，敏捷 ×2/×3/×4」。实测触发器中敏捷系数项是**统一的 ×24（专属 ×29）**，「×2/×3/×4」并不成立；递增的只是各轮的**固定底伤** `100/200/300/400`。

???+ abstract "E · 魔法刻印　冷却：15秒　15级解锁"

    指向 1 名敌人施加持续 **7 秒**的刻印状态（buff `B020`）。相羽六**普攻命中被刻印目标**时触发被动追加伤害，并推动「战意」累积：

    - 每次普攻命中带 `B020` 的目标，战意 +1，并造成 **当前敏捷 × 当前战意** 的伤害（`DAMAGE_TYPE_UNIVERSAL`，即普通/全谱伤害）。
    - 战意达到 **10** 时，这一击按 **敏捷 × 10** 结算后**战意清零**，随后从 1 重新累积。
    - 若战意已被 R 等技能抬高（如设为 20），则该击直接按当前层数（×20 等）结算一次后清零。

    因此 E 本身的循环上限是**敏捷×10**；只有靠 R 把战意顶到 20，才会出现敏捷×20 的单次结算。

    *技能ID：S001*　*伤害类型：全谱（DAMAGE_TYPE_UNIVERSAL）*

    !!! warning "描述与实测差异"
        物编 `[S001]` 的 Ubertip 写的是「电磁路径……敏捷×1.0/×200、20% 麻痹」之类文案，**这是错挂的炮姐（`Ewrd`）技能描述**，与相羽六实际机制完全无关。真实机制以上述触发器（`Trig_XL2`）为准。E 不会在地面留下路径，也没有麻痹效果。

???+ abstract "R · 雷神惩戒　冷却：50秒　消耗：150魔法　20级解锁"

    指向 1 名敌人施放。施放瞬间**将战意直接设为 20**，本体隐身、化作幻影群（`e02E`/`e02F`），随后以 0.1 秒一跳的高速节奏在目标周围 100~600 码范围内不断瞬移、留下幻影逐次攻击目标，每跳消耗 1 点战意：

    - 每次幻影攻击造成 **当前敏捷 × 随机(3~7)** 的混乱伤害；装备アーサー后系数 +5 → **敏捷 × 随机(8~12)**。
    - 持续到战意耗尽（或目标失去 `B020`/死亡）；最后真身现身，用枪将目标**击退 800 码**（这一下不造成伤害）。

    施放台词：「相羽六：支配雷神　精神闪耀」。

    *技能ID：A0PQ*　*伤害类型：混乱*　*关联状态：B020 / BPSE*

???+ abstract "第5技 · 神枪天际　冷却：30秒　35级解锁（第5技能位）"

    在目标地点（施法距离 600）积蓄魔法，生成不断放大的能量体（`e02D`）后爆裂，形成多层环状弹幕（`e02C`，自外 600 码向内 0 码共 7 圈），并对范围内敌方非建筑单位造成两段混乱伤害：

    - **外圈（600 码内全体）**：每个目标 **当前敏捷 × 60**（装备アーサー后 +5 → **× 65**）。
    - **内圈（300 码内）**：内圈单位同时落在 600 码与 300 码两个判定组里，触发器对其结算 **3 段**——600 码组的 ×60、300 码组再来一段 ×60，外加追加段 **当前敏捷 × (战意 + 20)**。装备アーサー后两段基础均 +5（×65），追加段为 **敏捷 × (战意 + 20 + 5)**。

    即越靠近爆心的敌人吃到「外圈 + 内圈基础 + 内圈追加」三段伤害，战意越高内圈追加越强。

    *技能ID：A0PN*　*伤害类型：混乱*

    !!! warning "描述与实测差异"
        Ubertip 写「主属性 ×10（战意 ×1）」。实测外圈系数是**敏捷 ×60（专属 ×65）**，内圈追加为**敏捷 ×(战意+20)**，与提示文字的「×10」相差甚远，以触发器为准。

## 专属装备

**アーサー**（`I0PE`，硬性专属，仅相羽六体系使用）

详见物品页：[アーサー（I0PE）](../items/不归类/I0PE_アーサー.md)。

四个伤害技能（Q / W / R / 第5技）内部都用 `YDWEUnitHasItemOfTypeBJNull(施法者, 'I0PE')` 检测背包是否持有アーサー，命中则把对应系数 **+5**：

| 技能 | 无专属系数 | 装备アーサー后 |
|------|-----------|----------------|
| Q 魔法回避（A0PO） | 敏捷 ×3（战意≥1 时 ×8） | 敏捷 ×8（战意≥1 时 ×13） |
| W 闪雷连射（A0PM） | 敏捷系数项 ×24 | ×29（每发额外 +敏捷×5） |
| R 雷神惩戒（A0PQ） | 敏捷 ×随机(3~7) | 敏捷 ×随机(8~12) |
| 第5技 神枪天际（A0PN） | 外圈 ×60；内圈追加 ×(战意+20) | 外圈 ×65；内圈追加 ×(战意+25) |
| E 魔法刻印（S001） | 普攻追加 敏捷×战意 | **无专属分支**（触发器 `Trig_XL2` 未检测 `I0PE`） |

!!! note "注"
    专属加成是「系数 +5」而非「倍率」，故对低系数技能（如 Q ×3→×8）提升幅度相对更明显。**E 的追加伤害不享受专属加成**，其普攻被动逻辑中没有任何 `I0PE` 判断分支。
