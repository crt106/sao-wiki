# I07E · 苍蓝彼方

> **品质**：传说　**类型**：装甲　**物品 ID**：`I07E`

!!! info "本次重审结论"
    2.5 与 2.41 的属性和实际效果相同。旧 Wiki 把“恒温”和“魔方专属系数提升”误写成现行效果；当前能确认的只有全属性、攻击速度、生命上限和魔法回复，恒温与现行英雄联动均不生效。

## 基础属性

| 属性 | 实际数值 | 来源能力 |
|------|---------:|----------|
| 力量 | +75 | `A0FZ` |
| 敏捷 | +75 | `A0FZ` |
| 体力 | +75 | `A0FZ` |
| 攻击速度 | +80% | `A0F1` |
| 最大生命值 | +10000 | `A0TE` |
| 每秒魔法回复 | +40 | `A0XP` |

对应技能 ID 为 `A0XP`、`A0FZ`、`A0F1`、`A0TE`。其中 `A0XP` 虽显示“体力恢复 Lv4”，实际效果是**魔法回复 +40**，不是生命回复或体力属性成长。

## 显示技能核查

### 恒温

`-cxitem` 与物品详情都写着“不受寒冷和炎热影响”，但实际每3秒结算的生命损失与魔法损失豁免范围中都没有 `I07E`。因此当前不能把苍蓝彼方列为环境免疫装备：

- 不会阻止寒冷／高温区域每3秒造成的1000点生命损失；
- 不会阻止高温区域每3秒扣除的1000点魔法；
- 也没有抵抗51～60层藤蔓的能力。

!!! danger "显示有效，实际未生效"
    2.5 中的“恒温”只有说明文字，实际不会提供环境伤害免疫。

### 雷属性上升Lv3

旧技能 `A0JN` 和 `A0QT` 曾与“雷属性上升 Lv3”有关，但当前斯托蕾亚与御坂美琴在正常玩法中都不会获得这些旧技能。

**结论**：苍蓝彼方不会提高当前斯托蕾亚的 Q、W、E、破坏之雷或 `A0JO`，也不能把上述旧御坂倍率计入现行效果。

## 获取方式

击败指定[29 层天空龙](../../info/楼层/21-30层.md)（单位 ID：`njgb`）时，必定掉落 1 件 `I07E`。

当前没有商店、合成、扭蛋或其他来源。

## 使用限制

任何英雄都可以持有本物品并获得基础属性；它不是当前版本的斯托蕾亚专属装备。
