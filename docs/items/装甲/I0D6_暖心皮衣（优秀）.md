# I0D6 · 暖心皮衣

> **品质**：优秀　**打造物品等级**：36

> **2.5 复核结论**：旧页没有还原打造成功率，且把魔抗写成正值。每次材料充能获得本物品的概率为 50%。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +90 |
| 敏捷 | +90 |
| 智力 | +90 |
| 生命值上限 | +5000 |
| 所受魔法伤害 | -30% |

## 隐藏效果

**御寒**：寒冷区域每 3 秒会对未获豁免的单位造成 1000 点自伤；持有 `I0D6` 的单位可获得对应豁免，不受这笔环境伤害。

物品虽然可以点击使用，但当前没有可确认的主动效果；`A06H` 也不会因此成为可用技能。

## 获取方式

在 28 层防具打造中使用[白狼皮](../素材/I08M_28层白狼皮.md)：

- 打造成功率为 `1/2`；
- 成功后固定获得暖心皮衣；
- 成功与失败都会消耗 1 次材料充能。

因此每次材料充能的实际获得概率为 **1/2（50%）**。
