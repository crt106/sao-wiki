# I0O5 · 九天凤凰琴

> **品质**：传闻　**类型**：副武器　**物品 ID**：`I0O5`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +80 |
| 敏捷 | +255 |
| 体力 | +100 |
| 攻击速度 | +100% |
| 生命值上限 | +13,000 |

物品还带有魔法恢复技能 `A0XO`，参数为 `50.0`。它不是体力或生命恢复；最终面板效果仍待实际确认。

## 被动效果：凤啼鸣

攻击者持有本物品并进入攻击触发后，等待 0.3 秒，对当前目标连续结算两笔混乱攻击、火焰伤害：

1. 持有者结算时的当前生命值 ×5%；
2. 持有者结算时的当前筋力、敏捷、体力之和 ×1。

随后再等待 1.7 秒解除持有者自己的冷却标记，所以两笔伤害是一组固定组合，内置冷却约 2 秒。旧页把“天命”和“凤啼鸣”写成两个可独立触发的效果，实际当前效果每次有效触发都会一起结算。

## 获取方式

击败朱雀（单位 ID：`n01P`）时，必定掉落一件 `I0O5`。

## 合成用途

本物品还是“梦幻”的第三件材料：

[I0MC · 随身佳肴](../不归类/I0MC_随身佳肴.md) + [I0K2 · BUG化·结晶](../特殊/I0K2_BUG化·结晶.md) + **I0O5 · 九天凤凰琴** → [I0QB · 梦幻](I0QB_梦幻.md)

三件材料各消耗 1 件，生成 1 件梦幻。
