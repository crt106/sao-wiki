# I0G4 · 骷髅指挥官之剑

> **品质**：稀有　**类型**：副武器（剑类）　**物品 ID**：`I0G4`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 体力 | +105 |
| 生命值上限 | +1,500 |

## 被动效果：强行夺取

持有者发起普通攻击时：

- 攻击者恢复 `500 + 攻击者当前敏捷 ×10` 点生命；
- 目标被直接扣除 `1,000 + 目标自身当前敏捷 ×20` 点生命。

旧页把第二式也写成了攻击者敏捷，实际按**被攻击目标**的敏捷计算；非英雄目标通常按0点英雄敏捷处理。这项扣血不受常规伤害减免影响，也不会触发吸血。

触发后，所有玩家和所有副本中的同类物品都会进入 3 秒共享冷却。回血数值本身正确，但飘字可能显示在其他单位身上或不显示。

## 获取方式

击败 16 层骷髅指挥官（单位 ID：`nepl`）时，必定掉落一件 `I0G4`。
