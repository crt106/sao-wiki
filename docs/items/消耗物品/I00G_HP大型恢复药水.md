# I00G · HP大型恢复药水

> **分类**：消耗物品　**售价**：1,000 金　**使用次数**：10 次

> **版本结论**：2.5 与 2.41 的游戏数据、药水追加恢复和获取方式一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际效果

| 结算层 | 效果 |
|---|---|
| 能力 `A06E` | 恢复 2,500 点生命 |
| 药水实际效果 | 额外恢复 `当前力量 × 10` |
| 实际总恢复 | `2,500 + 当前力量 × 10` |
| 冷却 | 7 秒 |

筒隐月子（单位 ID：`Hvwd`）使用时，还会因英雄专属效果额外恢复 60 点生命；其他英雄没有这项加成。

## 获取方式

### 商店

| 商店单位 | 显示名称 | 价格 |
|---|---|---:|
| `nckb` | 莉兹贝特 | 1,000 金 |
| `h06N` | 尔雅 | 1,000 金 |
| `h079` | 维丽亚 | 1,000 金 |

### 地图宝箱

| 宝箱 | 实际结果 |
| --- | --- |
| `ndrv` 宝物箱子 | 固定获得 2 件 |
| `ndrv` 宝物箱子 | 与 `I03T` 二选一，50% |
| `ndrv` 宝物箱子 | 四选一，25% |

!!! note "次数口径"
    每件掉落或购买到的物品都带 10 次使用次数，不是上述宝箱总共只提供 10 次。
