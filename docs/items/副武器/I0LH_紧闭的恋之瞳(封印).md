# I0LH · 紧闭的恋之瞳（封印）

> **品质**：礼物　**类型**：副武器　**物品 ID**：`I0LH`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 攻击力 | +100 |
| 筋力 | +50 |
| 敏捷 | +50 |
| 体力 | +50 |
| 生命恢复 | +20/秒 |

游戏说明写有攻击速度 +50%，但实际不提供攻击速度加成。技能 `A07Q` 的名称仍写“生命恢复 10”，实际为每秒恢复 20 点生命。

## 主动技能：力量外泄

物品可主动使用，对应技能 ID 为 `AIre`：

- 恢复 600 点生命；
- 恢复 300 点魔法；
- 冷却 7 秒；
- 无魔法消耗。

## 获取方式

符合支持者奖励资格的玩家使用 `I0KV` 时，会一次性获得 `I0LG`、`I0LH`、`I0LJ`、`I0LI`。普通掉落、商店、合成与打造均没有其他来源。
