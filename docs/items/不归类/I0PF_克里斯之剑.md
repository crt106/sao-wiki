# I0PF · 克里斯之剑

> **品质**：不归类　**物品等级**：82　**物品 ID**：`I0PF`　**专属英雄**：[绝剑·优纪](../../heroes/绝剑_优纪.md)（`Hant`）

!!! info "本次重审结论"
    物品本身、持有条件和王珏掉落在 2.5 与 2.41 相同；变化发生在[优纪](../../heroes/绝剑_优纪.md)的技能效果。旧页把拾取提示“技能系数+5”当成统一效果，但 2.5 的 Q、W、E 各增加 10，R 只把加数 10 提高到 19。旧页还漏写了移动速度 +500 与禁止[物品镜像](../特殊/I0PZ_物品镜像.md)复制。

## 基础属性

| 属性 | 实际数值 | 来源能力 |
|------|---------:|----------|
| 敏捷 | +400 | `A1FO` |
| 攻击速度 | +240% | `A1FP` |
| 最大生命值 | +30000 | `A1FL` |
| 移动速度 | +500 | `A1FQ` |

对应技能 ID 为 `A1FL`、`A1FO`、`A1FP`、`A1FQ`。说明文字只列出敏捷、攻速和生命，遗漏了 `A1FQ` 提供的移动速度 +500；物品战力为 55,000。

!!! note "移动速度还有间接增益"
    `A1FQ` 会提高[优纪](../../heroes/绝剑_优纪.md)的实际移动速度，因此除了上表的显式分支，还会继续抬高 E、R 公式中的“当前移速”，并可能让初始攻击残影越过400移速的翻倍阈值。最终移速受 Warcraft 上限、减速与其他状态影响，不能简单把500原样代入公式。

## 拾取限制

本物品是[优纪](../../heroes/绝剑_优纪.md)（英雄 ID：`Hant`）的专属武器；其他英雄拾取后，物品会被移出背包。四项技能强化只对[优纪](../../heroes/绝剑_优纪.md)的对应技能生效。

## 获取方式

**击败王珏（单位 ID：`n02B`）时，必定掉落 1 件。**

同一名王珏还会同时掉落：

- `I0Q3`
- `I0PD`
- `I0PE`
- `I0PF`
- `I0FE`

该掉落为必定掉落。当前 2.5 没有其他正常获取方式；物品等级 82 也不代表来自 82 层。

## 其他限制

[物品镜像](../特殊/I0PZ_物品镜像.md)能力 `A1LD` 明确把 `I0PF` 列入禁止复制清单，尝试复制时只显示失败提示，不会创建副本。
