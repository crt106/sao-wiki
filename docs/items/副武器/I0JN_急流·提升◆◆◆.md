# I0JN · 急流·提升◆◆◆

> **品质**：优越　**类型**：副武器　**物品 ID**：`I0JN`　**有效物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 敏捷 | +105 |
| 攻击速度 | +80% |
| 生命值上限 | +2,500 |

旧页把 `A032` 写成“精准射击 Lv2”，但该技能实际只提供敏捷 +105，没有射击或命中效果。

## 获取方式

这是急流提升链的最高阶：

[I0JM · 急流·提升](I0JM_急流·提升.md) → [I0JL · 急流·提升◆](I0JL_急流·提升◆.md) → [I0JO · 急流·提升◆◆](I0JO_急流·提升◆◆.md) → **I0JN · 急流·提升◆◆◆**

每次施放 `A0Y9` 只替换一阶；当前效果零费用、必定成功。

## 融合用途

本物品还是“凝冰”的三件材料之一：

[I09D · 轻羽光弓（传说）](../武器/I09D_轻羽光弓（传说）.md) + **I0JN · 急流·提升◆◆◆** + [I09G · 圣物-蓝炎宝石（稀有）](../特殊/I09G_圣物-蓝炎宝石（稀有）.md) → [I0G2 · 凝冰（融合）](../不归类/I0G2_凝冰（融合）.md)

融合实际效果会移除三件材料并发放一件 `I0G2`。
