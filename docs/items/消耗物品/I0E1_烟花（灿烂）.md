# I0E1 · 烟花（灿烂）

> **类型**：消耗物品　**物品 ID**：`I0E1`

!!! danger "“获得扭蛋卷 ×2”没有当前效果"
    当前版本中，`I0E1` 只用于烹饪公式，没有可用的烟花效果，也不会发放扭蛋卷。因此说明中的“获得扭蛋卷 ×2”当前不生效。

## 获取方式

当前唯一可定位的来源是亚丝娜旧烹饪公式：

| 材料 | 数量 |
|---|---:|
| [面粉](../素材/I040_面粉.md) | 1 |
| [鸡蛋](../素材/I041_鸡蛋.md) | 1 |
| [草莓](../素材/I0E6_草莓.md) | 1 |

该配方只消耗表中列出的四种材料。当前没有活动发放、商店、掉落或其他直接来源，旧页所写“活动或特殊途径获得”没有当前版本依据。

!!! info "配方解锁条件"
    任意单位拾取 `I0E5`「商店:食物大动工」，或亚丝娜（英雄 ID：`Hmkg`）拾取任意物品后，即可使用该配方。重复满足条件不会重复产出。
