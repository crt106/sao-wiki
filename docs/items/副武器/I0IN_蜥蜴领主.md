# I0IN · 蜥蜴领主

> **品质**：优越　**类型**：副武器　**物品 ID**：`I0IN`　**有效物品等级**：33

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +120 |
| 敏捷 | +120 |
| 体力 | +120 |
| 生命值上限 | +4,500 |

全属性来自 `A0TR` 的 90 与 `A0C7` 的 30，相加为 120；生命值来自 2,000 与 2,500 两项，相加为 4,500。

扩展提示文字还写有“魔法防御 35”，但实际效果只有全属性与生命值加成，不提供魔法防御。因此旧页的魔法防御 +35 不计入实际属性。

## 获取方式

### 固定 Boss 掉落

击败指定的 `ntkt` 首领后，会在以下两件物品中随机掉落一件：

- `I0IN`：权重 50；
- `I0A4`：权重 50。

因此蜥蜴领主的掉落概率为 50%。

### 3 城武具打造

英雄使用 [I0DC · 3城商店武器打造](../特殊/I0DC_3城商店武器打造.md) 时，如果背包持有 [I07O · 33层巨蜥的大牙](../素材/I07O_33层巨蜥的大牙.md)，打造成功率为 50%；成功或失败都消耗大牙的一次使用次数。成功后随机获得 `I0I0`、`I0IB`、`I0IN` 中的 1 件。

若三种成功结果等概率，则每次打造获得本物品的概率约为 1/6（16.67%）；最终分布仍建议以长期游戏统计为准。
