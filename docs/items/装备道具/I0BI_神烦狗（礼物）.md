# I0BI · 神烦狗

**品质**：礼物 · **分类**：装备道具 · **物品 ID**：`I0BI` · **物品战力**：21,500

这是一件按玩家名授权的订制支援物品，不是普通掉落或商店装备。物品说明里的属性与能力名长期没有同步更新；下表以 2.5 实际效果为准。

## 实际属性与常驻能力

| 项目 | 2.5 实际效果 | 说明文字 |
|------|--------------|----------|
| 敏捷 | 授权持有者拾取后由 `A09M` 增加 **295** | +105 |
| 最大生命 | 物品能力 `A0JY` 增加 **5,000** | +2,000 |
| 法术伤害减免 | `A0BT` 的减免参数为 **50%** | “魔法防御 50” |
| 物理闪避 | `A0Z4` 提供 **50%** | 50 |
| 移动速度 | 授权拾取后增加 **100** | 未写 |
| 固定生命恢复 | 授权拾取后每秒恢复 **80** | 写作“生命恢复 Lv5” |
| 周期生命恢复 | 每秒直接恢复 `当前力量＋敏捷＋智力` 的 **30%** | 未写 |
| 周围持续伤害 | 永久献祭游戏数据，半径 **600**，每个周期 **10,000** | 未写明数值 |

!!! warning "说明文字不能作为实际属性"
    物品自带技能 `A0XW`、`A0JY`、`A0BT`、`A0Z4` 中没有“敏捷 +105”或“生命 +2000”。指定英雄拾取后实际额外获得的是敏捷 +295、每秒回血 80 和移动速度 +100，因此旧页照抄的属性不成立。

周期回血会正确恢复持有者生命，但绿色飘字可能使用另一名单位的属性，显示数字与真实恢复量不一定一致。

## 实际能力

### 攻击发起追伤

持有者每次发起普通攻击时，会立刻对被攻击目标追加：

`持有者当前力量 × 1 ＋ 2,500`

该笔伤害使用混乱攻击／通用伤害类型，没有说明文字所写的5秒个人冷却。

### 施法后的五道冲击

任意英雄持有本物品并施放技能时，会产生 5 道随机方向的冲击，滑行距离 600、持续 0.8 秒；该效果有 5 秒的多人共享冷却。

!!! danger "当前伤害来源异常"
    五道冲击可能使用另一名单位的敏捷，或在没有对应角色时造成 0 伤害；所有持有者还共用 5 秒触发间隔。实际命中表现仍待确认。

### 英雄联动

- [草壁操](../../heroes/暗杀者.md)（单位 ID：`Orkn`）拾取时，“双剑提升等级”增加5；丢弃时减少5。该数值加在 Q／W／E 键技能的倍率。
- [桐人](../../heroes/封弊者_桐谷和人_桐人.md)（单位 ID：`Hamg`）拾取时，独立双剑提升等级增加5；**丢弃时不会减少5**。

!!! danger "桐人丢弃后不会扣回加成"
    当前版本中，桐人拾取时会增加 5 点双剑加成，但丢弃后这 5 点仍会保留。建议按正常持有流程使用。

### 环境豁免

本物品同时列入寒冷扣血区和炎热扣蓝区的豁免清单：

- 寒冷区域原本每轮对不合格单位造成 1,000 点自伤，持有本物品时跳过。
- 炎热区域原本每轮扣除 1,000 点魔法，持有本物品时跳过。

## 获取方式与装备限制

1. 每局只能通过订制补给领取 1 次。
2. 只有指定玩家可以领取。
3. 地图上的“支援补给员 No.2”出售 `I0KX`“外物补给品2”；授权玩家拾取后获得 `I0BI`，本局领取资格随即用尽。
4. 未授权玩家拾取 `I0BI` 时，物品会被实际效果立即移出背包，并提示这是订制专属。

**不存在的获取途径**：普通 Boss 掉落、扭蛋、合成、常规商店购买。它也不是可供普通玩家刷取的“礼物池”物品。
