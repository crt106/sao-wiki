# I0HX · ★★★秘密的夜色

> **物品名星级**：★★★　**游戏内品质**：★★★★　**扭蛋池当前效果**：物品等级 203

> **2.5 复核结论**：物品等级 203 是三星扭蛋池当前效果，不是“203 层”。物品名与池级均为三星，但游戏内品质仍写四星，当前版本自身不一致。除扭蛋外，地图还有一只固定宝物箱必掉本物品。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +70 |
| 敏捷 | +70 |
| 智力 | +70 |
| 生命值上限 | +5000 |
| 防御力 | +55 |
| 每秒生命恢复 | +140 |

能力名仍写“生命恢复 70”，但实际数值为 140，实际恢复量是每秒 140。

## 获取方式

### 固定宝物箱

指定一只 `ndrv` 宝物箱，其一次性掉落池只有 `I0HX` 一项、权重 100。箱子首次死亡时**必定掉落 1 件**，随后专属实际效果移除。

### 圣诞扭蛋 A

拾取[礼物：混乱之圣诞扭蛋](../特殊/I0AX_礼物混乱之圣诞扭蛋.md)且持有[圣诞礼物·扭蛋卷](../特殊/I0BE_圣诞礼物·扭蛋卷.md)时：

- 星级随机值为 `1～15`；
- 取到 `10、11、12` 时进入 物品等级 203 池，概率为 `3/15`；
- 当前 物品等级 203 池共有 6 件物品。

按当前资料均匀抽取时，本物品单次扭蛋概率为 **3/15 × 1/6 = 1/30（约 3.33%）**。
