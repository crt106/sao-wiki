# 数字君

*称谓：458356800* · **英雄 ID**：`Opgh` · **主要伤害属性**：敏捷 / 智力

!!! info "版本说明"
    数字君是旧 Wiki 的历史漏页。2.41 与当前 2.5 的英雄属性和技能没有明确版本差异，因此本页只保留一份经当前版本复核的内容，不设置重复的版本 Tab。

!!! warning "实际技能解锁等级"
    技能位为 `A0ZD / A0ZE / 0 / A0ZF / A0ZI / A1B4`，实际对应 **Q 3级 / W 10级 / E 20级 / R 35级 / 身体强化 120级**；15级没有新技能。旧调研稿把后三项写成15/20/35级，属于记录错位。

## 基础属性

| 属性 | 初始值 | 每级成长 |
|---|---:|---:|
| 力量 | 20 | +1.0 |
| 敏捷 | 20 | +1.0 |
| 智力 | 20 | +1.0 |

基础攻击为 `4d4`，攻击类型为穿刺，护甲类型为小型。单位初始携带 `A0ZC`、`A0ZB` 与物品栏。

## 技能

???+ abstract "D · 暗影魅惑　被动　初始自带"

    *技能 ID：`A0ZB`*

    英雄（单位 ID：`Opgh`） 发起攻击时制造幻影，并对目标追加：

    **敏捷 × 10**

    未持有专属装备时，伤害类型为穿刺攻击／普通伤害；触发后约有 **2.8 秒**间隔，接近 3 秒。

    持有[复仇刻印](../items/装备道具/I055_复仇刻印.md)时，追加伤害改成直接扣减目标当前生命，且约 **0.1秒**后即可再次触发。这种扣血不会触发受伤类联动效果。

    !!! warning "适用范围"
        数字君（单位 ID：`Opgh`）可以触发该效果。

???+ abstract "Q · 操影术·爆破　冷却：1秒　魔耗：50　3级解锁"

    *技能 ID：`A0ZD`*

    普通施放时，在自身前方约100码创建影子单位 `h057`，让其快速移动到目标点，并赋予 **15秒**限时生命。

    再以已有影子为目标时，当前效果会交换本体与影子的位置、移除该影子，并对原影子附近 **300码**敌人造成：

    **智力 × 7**

    伤害为魔法攻击 / 魔法伤害。

    !!! warning "描述与当前表现差异"
        游戏内提示写的是“敏捷×7”，实际伤害按 **智力×7** 结算。“点影子换位”在当前版本中的稳定性仍待确认。

???+ abstract "W · 影射·吞噬　冷却：7秒　魔耗：60　10级解锁"

    *技能 ID：`A0ZE`*

    向目标投射黑影。游戏数据本体配置 **300点**伤害并使目标无法行动 **1.5秒**；伤害响应在数字君对这名目标造成伤害时再追加：

    **敏捷 × 15**

    因而单次正常命中的完整口径为 **300 + 敏捷×15** 魔法伤害。目标标记会保留约 **2秒**，作为 E 连段的标记。

???+ abstract "E · 鸟影·疾风腿　冷却：1秒　魔耗：115　20级解锁"

    *技能 ID：`A0ZF`*

    游戏内提示设计了两条路线：

    1. 800码内存在 W 标记目标时，交换位置并消耗附近影子，造成“敏捷×15×影子倍率”的350码范围伤害；
    2. 没有标记时向前冲刺300码，结束后对200码范围造成伤害。

    当前效果对玩家数字君可稳定当前版本核对的是第二条：冲刺约 **300码 / 0.3秒**，随后对周围 **200码**敌人造成：

    **智力 × 10**

    该段使用穿刺攻击 / 毁灭伤害。持有[复仇刻印](../items/装备道具/I055_复仇刻印.md)时，冲刺期间直接设为无敌；未持有时则临时移除 `A0ZB` 并换入 `A0ZZ`。

    !!! danger "W→E 标记连段当前通常不会生效"
        玩家数字君（单位 ID：`Opgh`）使用 W 后，E 通常仍会进入普通冲刺路线，而不会触发标记换位路线。另一单位 ID `O019` 的相关效果与玩家英雄并不共用。

        即使偶尔触发影子消耗效果，最终倍率也并不稳定，不能直接按旧 Wiki 所写的影子数量计算。

???+ abstract "R · 奥义·影·幻象天星　冷却：45秒　魔耗：600　35级解锁"

    *技能 ID：`A0ZI`*

    在施法位置形成持续 **10 秒**的影界。影界存在时，数字君在中心 **500 码**内每次施放技能，会以自己为中心对 **350 码**敌人造成：

    **敏捷 × 15**

    该段使用混乱攻击 / 魔法伤害。

    !!! note "首次触发"
        只有数字君（英雄 ID：`Opgh`）可以触发。开启影界的这次施法不保证立即落下第一颗流星；影界形成后，在中心范围内继续施放技能可以稳定触发。

???+ abstract "第5技 · 身体强化　被动　120级解锁"

    *技能 ID：`A1B4`*

    攻击力奖励能力，实际数值为 1000，即获得后增加 **1000点攻击力**。该 ability 没有主动按钮逻辑。

## 专属装备

- E「鸟影·疾风腿」：冲刺期间使用真正的无敌状态，而非临时替换被动能力。
