# I0G3 · 普德之衣

> **品质**：普通　**物品等级**：物品等级 19

> **2.5 复核结论**：属性与旧页一致；获取不是随机防具池，而是穷人的布料对应的直接产物。每次材料充能有 50% 概率获得 1 件，成功和失败都会消耗充能。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +30 |
| 敏捷 | +30 |
| 智力 | +30 |
| 生命值上限 | +500 |
| 防御力 | +15 |

## 获取方式

在防具打造中使用[8 层穷人的布料](../素材/I046_8层穷人的布料.md)：

- 成功时直接获得 `I0G3`；
- 成功率为 **1/2（50%）**；
- 成功或失败都会消耗 1 次材料充能。

物品等级 19 是物品等级，不代表 19 层掉落，也没有发现独立商店或 Boss 来源。
