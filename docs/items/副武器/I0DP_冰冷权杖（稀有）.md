# I0DP · 冰冷权杖（稀有）

> **品质**：稀有　**类型**：副武器（法杖）　**物品 ID**：`I0DP`　**物品等级**：8

## 持有属性

| 属性 | 实际值 |
|---|---:|
| 体力 | +205 |
| 生命值上限 | +2,150 |

体力由 150 与 55 两项相加得到。旧页写成生命值 +4,650，是把 `A06E` 的 2,500 点**主动治疗量**错误叠加到了 `A0H5` 的 2,150 点生命上限上。

## A06E 治疗能力

游戏数据中还包含技能 `A06E`：

- 能力本体治疗 2,500，冷却 7 秒；
- 使用时额外恢复当前筋力 ×10；
- [筒隐月子](../../heroes/筒隐月子.md)使用时另恢复 60。

当前无法确认玩家在正常持有状态下能否主动使用该技能，因此本页不把 2,500 点治疗计入生命上限或稳定可用效果。

## 获取方式

击败单位 ID 为 `nsra` 的 69 级对应敌人时，会获得两组 100% 掉落：

1. 固定掉落 `tpow`；
2. 固定掉落冰冷权杖 `I0DP`。

因此本物品是该敌人的必掉物品。
