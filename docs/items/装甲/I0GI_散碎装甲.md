# I0GI · 散碎装甲

> **品质**：普通　**打造物品等级**：49

> **2.5 复核结论**：游戏说明和新提示都写全属性 180，但实际同时加载的两项全属性能力分别为 90 和 70，执行总值是 **160**。锻造单次最终概率为 25%；迷宫野兽路线的单次击杀概率可还原为 1/28。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +160 |
| 敏捷 | +160 |
| 智力 | +160 |
| 生命值上限 | +5000 |
| 防御力 | +35 |

## 隐藏效果：降温

炎热区域会每轮对未获豁免的单位扣除 1000 点魔法值；持有 `I0GI` 的单位位于环境免疫中，不受这笔魔法扣减。

## 获取方式

### 防具打造

使用[39 层冰柔之毛](../素材/I0AZ_39层冰柔之毛.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0GI` 或 `I0L5`。

因此每次材料充能获得散碎装甲的概率为 **1/2 × 1/2 = 1/4（25%）**。

### 迷宫野兽

击败 `nowb`（Lv40 雪地的小野兽）时，有 `1/7` 概率从4件49级奖励 `I0AZ`、`I0B0`、`I0GI`、`I0L5` 中随机掉落一件，因此单次击杀获得散碎装甲的概率为 **1/28（约3.57%）**。
