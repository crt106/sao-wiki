# I0HU · 羽翼斗昆虫甲

> **品质**：普通　**打造物品等级**：29

> **2.5 复核结论**：旧页直接采用说明文字的生命 +5000，但当前资料存在冲突；最终生命加成需在游戏内确认。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +50 |
| 敏捷 | +50 |
| 智力 | +50 |
| 生命值上限 | 说明写 +5000；当前资料无法排除实际仅 +2500 |

三属性由 `A0C7` 的全属性 +30 与 `A0DC` 的全属性 +20 相加得到。生命值最终是 +2500 还是 +5000，仍需在游戏内查看最大生命值确认。

## 获取方式

在防具打造中使用[虫蛋壳](../素材/I004_虫蛋壳.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0HQ` 或 `I0HU`；
- 无论成功与否都会消耗 1 次材料充能。

每次材料充能获得本物品的名义概率为 **1/4（25%）**。游戏数据中的木材价格数值没有商店库存，不能作为购买来源。
