# I0P6 · 食物:药酒

> **类型**：消耗物品　**物品 ID**：`I0P6`　**标示价格**：50 金　**入口冷却**：20 秒

## 使用效果

使用能力 `A1F5` 后临时获得能力 `A1F9`：

| 属性 | 实际变化 | 持续时间 |
|---|---:|---:|
| 筋力 | +100 | 3 秒 |
| 敏捷 | +100 | 3 秒 |
| 体力 | +100 | 3 秒 |

3秒后移除 `A1F9`，三项属性恢复原值。该物品与本组食物共享冷却。

## 获取方式

施放打造技能 `A0Y9`，通过计数合成获得：

| 材料 | 消耗 |
|---|---:|
| [小型体力药水](I0H7_小型体力药水.md) | 1 充能 |
| [HP小型恢复药水](I00F_HP小型恢复药水.md) | 1 充能 |
| [普通酒水](../素材/I0PI_普通酒水.md) | 1 充能 |

!!! warning "[药材](../素材/I0MZ_药材.md)不是实际材料"
    配方记录末尾还写了[药材](../素材/I0MZ_药材.md) `I0MZ ×1`，但材料种类数声明为 3；数量合成配方 只保存前三组参数，因此当前合成不检查也不消耗[药材](../素材/I0MZ_药材.md)。

!!! warning "当前版本会发放三次药酒"
    一次成功合成会连续发放 3 份 `I0P6`。它可能表现为三件物品，也可能合并为一件多充能物品，实际表现仍待确认。

当前没有商店、掉落或其他直接获得方式；`50` 金只是标示价格。
