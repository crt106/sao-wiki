## 获取方式

[28 层隐藏区域](../../info/楼层/隐藏与副本Boss/index.md#smile-coffin)的幽冥单位 ID 为 `nrvi`。击败任意 `nrvi` 后都会掉落：

- `I09F`；
- [遗忘 `I0H8`](../装备道具/I0H8_遗忘.md)；
- 通用材料 `I0BE`；
- 灵魂·国色天香 `I09O`。

四件物品都没有随机判定。当前地图中唯一的 `nrvi` 为指定宝箱，因此本物品为 **必掉**。

当前没有正常商店、扭蛋、合成或其他直接获得方式。
