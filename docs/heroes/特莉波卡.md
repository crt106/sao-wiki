# 特莉波卡

**主属性**：敏捷 · **英雄 ID**：`H07E`

## 基础属性

| 属性 | 初始值 | 每级成长 |
|------|--------|---------|
| 力量 | 40 | +1.0 |
| 敏捷 | 40 | +1.5 |
| 智力 | 40 | +1.0 |

!!! note "攻击伤害取值说明"
    本英雄 Q/W/E 公式中的「攻击伤害」均为面板**平均攻击力**，即代码中
    `(最小攻击 + 最大攻击) / 2`，并非最大攻击。下文公式统一以「平均攻击」表述。

## 技能

???+ abstract "Q · 螺旋切割　冷却：8秒　3级解锁"

    原地旋转一圈，对**周围 300 范围**内的全部敌人各造成一次斩击，伤害为
    **平均攻击 + 敏捷 × 30**。

    - 伤害类型：**混乱**（无视护甲）。
    - 施法瞬间会短暂定身自身约 0.05 秒播放旋转动作，结束后恢复行动。

    *技能ID：A1FH*（消耗 50 魔法）

???+ abstract "W · 收割　冷却：12秒　10级解锁"

    瞬移到指定目标身后（约 80 距离），挥镰造成一次伤害并附加 **2 秒眩晕**。

    - 基础伤害为 **平均攻击 + 敏捷 × 25**，再乘以一个 **1 / 2 / 3 倍的随机倍率**
      （等概率随机整数 1~3，相当于约 2/3 的概率打出 2 倍或 3 倍「暴击」）。
    - 伤害类型：**混乱**（无视护甲）。眩晕通过马甲技能 `A18S` 施加。

    *技能ID：A1FI*（消耗 100 魔法，施法距离 850）

    !!! warning "描述与实测差异"
        工具提示写「概率触发 2~3 倍暴击」，实际是对基础伤害乘以 `GetRandomInt(1,3)`，
        即结果为基础伤害的 **1 倍 / 2 倍 / 3 倍**（各约 1/3 概率），并非「2~3 倍」。

???+ abstract "E · 死亡狂镰　冷却：30秒　15级解锁"

    锁定单体目标后进入疯狂连击状态，持续约 **2 秒**（计数超过 2 后结束）。

    - 每 **0.1 秒**对目标造成一次伤害，单次伤害为 **敏捷 × 1.5 + 平均攻击 × 0.2**；
      期间不断在目标周围 120~200 范围内瞬移并贴身输出。
    - 持续期间**自身无敌**，并被定身、关闭转身（无法被打断）。
    - **可手动中止**：在持续期间下达任意指令即会提前结束狂镰。
    - 结束时会移除并重新添加 W（`A1FI`），从而**立即刷新「收割」的冷却**。

    *技能ID：A1FJ*（消耗 100 魔法，施法距离 850）

    !!! warning "描述与实测差异"
        工具提示标注伤害类型为「普通攻击」，但触发器内每跳实际以
        `ATTACK_TYPE_CHAOS / DAMAGE_TYPE_DEMOLITION`（**混乱 · 无视护甲**）结算，
        并非普通攻击伤害。

???+ abstract "R · 疾风破虚　冷却：被动　20级解锁"

    纯被动属性技能：直接为自身**增加 15000 点攻击力**，并将**攻击间隔压低至 1.4**。

    *技能ID：A1H2*

    !!! note "实现说明"
        本技能为属性加成型被动（基于 `Aamk`），数值由物编直接挂载，没有额外触发器逻辑；
        升级到 20 级习得后即永久生效。

???+ abstract "D · 彗星消除　冷却：65秒　初始自带"

    特莉波卡的核心生存机制，兼具被动与主动两部分。

    **被动（伤害延迟）**：受到的伤害**不会立即扣血**，而是被记入「累计伤害」并刷新；
    随后由计时器**每 0.1 秒**扣除一部分：

    - 每跳以 `DAMAGE_TYPE_DEATH` 对自身结算「累计伤害 × 5%」，逐步把欠账还清。
    - 若**累计伤害总额超过当前生命**，会提示「彗星:当前伤害致死！！」；当单跳的实质扣血量
      超过当前生命时，本英雄会被直接击杀（无法靠拖延逃过致死量）。

    **主动**：对周围 **350 范围**内敌人造成 **500 + 敏捷 × 2** 的**混乱伤害**，
    同时**清空当前累计伤害**（把已经记账、尚未扣完的伤害一次性抹掉），实现「化险为夷」。

    *技能ID：A1FG*（消耗 100 魔法）

    !!! note "机制说明"
        被动会把绝大多数伤害先「吸收」再分期扣除，因此特莉波卡的有效血量取决于能否在累计伤害
        扣完前用主动 D 抹账或拉开距离回血；一旦累计总额或单跳实质量超过当前血量则直接阵亡。

## 其他说明

本英雄的 Q/W/E/D 走施法事件统一分发（单位类型 `H07E`），R 为习得即生效的被动属性技能。
源码中另有一段旧的 `hero_xh_R`（绑定 `A1FK`）连斩逻辑，但该 ID **未注册到本英雄的技能位**，
当前版本不会触发，故不计入现役技能。

经核查，特莉波卡在 2.41 版本**没有专属装备/专属武器检测**（技能内不含 `UIOP` 等专属物品判断）。
