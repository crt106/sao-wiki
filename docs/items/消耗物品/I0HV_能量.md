# I0HV · 能量

> **类型**：消耗物品　**当前获取状态**：无正常来源

> **版本结论**：2.5 与 2.41 的游戏数据及版本内容一致；本页以 2.5 重新核验后的结论为准，不另设版本 Tab。

## 实际效果

拾取后永久增加：

| 属性 | 数值 |
|---|---:|
| 筋力（力量） | +50 |
| 敏捷 | +50 |
| 体力（智力） | +50 |

沿用自属性之书类物品 `tpow`，并绑定能力 `A0QO`。`A0QO` 的三个属性数值均为 50，因此旧页面和游戏说明所写的“全属性 +1”是错误的。

## 获取方式

当前 2.5 没有商店、怪物或宝箱掉落、合成、扭蛋或任务等正常获取方式。

**结论：正常游戏流程下无法获得。**

## 使用说明

- 拾取后会立即消耗，不是可反复使用的背包装备。
- 当前版本没有正常获取渠道，上述永久属性仅作数据记录。
