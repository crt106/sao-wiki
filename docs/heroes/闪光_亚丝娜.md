# 闪光 · 亚丝娜

**主属性**：敏捷 · **英雄 ID**：`Hmkg`

> 亚丝娜在 2.41 版本已整体重做，技能均改由新式 `hero_asn_*` 函数实现（注册技能 ID 为 `A1B7`/`A1LC`/`A1LF`/`A1AP`/`A1KS`）。本页数值与机制全部基于触发器代码验证，工具提示文字仅作参考。

## 基础属性

| 属性 | 初始值 | 每级成长 |
|------|--------|---------|
| 力量 | 20 | +1.0 |
| 敏捷 | 20 | +1.0 |
| 智力 | 20 | +1.0 |

主属性为**敏捷**，全部输出技能均以**当前敏捷**为系数。

## 技能

> 下列技能均带「装备**闪烁之光**（`I0PD`）后强化」机制：背包中携带该专属细剑时，对应技能系数提升（详见各技能与「专属装备」节）。

???+ abstract "Q · 四倍痛击　冷却：6秒　3级解锁"

    *技能ID：A1B7*

    向目标发起一次冲刺并接续 3 段位移斩击，**共 4 击**。第 1 击伤害为**敏捷×13**，此后每一击伤害在上一击基础上**乘以 1.2**（即 ×13 → ×15.6 → ×18.7 → ×22.5，递增）。

    - 第 2 段绕到目标正侧、第 3 段绕到反侧、第 4 段从背后斩击，并伴随溅血特效。
    - 施法期间亚丝娜处于**无敌**与时间流速加速状态。
    - 伤害类型：**混乱攻击 / 毁灭伤害**（`ATTACK_TYPE_CHAOS` / `DAMAGE_TYPE_DEMOLITION`，无视护甲）。

    !!! warning "描述与实测差异"
        - 工具提示写「连续造成 ×13 的敏捷伤害，一共 4 次」，**实际后续每击在前一击基础上递增 20%**，并非全程固定 ×13。
        - 工具提示写伤害类型为「穿刺」，实测为**毁灭伤害**。
        - 携带专属细剑**闪烁之光**时，首击基础系数由 **敏捷×13 提升至 ×16**（后续递增规则不变）。

???+ abstract "W · 闪光袭击　冷却：10秒　10级解锁"

    *技能ID：A1LC*（触发函数 `hero_asn_W`，对应「星爆气流斩」式连闪）

    瞬移至目标身前，进行**5 段高速闪击**，随后接一段三影合击的收尾斩。

    - **每段闪击**：造成**敏捷×10**伤害，并通过马甲单位（`A166`）施加**约 0.5 秒眩晕**，同时将目标向前推挤约 100 距离。
    - **收尾斩**：亚丝娜与两个分身穿身而过，造成**敏捷×50**伤害，并施加**1.5 秒眩晕**（`A1C6`）。
    - 伤害类型：**混乱攻击**（混合 `DAMAGE_TYPE_UNIVERSAL`，无视护甲）。

    !!! warning "描述与实测差异"
        旧 Wiki 写「多段连刺每刺敏捷×10，最后一击敏捷×60 眩晕 1.5 秒」。实测为：**5 段闪击各敏捷×10**（每段 0.5 秒晕）+ **收尾敏捷×50**（1.5 秒晕），**收尾系数为 ×50 而非 ×60**。
        携带**闪烁之光**时：每段闪击系数 **×10 → ×13**，收尾系数 **×50 → ×53**。

???+ abstract "E · 五星撕裂　冷却：22秒　15级解锁"

    *技能ID：A1LF*（触发函数 `hero_asn_E`）

    在指定地点进行**5 段瞬移跳跃**，落点连成五角星轨迹（上 → 右下 → 左下 → 右 → 左），最后回到五角星中心释放一次收尾爆发。

    - **五段跳跃**：每段落地对周围**半径 800** 范围内敌人造成**敏捷×25**伤害，并附带雷击特效与轻微击退（每段间隔约 0.1 秒，跳跃半径 120）。
    - **收尾爆发**：5 段结束后亚丝娜回到中心点，再对**半径 800** 范围内敌人造成一次**敏捷×60**伤害（雷击特效）。
    - 施法前会沿直线检测地形，遇阻挡则停在最后一个可通行点。
    - 伤害类型：**混乱攻击**（混合 `DAMAGE_TYPE_UNIVERSAL`，无视护甲）。

    !!! warning "描述与实测差异"
        旧 Wiki 写「高速多次×25，最后一击敏捷×60」。实测为**固定 5 段、每段均为敏捷×25**，外加**回到中心的一次敏捷×60 收尾爆发**（即旧 Wiki「最后一击×60」确有其事，但它是 5 段跳之后的中心爆发，而非第 5 段本身）。
        携带**闪烁之光**时：每段跳跃系数 **×25 → ×28**，收尾爆发 **×60 → ×63**。

???+ abstract "R · 闪光三十六连击　冷却：36秒　20级解锁"

    *技能ID：A1AP*（触发函数 `hero_asn_R`）

    在目标点进入无敌状态并高速乱舞，**共 36 段连击**。

    - 每段在落点周围**半径 520** 范围内对敌人造成**敏捷×9**伤害，并以马甲单位施加雷击眩晕。
    - 施法全程亚丝娜**无敌**、随机高频瞬移（带飞行高度变化），结束后回到起手位置。
    - 伤害类型：**混乱攻击 / 毁灭伤害**（无视护甲）。

    !!! warning "描述与实测差异"
        携带**闪烁之光**时：每段系数 **敏捷×9 → ×14**。

???+ abstract "F · 圣母圣咏　冷却：70秒　隐藏解锁（非等级解锁）"

    *技能ID：A1KS*（触发函数 `hero_asn_F`）

    单体爆发大招。施法时需先蓄力（对非 Boss 目标蓄力可被打断），蓄力完成后亚丝娜进入**无敌**并对锁定目标发动一轮极速连斩：

    - 起手贯穿斩：造成**敏捷×8**（**魔法攻击 / 毁灭伤害**）。
    - 随后进行**约 22 段**乱舞连击，首段基础为**敏捷×8**，每段在上一段基础上**乘以 1.10（递增 10%）**，并每段以 `A166` 雷击眩晕目标。
    - 主体连斩为**混乱攻击 / 毁灭伤害**（无视护甲）。
    - 若目标在过程中死亡，连击会提前收束。

    !!! warning "描述与实测差异"
        工具提示写「进行 22 段连击，每段敏捷×8，每次连击伤害提高 14%」。实测每段递增系数为 **×1.10（即 +10%）**，并非 +14%。

    !!! note "解锁方式"
        该技能**不随等级自动获得**：需在**血盟骑士团副本**中击败对应 Boss（单位 `n05E`）后，由触发器永久授予亚丝娜本体（届时会提示「系统:你已经掌握圣母圣咏！！」）。

## 专属装备

**闪烁之光**（`I0PD`，物品等级 82，专属细剑）

- **获取途径**：由 Boss **王珏**（单位 `n02B`）击杀掉落（同时掉落数件专属武器，属保底掉落池）。
- **基础属性**：攻击力 +700、力量 +300、敏捷 +340、生命值 +30000，附带「细剑提升」与透明剑刃 **25 层强化空间**效果。
- **技能强化**：背包中携带该剑时（运行时 `YDWEUnitHasItemOfTypeBJNull(..., 'I0PD')` 检测），亚丝娜的输出技能系数全面提升：

| 技能 | 无专属 | 携带闪烁之光 |
|------|--------|-------------|
| Q 四倍痛击（首击） | 敏捷×13 | 敏捷×16 |
| W 闪光袭击（每段闪击 / 收尾） | ×10 / ×50 | ×13 / ×53 |
| E 五星撕裂（每段跳跃） | 敏捷×25 | 敏捷×28 |
| E 五星撕裂（中心收尾爆发） | 敏捷×60 | 敏捷×63 |
| R 闪光三十六连击（每段） | 敏捷×9 | 敏捷×14 |

> F「圣母圣咏」的伤害系数不随该专属武器变化。
