# I0L5 · 气流装甲

> **品质**：普通　**打造物品等级**：49

> **2.5 复核结论**：旧页漏掉每秒 50 点魔法恢复，也没有给出两条随机来源的最终概率。锻造单次为 25%；迷宫野兽单次击杀为 1/28。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +90 |
| 敏捷 | +90 |
| 智力 | +90 |
| 生命值上限 | +15000 |
| 防御力 | +35 |
| 每秒魔法恢复 | +50 |

## 隐藏效果：降温

持有 `I0L5` 的单位位于炎热区域豁免范围中，不受每轮 1000 点魔法扣减。

## 获取方式

### 防具打造

使用[39 层冰柔之毛](../素材/I0AZ_39层冰柔之毛.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I0GI` 或 `I0L5`。

因此每次材料充能获得气流装甲的概率为 **1/2 × 1/2 = 1/4（25%）**。

### 迷宫野兽

击败 `nowb`（Lv40 雪地的小野兽）时，有 `1/7` 概率从4件49级奖励 `I0AZ`、`I0B0`、`I0GI`、`I0L5` 中随机掉落一件，因此单次击杀获得气流装甲的概率为 **1/28（约3.57%）**。
