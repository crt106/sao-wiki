# I0EM · 楼兰·仙气之衣

> **品质**：传说　**类型**：装甲

> **2.5 复核结论**：补齐主动技能的 800 点魔法消耗与 12 秒冷却。物品本体属性和掉落沿用旧版，但 2.5 新增了作为[玲珑仙裙](I0QA_玲珑仙裙.md)材料的用途。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +120 |
| 敏捷 | +120 |
| 智力 | +120 |
| 生命值上限 | +12000 |

## 主动效果：仙气内聚

能力 `A0Q3` 基于神圣之光：

| 参数 | 实际值 |
|---|---:|
| 治疗量 | 10000 |
| 魔法消耗 | 800 |
| 冷却时间 | 12 秒 |

神圣之光对敌方不死单位的伤害规则、目标过滤和数值显示需要实际游戏确认。

## 获取方式

击败 Lv70 琳（单位 ID：`n02C`）时，必定掉落 1 件 `I0EM`。

## 合成用途

=== "2.5 狂猎"

    可与[黑魅连衣裙](I07H_黑魅连衣裙.md)、[神秘的幻彩水晶](../特殊/I09L_神秘的幻彩水晶.md)合成[玲珑仙裙](I0QA_玲珑仙裙.md)。

=== "2.41 测试版"

    旧版没有 `I0QA`，也没有这条三材料合成公式。
