# I0OM · 智慧之书

> **分类**：消耗物品（拾取即用）　**使用次数**：1 次

> **版本结论**：2.5 与 2.41 的游戏数据和唯一获取方式一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际效果

英雄拾取后会自动消耗，并永久增加 50 点智力。

**技能 ID**：`A1BO`

## 获取方式

一只指定的宝物箱（单位 ID：`ndrv`）必定开出：

- `I0OM` 智慧之书 ×1；
- `I0ON` 贤者之帽 ×1。

当前版本没有其他商店、合成或随机奖励来源，旧页的“获取方式待验证”现已补全。
