# I0D5 · 超便装

> **品质**：精良　**打造物品等级**：34

> **2.5 复核结论**：旧页属性基本正确，但没有给出打造失败率和池内概率。2.5 与 2.41 游戏数据一致，本页不拆版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +92 |
| 敏捷 | +144 |
| 生命值上限 | +5000 |
| 移动速度 | +70 |

## 获取方式

在 25 层防具打造中使用[坚硬羽毛](../素材/I07R_25层坚硬羽毛.md)：

- 打造成功率为 `1/2`；
- 成功后随机获得 `I097` 或 `I0D5`；
- 无论成功与否都会消耗 1 次材料充能。

每次材料充能获得本物品的名义概率为 **1/4（25%）**。
