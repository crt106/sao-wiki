# I0C3 · 罪恶王冠

> **品质**：传说　**类型**：头部道具　**物品 ID**：`I0C3`

!!! warning "提示文字与实际执行严重不一致"
    游戏提示只写了“生命低于 30% 时触发”，但当前 2.5 中有两套保护效果同时存在：其中一套会在冷却结束后受到第一笔正伤害时直接触发，两套效果也可能互相重叠。

## 基础属性

| 属性 | 实际值 |
|---|---:|
| 筋力 | +225 |
| 敏捷 | +225 |
| 体力 | +350 |
| 生命值上限 | +5,000 |

## 失落的圣诞

### 伤害保护

冷却就绪时，持有者受到任意一笔正伤害都会：

1. 将本次伤害归零，并把持有者生命直接设为 1；
2. 无敌并暂停 3 秒；
3. 结束后给当前生命增加一份最大生命值，通常会回到满血；
4. 3 秒保护结束后才启动 60 秒冷却，因此从触发到再次可用约为 **63 秒**。

该效果不检查当前生命比例，也不要求本次伤害足以致命；特殊击杀效果不保证触发保护。

该效果与[罪恶王冠（觉醒）](I0PV_罪恶王冠_觉醒.md)共享约63秒的保护冷却，同时持有也不会得到两次独立保护。

### 旧式低血量保护

持有 `I0C3` 时，每秒会检查一次生命；生命不高于30%时：

- 无敌并暂停 3 秒；
- 回复 `当前体力×100` 生命；
- 3 秒保护结束后进入 120 秒冷却。

同一时间只有最后拾取者能稳定获得该效果；后拾取者会覆盖前一位持有者。任意一件 `I0C3` 被丢弃时，还可能停止其他持有者的效果；首次触发后的 3 秒内也可能重复进入。

统一伤害保护会主动把生命设为 1，因此也可能让旧定时器满足 30% 条件。两套保护的并发顺序、多人覆盖与重复进入实际表现仍待确认，不能只按提示文字理解为单一 60 秒技能。

## 获取方式

击败 35 层“无情之地”的固定首领雷米利亚（三皇）（单位 ID：`nenp`）时，必定掉落 1 件。

标注金币价格 等游戏数据不能证明商店来源；当前版本没有正常商店、扭蛋或其他直接获得方式。

`I0C3 + I0PW → I0PV`
