## 获取方式

本物品来自地图中的一只**指定金色宝箱**，不是所有金色宝箱的通用掉落：

- 宝箱单位 ID 为 `nrvs`；
- 掉落池为 `I0BG`、`I0LA`、`I09F`、`I0H2` 四项等权；
- 因此黑鸦之羽的掉落概率为 **25%**。
