# I0O9 · 黑色晚礼服

> **品质**：传闻　**类型**：装甲

> **2.5 复核结论**：旧页照抄的“恒温”没有任何生命或魔法环境豁免，当前不生效；召唤物也没有同步全部英雄属性，只复制最大生命值与防御力。主动真实冷却为 42 秒，小猪仅存在 3 秒。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 筋力 | +110 |
| 智力 | +230 |
| 生命值上限 | +8000 |

## 主动效果：召唤共鸣

使用 `A1AB` 后在持有者位置创建契约小猪 `n03X`：

1. 小猪最大生命值复制持有者最大生命值，并以满血出现；
2. 小猪防御力复制持有者当前防御力；
3. 立即下达一次范围嘲讽命令；
4. 3 秒后因限时生命消失。

嘲讽技能 `A1AC` 的范围为 1200、最多影响 50 个目标、冷却为 5 秒。小猪只存在 3 秒，因此通常只能成功施放一次，不能描述成“每 3 秒循环嘲讽”。物品主动冷却为 **42 秒**。

## 未生效说明：恒温

物品说明和查询文本写有恒温，但当前实际游玩中不能确认它能免疫寒冷扣血或炎热扣蓝。

## 获取方式

击败 Lv40 伊偌－亚兰·法多（单位 ID：`nwwd`）时，必定掉落 1 件 `I0O9`。
