# I0DI · 骷髅面具（劣质）

> **分类**：头部道具　**品质**：劣质　**物品等级**：68

> **版本结论**：2.5 与 2.41 的游戏数据和迷宫掉落方式一致；本页以 2.5 重审结论为准，不另设版本 Tab。

## 实际属性

| 属性 | 数值 |
|---|---:|
| 力量 | +10 |
| 敏捷 | +10 |
| 智力 | +10 |
| 防御 | +30 |
| 魔法伤害减免 | 30% |

旧页把魔法防御写成平面“+30”；技能 `A079` 的实际效果是魔法伤害减免 30%。

## 获取方式

击败 44 层迷宫中的 46 级怪兽骷髅（单位 ID：`nstl`）时，有 **4%** 概率掉落本物品。

物品等级 68 不是“68 层掉落”的意思；实际来源是 44 层迷宫。
